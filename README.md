# 万神之书 · MYTHIC DND

八大神系、十三部中文 DND 风格冒险的完整游戏合集，附作者本机工作台。游戏源码、剧情、规则、地图和运行所需素材均随仓库提供；无需原作者电脑上的目录，也无需安装第三方 npm 包。

![万神之书](public/assets/hub-hero.png)

## 在线书库与联机状态

[GitHub Pages 书库](https://throne-kari.github.io/mythic-dnd-hub/)用于浏览十三部冒险和规则资料，游戏入口连接独立的 [Render 联机服务](https://mythic-dnd-hub.onrender.com/)，不依赖房主电脑持续在线。

**目前是免费临时联机版，不是永久存档服务。** Render 空闲约十五分钟后会休眠，下一次访问可能需要约一分钟唤醒；休眠、重启或部署会清空房间、席位和服务端存档。请勿把长期战役的唯一存档留在此服务中。浏览器保存的席位凭据不能恢复已丢失的服务端房间。

长期保存需要独立的持久化磁盘或适配的外部存储。`deployment.json` 只保存公开的 HTTPS 后端源地址及临时存档标记，不保存密钥。具体配置和各游戏重启限制见 [DEPLOY.md](DEPLOY.md)。

## 开始使用

安装 **Node.js 24 或更新版本**，下载或克隆仓库，在项目目录运行：

```sh
npm start
```

- 游戏大厅：<http://localhost:4780>
- 作者工作台：<http://127.0.0.1:4781/manage/>

Windows 可直接双击 `start-author.cmd`。仅启动游戏网站可运行 `npm run serve`，或双击 `start-site.cmd`。服务需要持续运行，终端中按 Ctrl+C 关闭。

大厅支持神系筛选、搜索、游戏详情、资料阅读与本浏览器的最近游玩记录。点击进入游戏时自动启动对应程序，所有游戏都使用 `/play/<游戏ID>/` 入口，各自保留原有的房间、人物、剧情、地图与操作界面。人数、主持需求以各作品详情为准。

## 作者工作台

工作台只监听本机回环地址，可查看游戏状态、启动 / 停止进程、阅读运行日志、查看存档并下载备份。它与游戏网站使用不同端口，网站端口不提供作者管理接口。

原作者的工作目录保存在忽略的 `author-sources.local.json` 中。换电脑后可在工作台重新选择本地源目录；点击“从源目录更新”会先停止对应游戏，再把源码与素材更新到合集。该操作保留独立运行目录中的存档，原始写作目录不被修改。

命令行也可以更新：

```sh
# 先在工作台停止目标游戏
node scripts/import-games.mjs --game aztec --update
```

完整原稿目录可首次映射为本地来源（已有合集使用 --update）：

```sh
node scripts/import-games.mjs --source-root "../你的原稿目录" --update
```

`catalog.json` 保存通用目录、版本、简介与资料入口；不保存本机绝对路径。导入脚本为十三部现有作品保留各自的适配规则。

## 数据与迁移

合集运行数据默认在 `runtime/<游戏ID>/`。各游戏的数据、房间和浏览器身份相互隔离。已有原项目存档不会自动迁移，也不会被覆盖。

迁移时先停止服务，复制整个 `runtime/` 到新电脑同一位置，再启动同版本合集；或使用 `HUB_RUNTIME_DIR` 指向其他持久化目录。浏览器中的席位凭据仍由原游戏管理，“最近游玩”只是入口记录，不能替代服务端存档。

`runtime/`、本机源映射、`.env`、日志与备份压缩包均被 Git 忽略。不要把实际 API 密钥写入源码或公开配置。现有游戏的 AI / Agent 接口继续按各作品指南配置，本合集无需模型密钥即可启动。

## 自托管

运行方式、Docker、Pages 与 HTTPS 反向代理见 [DEPLOY.md](DEPLOY.md)。这是有服务端进程和持久化存档的 Node 应用；GitHub Pages 只托管静态书库，不能运行完整游戏服务。

## 界面与素材

大厅、详情页、资料页和作者台统一使用墨青、米白与黄铜色。各游戏原有界面保留。UI 参考图位于 [design/](design/)，内置 imagegen 生成的参考与封面提示词见 [design/prompts.json](design/prompts.json)。新增封面在 `public/assets/`，作品原有素材随对应游戏保留。各作品已有来源与许可文件继续有效。
