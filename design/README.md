# 界面视觉依据

先整理真实内容，再用内置 imagegen 生成并查看三张 UI 参考图，随后实现页面。

- `library-reference.png`：全神系大厅，宽幅画面、中文衬线标题、神系筛选与四列游戏卡。
- `detail-reference.png`：作品详情，左图右标题与主要操作，下面是概览、资料和同神系作品。
- `manager-reference.png`：作者工作台，窄侧栏、浅色统计区、深色游戏表与日志面板。

实现采用墨青背景、米白文本、黄铜细线与按钮；管理台保留浅色信息区。参考图中的示例状态、生成文字与人数不作为产品数据，实际内容来自 `catalog.json` 和运行服务。阿兹特克已于本次交付收为正式游戏。

`prompts.json` 保存内置 imagegen 的完整提示词。无字横幅及四张神系封面位于 `../public/assets/`；其余封面选自作品既有原画。
