# 第六幕规则查阅备忘

2026-09-22。供四名12级角色的朝歌行动与封神尾声使用。依据为[官方SRD 5.2.1](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf)；以下均为文内页码。只查阅来源与写作，未测试、模拟、回归或试玩。本幕保持12级，不因到达尾声自动升13级。

## 三妖采用整张原卡

本幕妲己采用Rakshasa，胡喜媚、王贵人各采用Lamia。这是这场冒险的完整规则接口，不是原著实力排序；三名真实人物就是三名敌人，不另加影分身、无限召唤或必然二阶段。外观与说辞可以改写，真实体型、类型、速度、施法时间和所有特质照原卡。

| 遭遇 | XP |
| --- | ---: |
| Rakshasa一名 | 10,000 |
| Lamia两名，每名1,100 | 2,200 |
| 三妖全部实际敌对时 | **12,200** |

SRD p.202：12级每人低／中／高预算为2,200／3,700／4,700 XP，四人合计 **8,800／14,800／18,800 XP**。不套2014的怪物数量倍率。12,200处于低、中预算之间，但Rakshasa有高于队伍等级的CR及特殊抗魔，不能只凭总数宣称平衡已经验证；同伴离场、获救、投降或被放逐均改变实际战斗。里程碑与任务奖励不要求杀死全部敌人。

### Rakshasa，pp.317–318

Medium Fiend、Lawful Evil；CR13／10,000 XP／熟练+5。AC17，HP221（26d8+104），先攻+8，速度40尺。六属性力量14、敏捷17、体质18、智力13、感知16、魅力20；豁免分别+2／+3／+4／+1／+3／+5。欺瞒+10、洞悉+8、察觉+8；真实视觉60尺、被动察觉18；Common、Infernal。

- 弱点：**受Bless影响的生物使用武器造成的穿刺伤害**。不要求使用者某种阵营，不自动包含挥砍、法术穿刺或其他附加伤害。绝仙长剑照常造成挥砍，不能因为是神话法宝而改成穿刺以触发弱点。
- 免疫魅惑、恐惧状态。**没有旧版非魔法物理伤害免疫**。
- Greater Magic Resistance：对法术及其他魔法效果的豁免自动成功；法术攻击检定自动失手。未经其许可，法术不能远程观察它，也不能读其思想、检测其生物类型或阵营。**这不是旧版“六环及以下法术免疫”，也没有七环自动绕过的分界。**
- Fiendish Restoration：在Nine Hells之外死亡，身体化为脓液，并立即在Nine Hells某处取得新身体、恢复全部HP。本地击败不等于永久消灭；不能为了收尾取消复生，也不能把复生写成原地第二条血。它没有随此特质立即回到朝歌的能力。
- Multiattack：动作三次Cursed Touch。
- Cursed Touch：近战+10，触及5尺；2d6+5挥砍加3d12黯蚀。命中生物便施加诅咒，无额外豁免；受诅咒者不能从完成短休或长休获得任何益处。原卡没有到次日自动结束条款，Remove Curse正常有效。
- Baleful Command：动作、充能5–6；自身30尺发散区域内每个敌人作感知DC18。失败受8d6心灵，并恐惧及失能至Rakshasa下回合开始；成功没有所列伤害及状态。此项不是名叫Command的法术，也不获得操控任意行为的能力。
- Spellcasting：魅力施法DC18，仅免材料成分。随意Detect Magic、Detect Thoughts、Disguise Self、Mage Hand、Minor Illusion；每日各一次Fly、Invisibility、Major Image、Plane Shift。法术仍遵守原施法时间、言语／姿势成分与专注；没有Shield、Counterspell、Dominate Person、传心或卡外真变形。

妲己的真形可写成中型、狐首、直立的妖躯；女身是Disguise Self。原卡没有变成小狐狸钻缝的Shape-Shift，也不提供随时附身他人的能力。不要在规则上把她改成Humanoid，或给幻象增加真实额外肢体。

**让玩家知道有效方法。** 自动成功豁免仍执行该法术的成功结果，例如Fireball、Sunbeam的成功减半伤害；Magic Missile（p.146）没有攻击检定与豁免，满足可见、范围等条件时正常造成伤害。Bless支援、治疗、移动同伴、搭桥与分隔战场均真实有效。原卡的抗魔不是消除整张地图的法术；也不自动扩展成所有体质豁免都成功，受伤后的专注仍按专注规则处理。另一方面，Disintegrate的成功结果本就无伤害，不因用了六环位而强行造成一半。

她的Plane Shift按原法术（p.153）是动作、接触，可以与至多八名手拉手成圈的自愿生物一同离开，目的地在另一位面。不能抓走不愿同行的俘虏。每日使用后须正常恢复，不能每回合往返。允许她带着同意同行的姐妹离场，本地安全目标不必升级成追杀九狱；人物去向如实记入尾声。

### Lamia，pp.303–304

Large Fiend、Chaotic Evil；CR4／1,100 XP／熟练+2。AC13，HP97（13d10+26），先攻+1，速度40尺。六属性16／13／15／14／15／16，豁免+3／+1／+2／+2／+2／+3；欺瞒+7、洞悉+4、隐匿+5。黑暗视觉60尺、被动察觉12；Abyssal、Common。没有卡面抗性、免疫、抗魔、飞行或复生特质。

- Multiattack：动作两次Claw，可把其中一次换为Corrupting Touch。
- Claw：近战+5、触及5尺，1d8+3挥砍加2d6心灵。
- Corrupting Touch：五尺内可见的一个生物作感知DC13；失败受3d8心灵并受诅咒一小时，诅咒期间具有魅惑及中毒状态。不是命中即自动控制，不能每回合随意指定目标替它作战；原卡没有每回合重作豁免条款，解除诅咒、状态免疫等正常处理。
- Spellcasting：魅力DC13，仅免材料成分。随意Disguise Self（可以显现为Large或Medium的两足外观）、Minor Illusion；每日各一次Geas、Major Image、Scrying。
- Leap：附赠动作，花费10尺移动跳跃至多30尺。不是飞行、传送或无限免费移动。

两妖可以各有雉纹／玉色等真身外观，但都保留Large占位与真实身体。Disguise Self只让别人看见中型人形，**不把真实体型降成Medium**，不能借幻象轻松穿过只容中型身躯的空隙。胡喜媚不会因原著九头雉鸡形象额外获得飞行、九次攻击；王贵人也不因琵琶外观成为物件或Construct。原卡无死亡后自动变回便携乐器、免伤乐器或复生。

三妖都是Fiend，Hold Person和Charm Person等限定Humanoid的法术不能以其为目标；Lamia没有魅惑或恐惧免疫，适用其他合法法术和六魂幡。杀死一名Lamia也不会自动解除另一名施加的法术或诅咒。

## 战前两瓶英雄药水

Potion of Heroism（p.236）：Rare药水，不需共鸣。饮用者获得10临时HP，持续一小时；同一小时内处于Bless法术效果，**无需专注**。药水通则（p.204）规定饮用或喂给另一生物花附赠动作，立即生效并消耗这瓶药水。

第十一回可从军中现有储备交付小队合计两瓶，明确数量及用途。喝下者真实满足Rakshasa弱点的Bless条件，可用普通矛、弓等武器造成穿刺伤害；武器熟练、射程、护甲与正常攻击检定仍适用。不能把绝仙长剑的挥砍随口改成穿刺。Bless自身效果见p.113：攻击检定及豁免加1d4，药水不是永久+1d4，也不对全部属性检定加骰。与另一个Bless不会叠成2d4，临时HP依通则选择保留一份而不相加。

未饮用的药水可以留到以后，不在离开朝歌时自动过期；两瓶是战前准备物，不从战后2,000GP报酬中暗扣。若玩家主动混用药水，使用p.204现有药水混合规则，不另创“符水冲突”系统。

## 识破、反制、放逐与解除诅咒

法术原文另可由[官方2024 Spell Descriptions](https://www.dndbeyond.com/sources/dnd/br-2024/spell-descriptions)查阅。这里只列终幕需要提前写清的接口，不假定每队都会全部法术。

| 能力 | 本幕用法与边界 |
| --- | --- |
| True Seeing，p.171；Truesight，p.190 | 六环、动作、接触自愿生物、V/S/M，消耗至少25GP蘑菇粉；一小时、无需专注，真实视觉120尺。看见黑暗、隐形，视觉幻象透明，辨魔法变形真形并看见以太位面；不透实体墙，也不读心。近处看透妲己Disguise Self没有让她作豁免，也不是远程观察或检测类型；得到真实外观信息。 |
| Disguise Self，p.124 | 一环、动作、V/S、一小时，无专注；一般须保持原有基本肢体布局，Lamia原卡另许可大型／中型两足外观。物理接触能发现幻象不吻合；Study动作观察并作智力（调查），对妲己DC18，对两Lamia DC13。不是必得先做三轮检定才准相信目击。 |
| Dispel Magic，p.124 | 三环、动作、120尺、V/S；结束目标身上持续的三环及以下法术。更高环逐项用施法属性检定，DC10+环级；升环自动结束不高于所用法术位的法术。可除Disguise Self、Fly、Invisibility和Major Image等当前法术；不会删除Rakshasa抗魔、诅咒攻击、怪物身份或标准魔法物品。此术不要求被驱散者豁免，Rakshasa的自动豁免不能阻止这种解除。 |
| Counterspell，p.120 | 三环反应；看见60尺内生物以V/S/M成分施法时使用，使其作体质豁免，失败法术无效、所用动作／附赠／反应耗掉；原本用法术位施放者不消耗那个位。妲己对这次法术豁免自动成功，**不能把反制写作必能拦下她的Plane Shift**。两Lamia正常豁免；不可反制Claw、Cursed Touch或Baleful Command。 |
| Banishment，p.112 | 四环、动作、30尺可见一个生物、V/S/M、专注至多一分钟；魅力豁免失败去无害半位面并失能。若提前结束则回原位／附近空位；若对Aberration、Celestial、Elemental、Fey或Fiend维持满一分钟，送往DM选定的类型相关位面随机地点而不返回。每升一环多一个目标。两Lamia合法，妲己自动成功；不是按旧版“是否出生于本位面”判定，也不是永久杀死。 |
| Remove Curse，p.158 | 三环、动作、接触、V/S，结束一个生物或物件身上的全部诅咒。可以真正结束Cursed Touch、Corrupting Touch及Geas；不用先杀施咒者或凑三件原创材料。魔法物品本身的诅咒只依原法术解除共鸣，不把物品消魔。 |

**Geas不是一回合接管角色。** p.135：五环、施法一分钟、60尺可见生物、V，持续30天，无专注。目标听不懂命令则自动成功，否则作感知豁免，失败获魅惑；反抗命令受5d10心灵、每天至多一次。命令不能要求必死行动，否则法术结束；Remove Curse、Greater Restoration或Wish可结束。若使用持续五环法术的一般驱散途径，Dispel Magic照常用DC15检定，五环或更高位自动结束。预先施放在谁身上、命令是什么、剩余时长都必须提前记录；不把所有宫人默认写成被控制的敌人。

Charmed只提供相应状态效果，不让主持接管玩家的全部选择。Corrupting Touch造成中毒也不等于目标永远相信施咒者；NPC的原有恐惧、私利与约定要与魔法分开写。

## 复生、遗体与封神尾声

**Dead通则（p.180）适用于复生。** 死者不能只靠普通治疗恢复HP；需要真正复生。灵魂知道施法者是谁，能够拒绝，Revivify也遵守此项。复生不自动解除仍在持续的状态、魔法疾病或诅咒；原法术另有说明才例外。原有力竭减少一级，死亡已结束物品共鸣，复生后不能直接当作还与六魂幡共鸣。

| 法术 | 时限、代价与可用程度 |
| --- | --- |
| Revivify，p.159 | 三环、动作、接触、V/S/M，消耗至少300GP的一颗钻石。死亡一分钟内回到1HP；不能复活老死者，也不修复缺失身体。常规牧师／德鲁伊5级可取得三环，圣武士／游侠通常9级；实际仍须已准备并有资源。 |
| Raise Dead，p.157 | 五环、施法一小时、接触、V/S/M，消耗至少500GP钻石。死亡不超过十天且死亡时不是Undead，回1HP并中和死亡时的毒素；闭合致命伤，不补肢体，缺少维生必需部位／器官则自动失败。复生后D20 Tests −4，每完成长休减少1直至0。常规吟游诗人／牧师9级可取得五环；12级圣武士尚无五环位。 |
| Reincarnate，p.158 | 五环德鲁伊法术、施法一小时、接触、V/S/M，消耗至少1,000GP稀有油。接触死亡不超过十天的Humanoid或其一部分，塑造新身体并呼唤其灵魂；按原表掷1d10决定种族，或DM选择其他可玩种族。保留原有记忆与能力，原种族特质换成新种族特质，相关选项由复生者选择。种族改变不是免费换职业，也不能对Fiend套此Humanoid限定法术；玩家仍可以拒绝回来。 |
| Resurrection，pp.158–159 | 七环、施法一小时、接触、V/S/M，消耗至少1,000GP钻石。死亡不超过一世纪、不是老死、死亡时不是Undead；回满HP，中和毒素、闭合致命伤并恢复缺失部位。同样有D20 Tests −4与逐次长休恢复；若死了至少365天，施法者在下一次长休前不能再施法且D20 Tests劣势。常规吟游诗人／牧师13级才有七环；本团12级尾声不凭空发七环位或免费NPC服务。 |
| Gentle Repose，p.135 | 二环、动作或仪式、接触、V/S/M，消耗两枚铜币，十天无需专注。尸体或遗骸不腐败、不变Undead；被此术覆盖的时间不计入相应复生期限。须在尚未超出目标复生期限时及时保存并记录；不能把已过期遗体的死亡日重置。仪式额外施法时间不能反过来补救错过的一分钟。 |
| Speak with Dead，p.164 | 三环、动作、十尺、V/S/M（燃烧的香），持续十分钟。尸体必须有嘴，死亡时不是Undead，过去十天没有成为本法术目标；至多五问，只知道生前知识和语言。面对敌人不被强迫说实话，不知道死后发生的事，也不推测未来；它没有把灵魂带回，不可拿来代替亡者是否愿意复生或受封的真实选择。 |

材料金额不是一切：还须确有该法术、遗体条件、时间和愿意回来的灵魂。角色若已有合法法术和材料，就让它发挥作用，不因原著某人必须死亡而宣布失灵；角色没有时，也不因为姜子牙在场就默认拥有无限次所有复生法术。复生支持本身可以是事先明确的人情或另行约定，不能作为玩家完成终战后的强制新增差事。

本幕可采用小队合计2,000GP的既定任务结算，和平解决、驱离和战斗完成按同一目标领取；金币是冒险报酬，不额外创造复生能力。已有武器、攀爬绳、传讯石、六魂幡与传送披风按其真实归属保留，不为封神尾声自动收走。

封神邀请、归山、留在人间与纪念亡者是战役结局叙事。SRD未提供本项目的封神神职职业、神力点或亡魂审判子系统，本幕不自行添加。死亡、失踪、已复生、愿不愿受封分别记录；不把获封自动等同于生理复活或逼角色先自杀才能选结局。

## 未采用候选与范围

Spirit Naga（p.329）本次只做候选定点查阅，**不加入三妖场面**：它是Large Fiend、CR8／3,900XP、AC17／HP135，死后1d6天必复生且只有Wish阻止，没有卡面变形。它比当前Rakshasa更会迫使尾声处理持续复生问题，故没有为了方便而拿掉复生特质后采用。Mage、Invisible Stalker沿用前幕已有说明，本幕不额外添入凑数。

本备忘只覆盖本幕实际接口，不是对所有职业、法术和封神宇宙的完整改编。以上原卡与规则均从固定官方来源查读，没有运行玩法测试。
