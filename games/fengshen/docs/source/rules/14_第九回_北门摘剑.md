# 第九回：北门摘剑

v0.7 · 四名 **10 级**角色 · 主持人草案 · 约一晚。前接 [今夜开关](12_第八回_今夜开关.md)，本回收束升 **11 级**，随后接 [幡下各有归路](15_第十回_幡下各有归路.md)。未进行测试或试玩。

## 这一回，摘下的就是真剑

**把北门的绝仙剑移离剑架，使它不再回到阵位。** 这一路由玩家负责；其余三路是预先约好的并行行动。在本回正式入阵的镜头开始前，三口剑已被取走，北门是本次诛仙阵最后的支点。小队做成，诛仙阵就真正破了，不再等某位天尊来补取一口“真正的剑”。

绝仙剑不是诱饵，也不是离台即碎的赝品。本团以一把完整的 **Weapon, +3（Longsword）** 表现它：Very Rare，不需共鸣，该武器的攻击检定与伤害掷骰各加 3，其余长剑规则照原条目。既不因是仙剑自动给持有者熟练或精通，也不附带挥一下便杀尽全场的能力。玩家取得后可以使用、保留、赠予或协议交存，不强制上交。

战前就把这张物品说明交给玩家。原著大阵的声势属于众人参与的一场战事，不是这把随身武器藏着一页尚未公布的无限效果。奖励说明从敌人持有到玩家取得始终相同。

## 从关楼饭桌，到北门剑光

汜水关的结果照实留下：韩荣父子活着便继续自己的去处，死者不复活；通路开放就继续开放。留出行军、安顿与正常休息的间隔。程简不在吃完饭后马上把小队推进另一场未休息的大战。

临近界牌关，道行天尊请小队看一张极简单的图：东诛仙、南戮仙、西陷仙、北绝仙。

> “原先北路由我摘剑。这回交给你们。我把看见的布置说清，你们选怎么进去。剑取下来后怎么用，也该由取剑的人说话。”
>
> 他看了一眼小队新得的兵器，又补了一句：“别把两把混了。北门那把剑脾气没有传言那么大，名头倒比你我都大。”

他提供已经观察到的北门布局，以及守卫会发射力场、压慢动作的消息；不赠送新法术、掌心免死符或忽略所有防御的通行权。高层仙人的交战牵住通天与其余战线，是本场开始时双方已知的局势。玩家面对的具体危险，全部写在本地地图和两张数据卡里。

先听玩家想借哪些旧关系：

| 旧关系或物品 | 这次的实用帮助 |
| --- | --- |
| 董全仍友好、愿意传话 | 可说明北门无形守卫是能听懂话、有自己打算的风中来客。没有他，守卫自己也能开口，情报不锁在死人身上。 |
| 韩变活着且愿意回话 | 提醒看石像手掌朝向：它能隔空出手，飞起来不等于已经安全。他不奉命返回战场代打。 |
| 顾行舟或许照仍可联系 | 前者能翻译 Primordial，后者能讲施法与专注；本回无形客也懂 Common，翻译不是必备门票。 |
| 攀云绳、传讯石、既有法术 | 按现有规则使用。绳能帮助上阁，石头能联系携带另一块的人；送给旧友的那一块不会又出现在小队背包。 |

没有这些帮助，北门依然可以侦察和进入。给每名玩家一个参与筹划的机会：谁看路径，谁准备应对压慢动作，谁接剑，谁负责让人能撤出来？可以一人做几件，也可以临场改变。

**钱款在出发前讲清：** 本回完成取剑、确实终止北门阵位后，军中向全队付 **1,000 GP**。下一回另有独立的 1,000 GP 委托；这次不扣下半笔钱等万仙阵。剑是这回实际取得的同一件法宝，不在结算时另外复制一把。

## 入场前应知道的四件事

1. 北门有一具石像守卫和一位看不见形体的守卫；没有每轮增加的兵卒。
2. 石像会近身重击，也会朝远处射出力场；它还能施放真正的 Slow，能被解除或打断专注。
3. 宝剑挂在有实墙遮挡的小石阁里，离地不高，普通挂扣不认人。取剑可以靠手、合法的远程操作或破坏剑架，不要求杀光守卫。
4. 取剑后守卫不会自动消失。带剑脱离其保护区域、谈妥停手或使其失去阻止能力，才算把这一结果稳稳留住。

道行愿把已知情况全讲清。玩家若还想看现场，外围北坡有能观察庭院的低石脊；Arcane Eye、隐匿观察或直接阵前喊话都能获得进一步信息。不要让取得可靠目击还要再掷一次“相信情报”的骰子。

## 能直接画的北门小图

以西南角 `(0,0)` 为原点，向东为 x、向北为 y，单位英尺。庭院约 **160 × 140 尺**；小队通常从北侧进入。红云、剑光与远处雷声只提供画面，不额外造成伤害、失明、耳聋或全场遮蔽。

| 位置 | 尺寸与行动意义 |
| --- | --- |
| 北入口 | `(80,140)`，宽 20 尺，接阵外石坡。通道开着，没有自动落下的铁栅。 |
| 西侧绕道 | 从 `(0,100)` 入场，绕过低石脊进入院西。地面可步行，不需先攀悬崖；从北侧阵外绕来约多走 180 尺。 |
| 东侧坡道 | 从 `(160,50)` 入场，普通平缓坡道。场外可绕达，能接近石阁东墙。 |
| 院中石墙 | `x45～85，y80～85`，高 10 尺、厚 5 尺。真实挡视线与直线通行，可绕两端或越过。 |
| 矮石槽 | `x20～45，y35～45`，高 3 尺。对实际被挡住的攻击提供 Half Cover，内有浅浅清水。不是藏着酸液的陷阱。 |
| 石阁 | 外廓 `x100～140，y20～60`，顶高 20 尺。西、东、南三面普通石墙厚 5 尺，顶为普通石板；北面也有墙，仅中央留门洞。 |
| 石阁门洞 | 北面 `y55～60，x115～125`，宽 10 尺、高 15 尺，无门扇。能从合适角度看见里面；阁墙提供实际遮挡，不可隔墙射中剑架。 |
| 剑架与挂剑 | 阁内 `(120,40)`，挂扣离地 4 尺。剑约 3 磅，挂在普通铁架上；周围有站位，不被石像身体填满。 |
| 阁顶 | 20 尺高的平屋顶，普通表面。能借梯、绳或飞行到达；屋顶本身没有通到室内的暗门。 |
| 南侧空地 | 图南缘接普通荒地，可离场；不是踏出一步即死的阵壁。 |

默认石像站在 `(105,90)`；无形客在阁内 `(120,50)`。已有侦察发现它们走动，就按实际站位。不要把无形状态误作同时占据三个入口，也不要让石像隔着阁墙看见一切。

北入口之外再走 200 尺是会合石坡。开场时把它标出来，便于玩家约定撤离点。两名守卫也必须按实际距离移动和追击；它们没有阵门间免费传送的能力。

## 守剑者：一位认真，一位太认真

### 石像：原卡 Stone Golem

完整采用 **Stone Golem，CR 10 / 5,900 XP，AC 18、HP 220**。准备时打开 [第五幕规则备忘](../research/ACT5_RULE_NOTES.md) 中的完整原卡入口。

它的本地任务是阻止未获原守阵者许可的人取剑，不能被冒充道行的一句话自动接管。它懂 Common、Primordial 和 Celestial（后两种为本具原卡允许的额外语言选择），但不会说话，也不是一尊需要被劝说回家的老兵。识别它的巡走与攻击范围、引开、阻挡、解除 Slow 或取得宝剑后甩开它，都是有效办法。

它在每个动作中按原卡作两次 Slam 或 Force Bolt：前者近身重击，后者是 **120 尺**力场远射。不能因为上一回的构装体没有远程攻击，就假定这具也只能站在台下发呆。它的法术与防御也不补回旧版同名卡的条目。

Slow 是充能后可用的附赠动作施法，依原卡 **DC 17**，需要专注。受到伤害后照常作专注豁免；Dispel Magic 可解除这项真实法术。它施放时免全部成分，2024 Counterspell 没有看见 V/S/M 施法的触发条件，不能因此使用；这不影响解除已生效的 Slow。不要给它未列出的传奇抗性。

这具是构装生物，不是能被 Passwall 当成石墙开洞的非魔法物件。它也没有旧版针对非魔法钝击、穿刺、挥砍的免疫。具体状态免疫和其他特性照新版全卡，不凭“仙家石头”增加。

### 无形客：原卡 Invisible Stalker

完整采用 **Invisible Stalker，CR 6 / 2,300 XP**。他懂 **Common、Auran**，可以和小队正常谈话。身形看不见，不表示没有脚步、声音、位置、意愿或受伤后的反应；发现、隐藏和攻击仍按实际规则。

第一次有人在阁前喊话，他可以回答：

> “你们是来摘剑的，我是来不让人摘剑的。很好，至少今日没有谁把差事听错。”

他接受的是守这一门的工作，不是永远为任何持幡人效命。若玩家用可核实的消息说明其他三门已经失守，他会认真考虑自己的处境，但不自动认输。若愿意给出真实且他认可的补偿，让他有理由结束这次受雇工作，或让他看到继续抵抗已没有可达成的目标，可使用 Influence 的意愿和态度规则交涉。

不设唯一礼物或固定成交暗号；主持人可让他对小队某件**已经持有、愿意交换**的精巧物件感兴趣，并在交换前说清这是个人要价，玩家完全可以拒绝。他不接受空口承诺“以后封你最大的神位”，也不要求另一名角色替死。若谈妥退场，他按自己的移动离开，不反悔来填满战斗预算。

若继续守剑，他用新版原卡的三次近战力场攻击，或依 Multiattack 替换其中一次使用 Vortex。Vortex 是同空间、体型符合条件的单目标动作；限制移动与说话的效果按卡处理，**不是全庭院沉默或永久禁魔**。玩家事前能从道行见过的情形得知：风会裹住人的口鼻，不要把负责言语施法的人独自送到他面前。

原卡没有旧版 Faultless Tracker，也没有“雇主不见便消失”或“剑被拿走便死”的特性。他在场时恒有 Invisible 状态，其物理抗性不以攻击是否魔法为分界；用 +3 剑也不自动无视该抗性。See Invisibility、其他能实际感知他的能力与合适的范围效果照原规则起作用。

## 三种入阵思路，都能把事办成

### 一、有人拖住守卫，有人进阁取剑

院中石墙能打断实际视线，阁的三面墙也能挡住力场弹。小队可让一人引出石像，其他人从东侧绕到门洞；也可先把无形客逼出狭窄入口，再换同伴进去。

这不是预定的职业分工。战士能去取剑，施法者能拖住石像，游荡者也能站出来跟风谈价。敌人按眼前发生的事反应，不在玩家刚提出分工时便凭主持人的知识布满所有路口。

取剑处没有重力封印。角色在挂扣旁能触及时，用一个 **Utilize** 动作解开挂扣并取剑；无需先解谜或作额外力量检定。战斗中同时承担其他动作，仍按正常行动经济安排。

### 二、让已经学会的法术省掉步骤

Dimension Door 可以按已知的空间描述直接到阁内空位，不能因为阁墙挡视线就判无效。Passwall 可在 5 尺厚的阁墙开出通道；Fly、攀云绳或普通梯子可以改变接近路线。法术只有角色真正掌握、准备并符合施法条件时才可用。

Mage Hand 也能依其完整条目操作这个普通轻小挂扣、搬起约 3 磅的剑；满足距离、控制动作和携物限制，就让它奏效。它不是生物，守卫不能对着一只魔手施加只影响生物的减速或缚住状态。守卫仍可以主动移动到看得见角色的位置、保护剑架或攻击真实的敌人，但没有免费打断每次物品操作的反应。

若玩家把剑合法传送或搬运到阁外，阵位就已经失去这口剑。不要追加“还得用肉身摸一次才算”。后续是否仍有追来的守卫、剑会不会被抢回，按实际行动处理。

Arcane Eye 的侦察能看清阁内与普通挂扣；它没有手，不能自己取剑。隐形能改变相应视线，但不等于无声，也不让任何生物忽略全卡已有感官。判定前给出足够可观察的线索，不靠新增 True Seeing 防住所有计划。

### 三、破坏剑架，或让一名守卫先退出

普通铁剑架的有效支撑部分采用 **Small 坚固铁物件，AC 19、10 HP**，免疫毒素与心灵伤害。能合法指定物件并确实有路径的攻击可以破坏它；剑架断裂，剑落地，便脱离原来的固定阵位。阁墙仍会挡住实际射线，不能从院外隔墙瞄架。

这是拆普通支撑，不是随手杀死石像。被击落的真剑仍在阁内，是同一件可以捡起的魔法武器；不是因为“任务完成”就免费飞入背包。玩家若想直接毁剑，先讲明魔法物品的正常抵抗与后果，依据所选条目处理，不把剑架的 10 HP 当成真剑的属性。

无形客可以单独退出，不要求石像也同意。石像则不会因为另一位受雇者说走，就自动改变原命令。分开两者的责任，往往比从头削光所有 HP 更有用。

## 守卫怎样反应，什么时候收场

正常全员在场时，总敌人为 **1 Stone Golem + 1 Invisible Stalker = 8,200 XP**。四人 10 级预算为低 **6,400**、中 **9,200**、高 **12,400 XP**；只用于选卡参考，未作平衡测试。无形客退走后只剩一具石像，主持不补来另一个。

石像优先阻止正在取剑或持剑离开的人，使用真实移动、攻击和 Slow；无形客可拦下单独穿行的人，也会判断自己是否要继续受伤。两者都没有传奇动作或“玩家每走一步就额外打一次”的能力。Force Bolt 是原卡攻击，不是可被 Counterspell 打断的法术。

**一旦剑确实离开阵位，先立即承认变化：** 北门剑光断开，阵上红气失去最后一处牵引，其他战线的人能看见这一结果。诛仙阵至此已破；其他三剑都已撤走，仅将这一剑重新挂起也不能重建整场四剑大阵。守卫仍是原来的生物，未失去行动能力者可能追取落在附近的剑，不会瞬间爆炸或消失。之后争的是这一口剑与同伴的安全，不是隐藏的第二次破阵任务。

石像的保护区域限定在这处庭院和四周 **30 尺**内，出发前道行能说明这一观察。它会在该范围内拦截取剑者，超过范围便回到剑架处；这个本地守卫命令不变成它的法术射程。若玩家仍在其可攻击距离内持续攻击，它可以在保护区域内正常还击。无形客不为此次工作追到阵外营地；谈妥退出后更不会远程索命。

保持剑离位并带离可被立即重新挂回的局面，或者已经解决守卫、明确不再复位，便完整完成本回。这里不是要求所有人必须踏过同一扇门；东坡、南荒地、传送或玩家找到的退路都有效。

取剑只用了一轮也可以结束这一核心行动。余下时间演阵外的人认出是谁出来、谁想先摸摸仙剑、谁反而把剑鞘收紧；不要为凑一晚再塞一只必打首领。

## 可以退，也可以再来

庭院没有无形边界墙。正常移动、脱离攻击与 Disengage 仍须处理；进入安全会合点不是全员瞬移。玩家可以带伤者撤到北坡，或用其他已知出口离开。

短休与长休按正常规则。若小队尚未取剑就撤出，其他三剑不会长回去；北门仍未完成，由小队再制定办法。两名守卫保留实际伤势、次数与去向，只有满足各自恢复规则才恢复，不趁玩家出图刷新。

没有未告知的三轮崩阵倒计时。若队伍决定长时间离开，先公开局势会怎样变化：双方可能停战重议，或原守阵者准备带剩下的剑撤走。玩家可以追踪、拦截、交涉，或者与盟友商量新的结束方式；不在幕后宣布神仙已经替他们完成任务。

| 实际结果 | 继续怎么讲 |
| --- | --- |
| 取得真剑，阻止其复位，队伍能够脱离 | 本次诛仙阵结束，剑归取得者按约处置；正常结算。 |
| 拆架使剑离位，守卫也已解决或愿意停手 | 阵已结束。剑留在现场等小队实际领取、赠予或封存，不另外生成奖励副本。 |
| 剑已离位，但还在争夺 | 破阵成果已经成立，剑的归属和同伴的脱离仍用真实回合处理；不假定敌人自动投降，也不恢复四剑大阵。 |
| 一名同伴先带剑走，其他人还在庭院 | 剑的成果保留，同伴的脱离仍要处理；不将持剑者传回去陪打。 |
| 取到剑后自愿交给可信的保管者，双方落实不复位 | 一样完成目标，交出是玩家选择；保管条件记在桌边，不能由名人单方面没收。 |
| 暂撤、被俘或放弃原计划 | 保存伤势、位置、俘虏和已发生的事，进入营救、换俘或重新谋划；没有原著规定的必死角色。 |

## 取剑之后，先让角色说一句话

小队完成本回，获得全队 **1,000 GP**，并升至 **11 级**。没有击杀也同样结算；战斗 XP 不再叠加升级，同一口剑不反复计功。未满足恢复条件时，升级本身不免费补满所有已消耗资源。

道行见到真剑，先问人是否都回来了，再问怎么取到的。他可以请求把剑借给后面的战事，也可以讲自己的看法，**玩家可以拒绝**。拒绝不扣已赚报酬，不让剧情停在“不同意就没有下一回”。

让四个人各选一句接话：

- 我本来以为最难的是________，结果是________。
- 这把剑以后绝不该用来________。
- 我想让________知道，我们做成了。
- 仙人们若再吵起来，我最想问他们________。

这是角色的想法，不会变成永久誓约惩罚。有人后悔、争辩或改变主意，也能继续演。

诛仙阵到万仙阵之间留出行军与休整，两阵不是同地同日。小队正常学习11级新能力；已经获得 Teleportation Circle 的人保留其已知目的地，新获得六环法术者按职业和准备规则选择，不因下一回有既定路线就禁用。

万仙阵的消息到来时，一名小队认识、仍活着且愿意联络的人可以先表达自己的立场：“这一次，我不想再进去。”没有适合的旧人，就由下一回的当地退阵者开口，不临时把一位玩家写过的亲人绑在阵里。

随后有人带来长耳定光仙的口信：

> “剑既然到了能自己拿主意的人手里，幡是不是也可以？”
