# 开团指南

版本：v0.7，2026-09-22。玩家可以直接读本页；没有后续冒险的谜底。前半约五分钟读完，末尾的空白笔记按需要填写。

## 你们来到怎样的世界

朝歌的命令越发让人不安，西岐却不断迎来新的投奔者。路上有拖着家当的百姓，也有带着师命下山的修行人。有人说神仙已经选好了天下的归属，也有人只关心明天能不能过关、家里还有没有饭吃。

黄飞虎归周的消息刚传开。你们还没有官职，也不必是名门弟子，眼下只接了一件事：把一小队旅人平安送过青蒲渡。

做得好，西岐会有人记住你们。做得乱七八糟，也可能有人记住你们。

## 做一个你愿意扮演的人

使用 D&D 2024 的角色创建规则，起始 3 级。任何职业都能找到位置：战士可以出身军伍，游荡者可以熟悉关津小道，法师可以学过仙门术法，牧师可以主持地方祭礼。职业不用改成某个神话人物的名字。

初次开团推荐：Human（人类）与现有职业、背景直接组合，人物最省事。想玩其他现有物种也可以，与主持人商量外形和来历；照选用的整套规则，不因写了“妖”“仙”就额外获得变身、飞行或免疫。

属性用标准数组或 27 点购点，整桌统一。初始装备用职业与背景的标准选项，先不额外发永久魔法装备。若选择起始金币方案，就按对应规则购买，不重复拿装备包。

### 从一个简单身份开始

| 想扮演的人 | 可以直接选用的背景 | 随手带入的一件心事 |
| --- | --- | --- |
| 退伍兵、护院、护送者 | Soldier | 有个旧同袍还在商军里 |
| 读书人、术法学徒、抄书人 | Sage | 师父说过一句话，你一直没弄懂 |
| 庙祝、祭礼学徒、照顾乡亲的人 | Acolyte | 你答应过护住一个人或一座村子 |
| 走私客、江湖帮闲、熟悉小路的人 | Criminal | 你欠了别人一次人情，打算换个活法 |

身份只是故事写法；背景的属性、专长、技能、工具和装备使用原条目。[官方背景](https://www.dndbeyond.com/sources/dnd/br-2024/character-origins)

### 写三句话就够了

1. 我来西岐，是为了________。
2. 队里有个人曾经________，所以我愿意跟他一起走。
3. 这趟路上，我最想保住的是________。

不用写长传记，也不需要熟读《封神演义》。知道哪吒、杨戬等名字当然有趣，不知道也不会缺少关键线索。

## 组队的共同理由

大家已经答应帮渡工陶七护送十二名旅人和两车口粮，报酬是全队 100 GP，抵达后由西岐接济处支付。每人选一个和这队人的联系：亲属在队里、受过帮助、顺路、想接下一份差事，或者单纯看不惯有人欺负他们。

有商军出身、截教关系或隐瞒来历的角色都可以。先约定一件事：这些关系带来好玩的麻烦，但大家愿意继续合作。无需用强迫队友内斗来证明自己的人设。

## 法术可以有封神味

会 Detect Magic 的人可以把施法描述为望气，会 Disguise Self 的人可以称作借形，会 Fog Cloud 的人可以说自己放出障眼雾。人物卡同时保留原英文法术名。

名称和外观可以变，法术效果、成分、消耗和限制照原文。望气不会顺带知道别人的全部身世，借形也不会自动变出新能力。

## 我们这一桌怎么玩

- 你可以谈、骗、绕路、求援，也可以打；说得通的办法，主持人会认真处理。
- 名人的出现会带来任务、线索或热闹，不包办小队的胜利。
- 没做到完美也继续玩：货丢了可以追，人得罪了可以谈，失败能变成下一段故事。
- 角色会受伤，也可能死亡，按 D&D 规则处理。封神榜不是复活保险。
- 不必照小说背答案。队伍改变了事情，之后就接着这个结果讲。

前六回的章节等级依次为 3、4、5、6、7、8 级，各回按故事收尾安排升级；第七、八回都用 9 级，第四幕整体收束后升 10 级。不是每一回都必升一级。这是本团暂定的章节升级安排，谈判、绕行等办法同样算完成冒险。战斗 XP 只用来帮助主持人编排遭遇，不另行叠加升级，也不会因离开同一场景再回来而重复升级。

第九、十回分别在10、11级行动，完成后依次升11、12级，再以12级进入最终一幕。新能力按职业规则取得，资源恢复仍需正常休息。取得物品时先了解其实际规则，小队再决定由谁持有、怎样使用。

第十一、十二回都保持12级，最后留出时间给每个人决定归处。完成这条主线不自动升13级，也不要求所有角色选择相同结局。想接着玩，可以带着仍然保有的装备和关系继续出发。

## 开场前聊一分钟

确认大家想要多少诙谐、多少惊险，以及哪些原著中的残酷桥段略过即可。默认是“有危险，但能互相打趣的英雄冒险”；血腥细节不必照搬。

准备角色卡、骰子和当前规则查询入口，就可以出发。

## 第一次上桌，先做这三件事

1. 把角色建到3级，记好实际选择的职业、背景、物种、装备和能力；施法者带上自己会用的法术原文。大家采用同一个2024规则口径，有问题当场一起查。
2. 用前面的三句话介绍角色，再告诉队友一件你擅长做的事。无需知道所有人的完整数值，知道谁会照料伤员、谁愿意先去说话就很够用。
3. 选出今天记线索、记公共钱物的人，也可以轮流来。每人自己记HP、法术位和有限次数能力；借出或用掉的东西顺手记一下。

轮到你时，先说想做什么、怎么做。主持人说明你能看见什么、何时需要检定；不必先从技能表里挑一个词才准行动。没想好时，可以请队友给个主意。

### 卡上这些名字怎么查

以下只是查阅入口，不替代动作与能力原文。一个场景里能做什么，还要看角色的位置、目标和实际条件。

| 本稿用语 | 原英文 | 什么时候翻这一项 |
| --- | --- | --- |
| 攻击动作 | Attack | 使用武器或徒手攻击时 |
| 魔法动作 | Magic | 能力或法术要求以此动作发动时 |
| 运用动作 | Utilize | 操作需要这个动作的非魔法物件时 |
| 协助动作 | Help | 想协助别人完成检定或攻击时，先看适用条件 |
| 影响动作 | Influence | 想通过谈话影响一个人的决定时；对方的意愿和条件仍然重要 |
| 躲藏动作 | Hide | 想隐藏行踪时，查看当时能否躲藏及如何处理 |
| 研究／搜索动作 | Study / Search | 前者侧重思考与知识，后者侧重留意环境；具体检定听现场说明 |
| 附赠动作／反应 | Bonus Action / Reaction | 查看能力是否允许使用，以及反应何时被触发 |
| 专注 | Concentration | 法术注明需要专注时，记下当前正在维持的法术 |
| 共鸣 | Attunement | 魔法物品注明需共鸣时，先查建立、结束与数量限制；拿在手中不等于已经共鸣 |

查询用[官方2024规则词典](https://www.dndbeyond.com/sources/dnd/br-2024/rules-glossary)、[法术正文](https://www.dndbeyond.com/sources/dnd/br-2024/spell-descriptions)与[装备规则](https://www.dndbeyond.com/sources/dnd/br-2024/equipment)。本团公开参考固定为[SRD 5.2.1](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf)；遇到同名旧版条目，先确认版本。

施法时把原英文名、目标、距离和所需成分一起说清楚。换成符纸、剑诀或祝祷等描述很有趣，实际消耗和限制仍照原条目。
