# 第五回：风里带回的消息

四名 7 级角色 · 约 2～3 小时，也可与入阵连玩 · v0.7 未测试草案。

这回让小队决定怎样破风吼阵。先见人、看现场、找帮手；顺序由玩家选择，不要求清完三项清单才准入阵。需要的原卡只有 Gargoyle，以及真有必要记录行动时使用的 Scout、Commoner；完整出处见 [第三幕规则备忘](../research/ACT3_RULE_NOTES.md)。

## 本幕到底交给玩家什么

十绝阵已经成为西岐城外的新威胁。其他阵各有人应对，**风吼阵及它堵住的北口道路由小队解决**。任务完成后，这座阵就真的结束，不会再揭露“你们只拆了一个没用的外壳”。

第五回弄清入口、守阵者与可行办法，第六回落实行动。总委托报酬为全队 600 GP，撤阵或打开安全通路后结算；找人、看阵不再各付一笔相同报酬。另有一条标准 Rope of Climbing 在本回交给小队使用并保留。

### 用前面的结果开场

| 已发生的事 | 这回怎样开始 |
| --- | --- |
| 求援送到沈砚 | 他联系的勘路同伴顾行舟带着损坏木片到接济处。入口位置、失联者姓名与大致见闻，开场就能问清 |
| 求援未送到或小队放弃送信 | 西岐另一名车工带来信使冯迟失联的消息，最后见到他在回风石场。顾行舟因当地风阵传闻自行到场勘察，如今在阵外白石亭；车工知道去亭子的路 |
| 鲁青和帮手已回城 | 鲁青愿意看木片、修普通梯板；她不懂所有仙术，不能一看木头便给出整座阵的答案 |
| 鲁青或帮手仍被扣，而且还活着 | 尚被扣的人已被调到回风石场做台架。他们与冯迟一起等待离开的机会；本回可以接回，不要求另开支线。已死或另有明确去向的人不凭空出现 |
| 青石驿传令路线已查清 | 送簿岔路通向白石亭一侧，小队认识这段路；去亭子不用绕到敌营前问路。未查到时由车工带路，多花半小时即可 |
| 许照愿意与小队往来 | 可以托他看一次报告。他指出“会动、会选目标的风，要先当对手看，别只找一只风箱”，不跟队代打，也不凭空知道董全的全部底细 |

过去的成败改变便利与关系，不决定玩家还有没有资格进入主线。

## 开场：这次不是去替神仙试刀

> 程简桌上摆着一截带着灰尘的栏木。木头裂了，绳孔还在，旁边是一张被改了三遍的草图。
>
> “这回来的是风。能拐弯，还知道堵路。”
>
> 他把另一张军中文书压在图旁：“但上头说了，能谈便谈，能绕便绕。没有哪条军令写着非得先死个人。”

程简经手转交姜子牙授权的本路撤离条件：**董全返还被扣平民与征用物，拆旗撤出北口道路；小队可护送他和幸存从者携带私人物件到东山口，当日该路西岐军不追击。** 这是具体路段的通行保证，不是承诺全线停战，也不是程简自己有权号令全军。第六回若换了一天，军中更新当日文书即可，不追加筹码任务。

喜欢见名人的桌，可以把递文书改成姜子牙当面交代。他会回答三件事：路通了确实有用；对方若依约退阵就守约放行；小队提出的具体方法由小队做主。他不知道每一只风灵想什么，不把答案念完才放玩家出门。

### 三处地方，先去哪里都可以

- **顾行舟的报告。** 求援成功时在城内，失败时到白石亭见他。能得到目击细节、翻译帮助和攀云绳。
- **回风石场。** 冯迟和可能尚被扣的熟人在这里，距白石亭约半小时。能救人，取到他画的板台图与抄下的约定。
- **白石亭与阵外观察处。** 可直接看到北口阵场的道路和板台；亭子到真正阵场约半小时。能亲自确认入口、旗号与守阵者的行为。

回风石场是阵外的工作地点；第六回北口阵场是另一处旧采石场，两者相隔约一小时路程。两处不要画成一张混战地图。白石亭位于战区外，供行人歇脚，能安排正常短休；长休可回城或栖霞观，时间按实际赶路计算。

## 一、顾行舟：我看见的，和我猜的

顾行舟用 Scout 原卡。其可选的一种额外语言选为 Primordial，能与风灵和石像鬼交流；四种方言可以互通。他的这项知识来自学习，不是给 NPC 临时补一项万能能力。

他没有负伤到无法说话，也没有关键时刻忽然失忆。让他把事实与猜想分别说清：

| 他确实看见或听见 | 目前不能据此断定 |
| --- | --- |
| 板台边有执黑幡的修者；幡起以后，两个风中轮廓各守一边 | 幡布本身就是无限力量的法宝 |
| 两个轮廓会转向、追近处的人，也会停下来听呼喊 | 整片空地每一步都在受到同样的伤害 |
| 风中传来的话提到“守这一场”“北面留路”；他懂这些话 | 董全能不经同意永远控制它们 |
| 栏木被冲击震裂，尘沙和碎片从它旁边飞过 | 第一个进去的人必须被献祭，后面才安全 |

顾行舟的笑话：“我学这门话，本来想问山里的石头哪边好走。如今石头先问我带了多少钱。”

两种流言已经在城外传开：一派说这阵靠固定机关，一派说风会闻见人的气息、进谁都一样。玩家不必选一个信。实际危险来自两只会自主行动的风灵和一位施法者；提前说清这一点，玩家才能据此侦察和准备。

鲁青若在，或角色花时间查看木片，可以直接看出它来自普通栏杆，绳孔没有锁扣。智力（调查）DC 13 可进一步辨认拆装方向，在画板台时标出系绳侧；失败也能从冯迟的图或到现场观察得到相同关键信息。不把“找对一个技能”设为破阵门票。

### 顾行舟能帮多少

他愿意跟到白石亭，或在明确停战的阵门外翻译对话；不会自愿站在风灵中间替玩家吸收攻击。小队若自己懂 Primordial 或有合适语言法术，可直接谈。他进入危险区域时按原卡和真实位置行动，不提供隔着整座山谷的免费传话。

Comprehend Languages 能帮助听懂，不能自动让对方听懂回答。Tongues、懂对应语言的同伴与双方已明白的图画手势，按各自实际能力处理。复杂的停战条件不能靠“我挥挥手”自动完整传达。

### 一条值得拿出来用的绳

顾行舟拿出沈砚为勘路准备的 **Rope of Climbing**，当地叫“攀云绳”。沈砚事先让他交给真正需要入险接人的人，因此本回见面即可把绳交给小队，作为团队物品保留；不用先欠一笔神秘人情债。只有这一条，第六回不再重复发。

这是标准 Uncommon 奇物，不需共鸣，长度 60 尺、承重 3,000 磅。持一端用 Magic 动作指挥另一端移动，首次及之后每次使用者回合开始各移动 10 尺，能按条目系牢、解开、打结等。打结后长 50 尺，借绳攀爬的属性检定有优势。其余限制、AC 与 HP 见 SRD p.242。

它能把绳头送上台架，不会瞬间把所有人拉上去，不会捆住任意敌人，也不是原著定风珠。先让玩家试着命令它系上亭柱、打结，再讨论行动，通常比念一段长说明容易记。

## 二、回风石场：两个石头讨工钱

冯迟来取板台资料，被两只石像鬼扣住。他把自己看到的旗号约定也抄了下来，准备带回去；石像鬼觉得留着送信人能逼人把欠下的看守钱结清。

这两只 Gargoyle 外号“脊角”和“缺耳”，只懂 Primordial（Terran）。外号可由顾行舟翻译；它们并不会为了说笑突然都会 Common。它们对人没多少同情，但很在乎拿到好处、保住自己，不愿为董全无限加班。

它们要的是 **60 GP，付一次便放走所有在场被扣的人，并退出这次守阵**。两只事先已分好了钱，交给其中一只就算结清，不在玩家付款后突然一只再要 60。小队也可以通过翻译提出：现在放人、放弃守阵，允许两只带走自己的普通物件，退到远离两座场地的山坡；小队不追猎它们。这个承诺只约束玩家自己，不冒用军中文书保证全线安全。两只对不付钱的办法犹豫，按 Influence 的魅力（说服）检定与当前态度处理，默认 DC 为 15 或智力属性值中较高者。

两只起初对谈交易者为 Indifferent。玩家已明确打算赶走或伤害它们时才变 Hostile；拿走自己人不代表必须接受勒索。不同办法带来真实结果，不因未付钱就强迫战斗。

### 一眼能画的石场

工地东西宽 90 尺、南北长 60 尺，四周开放，没有围墙。

```text
北：缓坡通上层台架，宽10尺，长40尺
           ┌──────────────┐
           │ 上层20×20尺  │  冯迟与尚被扣的工匠
           │ 高出地面20尺 │  内有可系绳的完好木梁
           └──────────────┘
            缺耳在台架东侧

    西侧石料堆       脊角在空地       东侧旧工棚
    高5尺可作掩护                     木梯放在棚内

南：来路与集合处，再走约半小时到白石亭
```

台架是小块石台与普通木架组成的工作平台；从地面到上面可走北缓坡，也能取工棚里的 20 尺木梯或用绳。台上木梁完好，能够承受本场景普通人员攀爬；不是玩家一系绳就断的暗雷。缓坡没有锁门，守卫只是会察觉直接下坡的人。

玩家从南侧到工棚约 40 尺，工棚到台架脚约 20 尺；上层人员能隔空交谈。石料堆按实际遮挡提供半掩护或全掩护，不是满场难以移动的碎石地形。陡边确实有 20 尺落差，跌落按正常规则；北缓坡没有坠落危险。

冯迟和普通工匠用 Commoner 卡，仅在确有危险时记先攻与伤势。他们能自己走路、爬合适的梯绳，不要求每名玩家各消耗一个回合“操作人质”。战斗中仍各用自己的移动和动作，别一次检定把所有人传送到集合处。

### 不给钱，也不一定要打

一部分人可以在南边谈话，让其他人带梯或绳接近台架；只要确实离开敌人视线、满足条件，就依 Hide 与正常察觉处理。也可以从北缓坡接人，借石料堆遮挡，或用正常能力引开守卫。飞行能跨过高度；隐形不自动消除声音，但这两只也没有看穿一切的感官。

鲁青若在，会提醒同伴先把自己做的普通工具带上；若工具太多，可以留在工棚以后取，不为搬一箱锤子卡住撤离。被救的人最看重能离开，不会为了等“完美营救姿势”拒绝已经安全的出口。

两只静止时确实像石兽，但新版 Gargoyle 没有 False Appearance。本场景开头它们正在活动，直接告诉玩家这是有生命的守卫；不能临时宣布没过某个检定就永远看不出。

### 动手时只放这两只

两只 Gargoyle 合计 900 XP，低于四名 7 级角色低预算 3,000；这是可以迅速处理的外围阻碍，不是必须榨干资源的主战。

它们利用飞行与 Flyby 攻击近处威胁，想逼玩家退开、保住勒索机会；不追杀已经跑远的工匠。Flyby 只在按卡飞离触及时避免借机攻击，不等于它们移动和行动都不受任何限制。

任一只进入 Bloodied，或所有被扣的人都已脱离它们能控制的位置时，另一只会叫着撤走。接受停手后双方真停手；玩家继续追杀，就继续正常行动。它们不会因少付工钱而凭空变身、召来第三只或刷新 HP。

没谈成且活着逃走的石像鬼可能退到主阵，加入第六回；已经明确约定退出、被俘或被杀的就不出现。保留真实伤势与后续是否有时间休息的事实，不在转换地图时自动恢复。

### 冯迟手里有什么

他最想说的是：“我不是没送信。我送到一半，石头嫌我工钱没送到。”

安全下来后，他交出板台图与 Common 字抄件：**黑幡升着，风灵守这一场；黑幡降下，这一场即结束，不论是谁降幡。双方约定北面留出口，散场者不受追杀。** 他看到董全和风灵用已经说好的手势确认过，明白这是一场有边界的约战。

这份抄件没有控制魔法。旗降要让风灵实际看见，风灵按自己的行动离开；它们不会被纸上的字直接驱散。董全也要遵守这场约定，不能让玩家成功降幡后再补一个必须死斗的阶段。

图上板台高 10 尺，北侧有台阶，挂幡绳扣在南缘；普通挂扣可以接近后操作，台后与石墙之间也有路。详细尺寸照第六回地图。冯迟不是唯一知道这些事的人；即使资料毁了、没救到他或大家跳过石场，阵外仍能看见这些布局，也能直接问风灵或董全。

## 三、白石亭：真正看一眼再做决定

白石亭不在法术范围内。沿亭外小路前行，到北口阵场的外围观察点，就能看见第六回标出的西门、南缺口、北出口与台上的黑幡。正常观察不要求先跨进风灵的攻击范围。

主持人先向玩家展示第六回地图的地形与看得见的守卫位置，再说明距离。尘土、风声和飞动碎片提供气氛；没有隐藏的全谷持续伤害。两只风灵的具体攻击、移动、免疫与抗性照 Air Elemental 原卡，不能因为小说说得厉害而叠加无豁免风刃。

至少交给玩家三个可用事实：

1. **危险会移动。** 两个风中轮廓各有位置，追人要移动，攻人要用动作；贴近其中一个不是同时触发整座山谷。
2. **通路不只有门。** 南侧缺口、北道和板台台阶都真实存在；石墙挡视线，风灵却能从小缝绕进来。墙能改变路线，不保证永远隔绝所有敌人。
3. **守阵也有约定。** 在阵外喊话、由顾行舟翻译，董全允许一次明确的观阵交谈。玩家问及散场条件时，他公开承认降幡的约定；风灵也能确认北路必须保持可撤离。

这里有一段真正停战的说话时间，不因主持人想展示伤害突然偷袭。若玩家借观阵主动动手，按实际位置掷先攻，之后的态度由发生的事决定。观察不提供免费攻击轮，也不要求玩家承诺从此不与商军为敌。

### 风灵想走，董全为什么还摆阵

风灵愿意履行已经答应的一场守备，不愿被当成永远不许回去的工具。董全为了同门和闻仲的情面而来，也在乎自己的约定。他愿意听一个能够交代人情、又不把同行耗死的退场办法。

军中文书提供了实际退路，小队可以加上一句双方都能接受的公开说法：“此路约战已毕，各自收兵。”条件仍包括交还平民与征用物、拆旗撤路，不是用一句夸奖便使他服从任何要求。具体成交、风灵另行解除约定及战斗办法，接第六回。

让玩家知道全部方向以后再选：交涉、接近幡扣、远程处理确实能看见的普通挂幡，或迎战守备都可以。不要把已经可用的飞行、语言或工具临时封掉。

## 把计划说给同伴听

回到亭子，用五分钟决定谁先做什么、以什么为成功、在哪里集合。可以拿 [玩家手札](10_第三幕_玩家手札.md) 写几句；没有准备点、优势点或必须累计几次成功的规则。

| 拿到了什么 | 第六回具体能用的事 |
| --- | --- |
| 顾行舟的报告与翻译 | 辨认真实施法者、向风灵提出能被听懂的条件；不会把风声全当成无差别陷阱 |
| 冯迟的板台图 | 从一开始知道普通系绳扣与北台阶的位置，可以计划接近与撤离 |
| 石像鬼已退出 | 主阵确实少掉对应敌人，不补新的怪来凑预算 |
| 攀云绳、鲁青准备的普通梯板 | 依法操作和攀爬；好工具能让简单行动直接可行，不额外送免疫击退 |
| 本路撤离文书 | 有可兑现的停战条件，董全不必拿性命赌一句空口保证 |

若第五回的找人、侦察和计划已经有了结果，队伍回到可安顿处后升至 **8 级**，接 [第六回《风吼阵前》](09_第六回_风吼阵前.md)。可以把两回安排在两个晚上；若合玩，照正常规则完成休息和升级安排，不把升级当作战斗中即时回满所有资源的按钮。

玩家若选择直接进阵，先给已能直接观察的事实，明确这条准备线已结束，按章进入 8 级阶段；不扣住升级逼他们做满三处。失联者仍需继续救，未取得的情报不凭空自动拥有。

### 没救到人或暂时撤走

冯迟和仍被扣的工匠留在石场，守卫用活人换钱，不在玩家一次交涉失败后立即处决。可以稍后回来，或在撤阵协议里要求一并交还。若敌人已离场而人还在，重新接人可以顺利完成，不刷新另一队看守。
