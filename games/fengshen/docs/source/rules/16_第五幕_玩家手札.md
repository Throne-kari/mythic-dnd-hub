# 第五幕·玩家手札

v0.7草案。配合 [北门摘剑](14_第九回_北门摘剑.md) 与 [幡下各有归路](15_第十回_幡下各有归路.md)；主持按实际知情阶段摘发。下列说明不增加角色能力，没有看见的布置不提前画进玩家地图。

## 一、北门这一路，交给你们

发放：第九回出发前，道行已经介绍计划时。

> **四方悬剑**
>
> 东门诛仙，南门戮仙，西门陷仙，北门绝仙。
>
> 另外三路已有安排。等三剑离位的消息传来，北门便是最后一路，由诸位自己决定怎样摘剑。把真剑移离剑架，这场阵便破了；里面的守卫仍须照常避开、谈退或应对。
>
> 阁里没有必须由谁念的口令。剑取下以后，可以带走，也可以商量交给谁保管；借剑不是领报酬的前提。
>
> 阵外北坡是原定会合处。走别的路也可以，先跟同伴说清：我们在哪里碰面，谁带没能马上出来的人。
>
> 道行

任务说明：本回完成后全队1,000 GP；收束后升11级。下一回另有1,000 GP任务，不把两回报酬重复加算。

**真绝仙剑在本团的使用规则，出发前即可知道：** Weapon, +3（Longsword），Very Rare，无需共鸣；军用近战武器，伤害1d8挥砍，Versatile双手1d10，重3磅。该武器攻击检定和伤害掷骰各+3；熟练、精通Sap及其他长剑规则照原条目。它不自动赋予熟练，不附带全场即死或远距杀神，也不会在取得后变成假剑。

在有人说明守卫能力后再摘发：

> 石像的手能朝120尺内射出力场。它使人迟缓的法术有专注，可以解除；看到它没有念咒、手势或材料，不等于法术没有生效。

玩家可添自己的观察，不在图上预印未发现的隐形守卫位置。

## 三、两封不必选同一个答案的消息

发放：第九回后正常休整，准备进入万仙阵时。两阵之间经过实际行军与军情推进；消息不表示NPC瞬间从别处赶到身边。

> **长耳定光仙的口信**
>
> 我手里有六魂幡。上面写着六个人的名字，有人要我等号令便用；现在又有人要我把它带回去。
>
> 我还没想好该跟谁走，只想先把“听令”二字从自己嘴里拿开。听说你们取了绝仙剑，还能自己决定把剑指向哪里。
>
> 来断壁石沟见一面。若不愿意带走幡，也可以来听我把话说完。

另一封从真正可联系的旧友中选。董全、韩变、沈砚或玩家自己的师门联系人，只有在仍活着、愿意说这番话且有实际传递办法时署名；否则交给已经离开险地的当地退阵者许苓。

> **一个准备离开的人**
>
> 我不是来劝你们替谁认错。阵里有我认识的人，我不能当作没看见；可我也不想每次有人喊同门，就必须把命留下。
>
> 若你们进去，替我听一句真话：他们到底想做什么，又有什么是已经不愿做的？
>
> 我自己的决定是________。若散了，希望在________见。

这两封话不强迫队伍同意任何立场。每位玩家可以说出自己最想当面问的一句，然后带着问题去见人。

## 四、幡柄上真正能用的法术

发放：长耳当面说明、完成适当鉴定或已得到可靠说明后；使用或决定摧毁前须把真实限制讲全。

**六魂幡采用一件完整Wand of Fear。** 小幡柄是魔杖本体，幡面与六条布尾是外观。Rare，需共鸣，不要求使用者是施法者；持握使用，法术豁免DC15。

| 项目 | 本团实际用法 |
| --- | --- |
| 充能 | 最多7；此刻剩余由实际使用记录填写：____。 |
| 1充能 | 施放Command，只能选Flee（逃离）或Grovel（伏倒），一次针对符合范围的一个目标，按完整法术作豁免。 |
| 3充能 | 施放Fear，锥形改为60尺；需要专注，至多1分钟。锥形内符合条件的生物都会受影响，不按六个名字挑人。 |
| 恢复 | 每次黎明恢复1d6+1充能，至多7。 |
| 耗尽风险 | 花掉最后1充能时掷d20，结果为1，魔杖化灰。这是原物品风险；留着最后1充能不用便不触发。 |
| 换人 | 抢到、接过或放进背包不等于完成共鸣；按正常短休共鸣，不能立刻替旧主人使用。 |

Fear会让失败者丢下所持物件，沿最安全路线远离施法者，不命令目标跳崖或冲进火墙。它可以被正常驱散，也会随施法者失去专注结束；夺走幡不会自动解除已经生效的Fear。完整法术的动作、路径、状态与重新豁免条件仍按规则。

这面幡上写着老子、元始、接引、准提、武王、姜尚。在本团，它们是报复的誓名，**不会定位这些人、越过距离施法或自动杀死他们**。撕掉名字可以表达决定，但不等于已经毁掉完好的魔法幡柄。

> 长耳说：“你若要把它收起来，就收起来。若你要用，先想想自己究竟想让谁害怕。”

另一件事先约定的报酬是 **Cape of the Mountebank**，与是否保留六魂幡无关：Rare、无需共鸣，穿着后以Magic动作施放Dimension Door，使用后下个黎明恢复。至多500尺，可带施法时5尺内一名自愿生物；落点与失败后果按原法术。烟留在离开处，轻度遮蔽至使用者下回合结束，不是无限传送或永久烟幕。
