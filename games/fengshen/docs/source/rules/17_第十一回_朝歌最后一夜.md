# 第十一回：朝歌最后一夜

第六幕《朝歌之后》前半 · 四名12级角色 · 主持草案 v0.7 · 未测试

朝歌的外城门已经开了，午门仍然关着。街边有人把店里的灯重新挑亮，又有人把门闩插回去。大家都在等：天亮以后，还要不要再打一场。

三妖准备在今夜袭击周军后营。她们想趁城中尚未安定杀出一个缺口，让围宫的人退却，然后再决定留在宫中还是逃走。小队得到消息时，行动还没有发生。

**本回目标：让这次夜袭停下来，让后营不再暴露于突然袭击。**截住三妖、谈成撤袭、制伏她们，或先把消息送到、切实撤空目标并使她们放弃此次出击，都可以做到。斩杀人数不是完成条件，追杀到另一个位面也不是任务的隐藏下半场。

完成后小队合计获得 **2,000 GP**。战前另有两瓶标准英雄药水，不从报酬中扣除。两回终幕都保持12级；第十二回负责尾声，不再次发这份钱，也不自动升13级。

## 开场：熟人把最后一盏灯递过来

从前五幕选一个确实活着、愿意联系小队的人，带来消息。默认是程简；也可以是阿禾、玩家的师门联系人，或另一块传讯石的持有者。没有这一位，就用正在办入城安顿的普通军吏，不把失踪者突然写成平安归来。

> “我本来想问，明天给诸位煮什么粥。”
>
> “宫里有人报信，三位娘娘披了甲，正在往西偏道来。后营还以为今夜只等开门。你们离得最近。”
>
> “这回想怎么收场，由你们去谈。只求那边的人能好好等到天亮。”

消息包括三个可直接相信的事实：三妖将从宫墙西侧的官桥前庭经过；前庭西面的街道通往后营；营中正在拆卸白日的接济棚，尚不知道此次出击。宫中报信者亲耳听见并看见了准备，联系人转交的是这份见闻，不要求玩家再过一项辨谎检定才能获得冒险入口。

这里的官桥是旧街名，前庭没有必须升降的桥或关门机关。午门在这幅局部地图以外，打完本场不等于全城每道宫门同时打开。

给玩家一段真实的准备时间。消息是三妖整装时送出的，小队可以换武器、分药水、传一则短讯或先赶去观察；需要长休、长时间仪式或漫游全城的计划则会让局势继续发展，先说明所需时间，不暗中宣布所有准备已经来不及。上一幕之后有正常行军与休整，并非前回斗法一结束就强制接战。

## 战前就给出的准备与权限

程简有本次军中授权：小队可接受三妖停止夜袭、暂时停战或自愿接受看管的条件，并将具体处置留到天亮后当面商议。他能保证本次接收期间不以交出兵器为由立即处死对方，不能许诺替天下所有受害者免除她们的一切责任。若此前换成其他联系人，仍由程简或已建立的实际军务渠道送达这项授权。

交付小队合计 **两瓶 Potion of Heroism（英雄药水，Rare，无需共鸣）**：饮用或喂给另一生物花附赠动作；饮用者得到持续一小时的10临时HP，并在这一小时处于无需专注的Bless效果。攻击检定和豁免加1d4，不加所有属性检定；同名Bless不叠成2d4，临时HP也不相加。没喝的药水留下，不因本回结束作废。

军中普通军械可供挑选矛、短弓与箭等现有普通武器，每位角色可借一件自己想用的武器及通常所需弹药，记录品种；不另造专门克妖神器。熟练、射程、装备占用和武器属性照规则。绝仙剑依然是造成挥砍的+3长剑，不能临时描述成“刺一下”就换成穿刺。

一位此前与妖术交过手的斥候已把这些观察交给小队。直接给出可操作的信息，不设必须先受骗一次的门槛：

| 已知情报 | 玩家可以据此做什么 |
| --- | --- |
| 妲己极难被术法直接命中、恐吓或魅惑；她没有抵挡普通刀枪的普遍免疫 | 普通武器照常有效。用Bless配合武器穿刺可打中她的弱处，英雄药水是真正的Bless效果 |
| 她的魔抗不替同伴挡术，也不消除对友军的祝福 | 支援、治疗、移动同伴、改变地形、对付另外两妖，都有实际价值 |
| 三妖都披着人形幻象；另外两妖真实身体很大 | 留意实际占位、脚步和碰到东西时的错位；看穿幻象不会自动驱散她们 |
| 妲己能离开此界，但不能任意带走不愿同行的人 | 不用把每个被她碰到的同伴都当成即将被强制掳走；她逃走和她投降是不同结局 |
| 她的爪伤会留下不能从休息受益的诅咒 | Remove Curse可以真实解除；当场说明中了什么，不等大家空耗一次长休才揭露 |

若玩家要先联络后营，普通跑腿、Sending或已安排好的Sending Stones都可用。传讯石沿用真实持有人和整对每日次数，不能凭空在程简手里多出第三块。Sending的目标条件与25词限制照2024法术，不改成25个汉字。

前庭已经没有平民，不新增一队老朋友供三妖挟持。后营的人是否收到消息另行记录。墙外的大军负责其余方向，没有每轮进入本图的无限援兵，也不在小队倒下时自动击杀本图敌人补完目标。

## 三妖各自想听见的回答

第一次看见她们时，读一小段即可：

> 王贵人抬头看了一眼熄了半边灯的长街：“这里从前夜里也有人唱曲。”
>
> 胡喜媚说：“你现在还想着听曲？”
>
> 妲己没有接话。她看着挡路的人，看见那把剑，或者认出了曾经在关前守约的名字。
>
> “好。最后又是你们。今日准备给我们留哪条路？”

“认出”来自近来的军中传闻和眼前见闻，不让她无条件读取玩家秘密。若队伍从未公开露面，她只将其视为阻路的高手。

**妲己**想挽回败局，同时给自己保留最后的退路。她会用“你们也替仙家做过事”试探小队是否愿意听她说话，但这句话不能免除她对自己选择的责任。她不接受当场献首或自杀，也不会因一次高骰点就终身服从。她可能接受：此次不再袭营，带愿意同行的姐妹退出这片战场；或在明确暂不处死、天亮公开议处的条件下，自愿留下接受实际看管。后者通常需要玩家展示确实有能力拦她、并给出可信的履约办法；说空话时她仍可拒绝。

**胡喜媚**不愿当最后被丢下的人。她会直接问：“我们若放下手，谁准你们的军士再动手？”给她看本次真实授权、当面联系能接收的人，或同意小队亲自留下见证，都能影响她。若另外两妖已答应停止出击，她不坚持为面子独自继续；她也可以拒绝跟妲己去陌生位面。

**王贵人**已经想走。她最先接受真正可走的南街或一份有期限、有去处的停战安排，不要求玩家替她恢复宫中地位。若玩家把她的退让当成开打信号，她会自卫；若允许她退出，便从此夜袭中实际退出，不在下一轮换装回来。

以下方案给主持人判断用，不是逐项盖章的流程：

- **有条件停战。**说清今夜不再攻击后营与城中退离者，先在前庭等待，还是由谁接往何处；小队同时把停战与识别办法告知己方。对方真的同意就执行，不在握手时强塞一个“本来就要背叛”的伏兵。
- **退出此战。**允许她们沿约定道路离开，或让妲己以自己的法术带自愿者去另一个位面。此夜威胁停止，人物去向与尚未追究的责任保留到尾声。小队没有许诺永远无人找她们，也没有因此获得永久控制她们的权力。
- **分开谈。**一人退出，不迫使另外两人立刻退出；也不强迫先退者必须回头替小队杀姐妹。实际战斗名单随之改变。
- **使夜袭失去目标。**如果后营已经撤空、道路被依法隔开，或可信消息让三妖知道偷袭机会已失，给她们重新权衡的机会。这里没有藏着另一份“真正后营名单”。

只在对方仍犹疑、结果确有不确定性时用Influence。依2024规则处理态度、理由与DC，不规定连掷三次才算说服。玩家可以问她们愿意接受什么，也可以明确拒绝放行，进入冲突。

## 交锋：强项公开，办法不只一种

默认敌人是三名真实人物：**妲己完整采用Rakshasa，胡喜媚与王贵人各完整采用Lamia**。合计12,200 XP；四名12级角色低／中／高预算为8,800／14,800／18,800 XP。只作编排参考，尤其妲己的抗魔和诅咒会明显影响不同队伍，未据此宣称平衡已验证。

| 对手 | 上桌要点 |
| --- | --- |
| 妲己／Rakshasa | Medium Fiend；AC17、HP221、速度40尺。动作三次Cursed Touch：+10、触及5尺，各2d6+5挥砍＋3d12黯蚀；命中生物即施加不能从短休或长休获益的诅咒。Baleful Command动作、充能5–6：30尺内每个敌人作感知DC18，失败8d6心灵并恐惧、失能至她下回合开始。成功无所列效果。免疫魅惑与恐惧 |
| 胡喜媚／Lamia | Large Fiend；AC13、HP97、速度40尺。动作两次Claw：+5、触及5尺，各1d8+3挥砍＋2d6心灵；其中一次可换Corrupting Touch，5尺可见一个目标感知DC13，失败3d8心灵并受一小时诅咒，期间魅惑、中毒。附赠Leap花10尺移动跳至多30尺 |
| 王贵人／Lamia | 同上，独立HP、法术次数与选择。没有和胡喜媚共享伤害或共同死亡的机制 |

完整感官、技能、法术与边界见[第六幕规则备忘](../research/ACT6_RULE_NOTES.md)。两名Lamia没有原卡飞行、抗魔或复生；九头、雉羽和玉色是外观，不产生九次攻击或变成物件的豁免。她们可以用Disguise Self显现为中型两足外观，真实身体仍是Large。妲己的真身是中型狐首直立妖躯，幻作女子；她没有真变成小狐狸钻缝的能力。

妲己的Greater Magic Resistance按新版完整使用：对法术及其他魔法效果的豁免自动成功，法术攻击自动失手；未经许可，不能用法术远程观察她、读思想、检测类型或阵营。**不是“六环以下全免”，也不是所有法术皆无效。**成功仍受半伤的法术照常造成半伤；Magic Missile满足可见、射程等条件时正常伤害，她原卡没有Shield。妲己被伤害打断专注时仍按专注规则进行，不把抗魔扩大成所有体质豁免自动成功。

受Bless影响者以武器造成的穿刺伤害触发她的弱点。判断每种伤害分量，不把武器上的火焰、其他附加伤害或长剑挥砍一并翻倍。没人使用这个弱点也可以正常作战；弱点是有帮助的办法，不是唯一许可伤害她的钥匙。

施法者还有清楚的选择：

- Bless、治疗、移动、掩护和战场分隔作用在真正的目标上；她不会一靠近便消去同伴身上的有益法术。
- 两名Lamia正常接受合法的控制与伤害。六魂幡的Fear可影响她们，不能影响妲己；锥形范围也仍要考虑队友。
- 三妖都是Fiend，Hold Person、Charm Person等限定Humanoid的法术不合法。Banishment可正常对两名Lamia使用；专注满一分钟按2024类型规则送往相关位面，妲己对其豁免自动成功。
- True Seeing在近处看透幻象；Dispel Magic可结束实际Disguise Self、Fly、Invisibility或Major Image，不删除怪物特质。Counterspell使目标作体质豁免，妲己对此自动成功，不能许诺它必能阻止她离场。
- 攀云绳、绝仙剑、传送披风等按实际物主和剩余次数使用；本图没有临时追加的禁飞、禁传送或所有物品失灵区。披风在出发位置留轻度遮蔽烟雾，按Cape of the Mountebank原条目处理。

三妖的施法照正常时间、成分与专注。妲己随意的幻象与每日各一次的Fly、Invisibility、Major Image、Plane Shift各有用处，也各花真实动作；两名Lamia各有每日一次Geas、Major Image、Scrying。**Geas施法一分钟，不能当成瞬发接管玩家。**Corrupting Touch的魅惑也只按状态行事，不让主持人任意接手玩家角色。

## 对手怎样行动，什么时候可以停

不要规定她们必须活到第三轮才能谈，也不设血量到零仍继续念台词的阶段。

妲己优先逼退挡路的高手，敌人聚在30尺内时会考虑Baleful Command；近身交手时使用Cursed Touch。她会认出眼前明显的祝福与穿刺威胁，尝试换位、借掩护或攻击施加祝福的人，但不自动知道谁准备了什么法术。她若要同时用Fly与Invisibility等专注法术，照正常专注限制选择，不能都保留。

胡喜媚用Leap越过石槽或拉近距离，试图让一人陷入Corrupting Touch诅咒；她不会因为施加魅惑就能命令此人转身砍队友。王贵人更愿意沿石台与南街保留退路，可以用Major Image制造岔路上的动静，但幻象没有真实伤害、掩护或实体墙的阻挡能力。

当妲己降到约70 HP、两名姐妹都已退出，或突袭目标已经撤走时，她会明确提出退战条件或准备离开。这是她改变主意的时机，不是无论玩家怎样行动都必定逃走的过场。胡喜媚与王贵人到约25 HP时各自优先考虑停手或撤退；能谈时，让她们出声。

妲己的Plane Shift每日一次，花动作，可与至多八名手拉手成圈的**自愿**生物同行。她必须真的走到愿意同行者身边并完成施法；不能从全图点名收走姐妹，更不能带走不愿去的俘虏。角色的真实控制、失能、无法满足施法条件等可阻止她正常施法；不为保证逃走而忽略它们。已经使用的每日次数照常记录。

若在Nine Hells之外死亡，她依原卡立即在Nine Hells获得新身体；朝歌的身体化去。这不在原地补第二条血，也不把“本地击败”伪写成永久灭绝。她没有此时立刻回朝歌的附加能力。两名Lamia没有同样的复生条款，死亡按实际结果记。

玩家想留活口时，在合法近战攻击本应将目标降至0 HP时，可按2024击昏规则改为1 HP并使其昏迷；不要把任意远程攻击或法术都默认改成击昏。昏迷之后的绳索与看管也不是永久封术：妲己若恢复、仍能满足施法条件且留有Plane Shift，普通捆绑不保证长期关住她。最可靠的停战是明确的自愿安排，或角色确有的有效能力；没有隐藏赠送一副全能封妖镣。

Remove Curse能解除本场Cursed Touch、Corrupting Touch及合法持续的Geas。玩家有此术便可照常处理，不附加杀死施咒者、拿到原著葫芦或求女娲到场的条件。没有资源时如实记录，并在第十二回正常找已有可得的帮助。

## 如果先报信、撤离，或三妖闯过去

后营距离西街约500尺。到达前，玩家仍能传讯、移动、追赶、阻路或改约见地点。进入战斗后的行动按实际轮次与速度处理，不以“离开地图”省略玩家还能做的事。

**消息及时且目标确实撤开：**程简组织营中人员按已有南侧通路离开，拆卸中的器材可放下，人可以先走。一次明确传讯足以启动这个安排；是否来得及取决于双方实际位置与行动，不额外要求盖印原件。三妖见营中已无可突袭的人，默认放弃本次袭营，转而考虑撤离。小队完成了这次任务；如果还想追究三妖或保护留下的器材，是自己的下一步选择，不强加一场补考。

**只有一两人被阻下：**保留已经退出的对手；仍出击者继续按自身速度与行动前进。小队可以追、先通知后营，也可以接受这次只拦住部分人的结果。不会让已被俘的人在营里重新出现。

**队伍撤退或未能拦住：**三妖继续走向后营，小队有机会发出迟来的警告。若确实让突袭发生，把实际受影响的人、物资和现有救援条件写清，再让玩家决定救援、追索或停下；不临时指定一位全程不在场的旧友必死来惩罚失败。该危机尚未解决时，不宣称全额任务已经完成，后续可继续处理同一目标，已经获得的成果不清零。

**停战已经执行：**到约定时辰，各方照约做事，剧情可以直接进入天亮。是否日后追责在尾声谈，不能用一队新敌人逼玩家证明和平结局也必须打到资源见底。

## 玩家主动去摘星楼

本回默认只承担三妖这一路，不把全城所有事件都同时压到小队身上。但若玩家明确要救下、劝降或抓住纣王，就让他们及时得到正在准备自焚的消息，按他们真正开始介入的时点演下去。

可把此事压成一个短场面：带队者领小队到楼下，楼梯仍可通行，纣王独自在上层大厅，柴堆刚堆好；若他们先前已花去很长时间，则如实说明火势和可达路径，再让已具备的飞行、传送、灭火与救援能力生效。不要等玩家宣布行动后才倒填“刚才已烧成灰”。不用另设预定死期、不可驱散天命火或强制失败检定。

纣王先说：“你们要的是我的命，还是我自己走下来？”玩家提出的条件要得到具体回答。若需要人身冲突的数据，使用完整 **Knight** 作为本团此时纣王的战斗接口，真实兵器装备依卡，王者身份不额外增加传奇动作；原卡是此处游玩编排，不是小说人物力量评级。他不再有另一支隐藏三妖亲卫。通常通过停火、离楼或接受看管结束场景，已无须另开高强度终战。

救下便让他活着面对后续，不为了第九十九回的名单补一次猝死；未介入时可简短交代原著方向的自焚与午门开启，不描写细节。摘星楼、鹿台财物与钜桥粮仓分别处理，烧楼不自动把战后粮财全部烧光。此支线不改变已经完成的截袭报酬。

## 天亮之前，留五行记录

1. 此夜袭营是否已经停止，后营是否获知并安排安全。
2. 三妖各自：留下、离去、被俘、死亡，或妲己在Nine Hells复生；实际位置与未完责任。
3. 谁受了伤或诅咒，哪些治疗、解除或复生条件实际可用。
4. 两瓶英雄药水用了几瓶，钱款是否已结清，旧法宝目前在谁手里。
5. 玩家最想在天亮后见谁，或者最想先做哪一件小事。

任务确实解决即结清全队2,000 GP。让报信的熟人回来问开场那句话：“那现在，明天的粥里放什么？”回答可以很普通。

随后进入[第十二回《封神之后》](18_第十二回_封神之后.md)。女娲与子牙不会在这时出场把玩家留下的人全部杀掉，也没有旁白宣布此前作战的人全是替身。桌上发生的事，就是这条战役最后一夜发生的事。
