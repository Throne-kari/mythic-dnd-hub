# 第十二回：封神之后

第六幕《朝歌之后》后半 · 四名12级角色 · 约半晚至一晚 · 主持草案 v0.7 · 未测试

第一次来到青蒲渡时，你们要保住的是十二名旅人与两车粮。如今朝歌已经变了天，有人等着你们裁断一件大事，也有人只想知道：那辆借走的车，还回来了没有？

这一回结束《封神·岐路》的六幕主线。**让玩家看见自己造成的改变，再亲口决定角色往哪里去。**没有必须打败的尾声敌人，不要求把每一项旧事办得完美才能结束。队伍保持12级；上回的2,000 GP全队报酬按上回实际完成条件结算，本回不再发一份，也不自动升13级。

## 先接住昨夜，别急着念封神名单

开始前只整理实际发生的结果。三妖中谁死、谁被俘、谁答应了什么、谁确实逃掉；午门是否交接；队伍是否介入纣王的处置；还有谁需要立即治疗。这些事按第十一回的真实经过续写。

若玩家还在追逐、交战、抢救或讨论眼前尚未结束的交接，先把那一场继续完，别用“现在进入尾声”跳过其选择。若有人逃脱，逃脱就是事实；可以由玩家选择继续追，也可以明确交给愿意承接的人去查，或承认其下落将成为以后的故事。结束战役不等于把所有逃敌悄悄写成已经伏法。

对朝歌局势用一句话说明即可：外城已先开放，皇城午门的交接与内宫事件另行处理。队伍没有介入纣王事件、也没有改变其前提时，可以用简短军情交代原著的自焚与火后交接，不细述惨状。玩家已经救下、劝降或俘获他，就沿那个结果写，不能在休息时补上一场不可避免的死亡。

三妖若已接受约束，就兑现谈好的看管和处置方式；若已被杀，不让替身现形取消胜利；若尚在逃，不让女娲突然把她们全部捆好送来。**妲己使用完整Rakshasa原卡：在Nine Hells以外死亡，会立即在Nine Hells获得新身体。**因此她被本地杀死的结果是朝歌妖躯已毁、本人已在该位面重生，不能记录为永久消灭；也不因此在原地多一条血或立刻返回朝歌。喜媚与王贵人的Lamia卡没有这个复生特质。姜子牙可以处理战争的后续事务，玩家完成的关键行动仍属于玩家。

读给大家听：

> 城里第一次传来的不是催战的鼓，是木轮压过石板的声音。粮车转过街角，有人掀开锅盖，有人把门上的兵器收了进去。
>
> 你们睡醒的时候，没有人来喊立刻出发。
>
> 桌上有热水，还有几封不知道该先拆哪一封的信。

先让每位玩家说一件角色今天想做的事，再从下面六个短场面里选三个。每场约十五至二十五分钟；最后留时间给每位角色一句个人收束。玩家主动提了别的好主意，直接替换一场。

## 六个短场面，选你们在意的三个

| 场面 | 适合谁想做的事 | 放在何时 |
| --- | --- | --- |
| 一、你们答应过他什么 | 处置俘虏、兑现停战、为某人说话 | 朝歌刚安定时 |
| 二、今天这锅饭算谁的 | 做一件看得见的战后好事 | 朝歌散财发粟时 |
| 三、渡口又摆了一张桌 | 见旧友、还东西、说说一路见闻 | 归程中 |
| 四、门开着，你可以走 | 辞师门、留任、归山或换一种生活 | 回程或稍后的拜访 |
| 五、封神台外的一句话 | 告别死者、商量神职或复活的愿望 | 岐山封神时 |
| 六、下次在哪里见 | 决定物件去向与小队的以后 | 最后的饭桌或送别处 |

无需把未选的场面硬塞进来。世界仍在推进：朝歌发粮散财，归程有休养和道别，子牙请敕后在岐山封神，随后有归山与分封。不是同一天连做完所有仪式。队伍参与哪一段，由玩家的兴趣决定。

### 一、你们答应过他什么

只选一件本桌真正在意、仍未处理的事。例如三妖中的俘虏已经答应停止袭击，某位普通守军等待释放，或玩家曾保证降者家人不受牵连。没有这样的旧事，就换下一场，别为了开庭临时抓个人。

选一位仍活着、愿意见队伍、确实知道这件事的人。程简适合帮忙把约定写清楚；他可以联系有权接管俘虏的人，不能自己代表所有军队作判决。涉及三妖或纣王时，可以由姜子牙听取小队的方案，不必再排出一队新官员。

> 程简把笔停在纸上：“名字我会写。可你们当时答应的那句话，我不能替你们猜。”

让玩家先重述自己承诺了什么，再让当事人回应。若是普通投降者，他可以问：“我能回家，还是还得等别人点名？”若是仍敌视玩家的俘虏，她可以要求明确由谁看管、何时再谈，不必突然变成感恩戴德的人。

玩家可以提出释放、移交、继续看管、让愿意出面的证人作证，或修改一项双方都肯接受的约定。已经谈妥且愿意履行的事直接落实；有真实分歧才谈判，不为签字强制掷一串说服检定。一次成功的影响动作也不会替所有未在场的人作出决定。

把结果演到能看见：被释放的人取回自己的包袱离开；接管者当面接受约定；家属听到明确消息；或者双方承认尚有争议，约好下一次会面。只写此次实际达成的内容。玩家若坚持执行先前的宽待，也不必为此遭遇一场专门证明“心软有罪”的突袭。

这场改变的是一个人的去留和一项承诺的状态。它不评定小队是否配得到结局。

### 二、今天这锅饭算谁的

鹿台的财物正在分发，钜桥的粮车进了街道。武王的诏令和负责搬运的人已经到位，小队不必自掏腰包才能让全城吃饭，也不必把散财的功劳全部据为己有。

街口的饭棚摆出两口大锅，一位负责做饭的居民看着挤在一起的空碗，朝队伍招手：

> “诸位能上天入地，总会有个办法让这两队人别挤在一条巷子里吧？锅里的饭够，路不够。”

这里没有潜伏妖怪。实际问题是两处饭棚的指引都挂在同一条狭巷里，带孩子与伤者的人走得慢，运水的车又要从中经过。居民知道旁边院子可以借用，但缺人安排桌椅、搬水和把消息传过去。

请每位想参加的玩家选一个具体办法：帮忙搬开桌椅、找愿意领路的人、在院内增设发饭处、治疗一位需要帮助的人，或使用角色本来就有的合适能力。普通劳作有足够时间时直接完成；法术正常消耗，效果照条目，不因到了尾声就改成无限施法。

愿意出钱添菜很好，不出钱也照样能帮忙。给居民一个能继续自己使用的办法，便让他们接手，不需要由英雄终身掌勺。

最后，那位居民多盛一碗递来：

> “这碗不用排。别客气，刚才你们搬的桌子。”

这场改变的是眼前街坊如何度过今天。玩家可以给饭棚取个名字、留一位愿意联系的朋友，或决定日后再来；不新增稳定收入、追随者数值或据点等级。

### 三、渡口又摆了一张桌

从陶七、阿禾、孟平、石叔等旧友中挑实际活着、与队伍仍愿来往的一至两位。其余人可以各忙各的，无需全部召回。若玩家更关心鲁青、顾行舟或另一位旧识，就把饭桌搬到合适的地方。

默认地点是青蒲渡。能回来的旧友在渡棚前支起桌子；若渡口已经毁坏或关系不适合聚餐，就用山路上的茶棚或朋友如今住的地方。不要让失去过的地方在无人付出行动时自行恢复原样。

陶七见到大家，可以先看装备，再看人数：

> “出去的时候两车粮，回来一身金光。行，船钱照旧——先吃饭，待会儿再说。”

如果阿禾也在，他把当年的抄写本放在桌边：

> “你们这一路，我只知道别人说的。有没有哪件事，跟他们传的不一样？”

请每位玩家讲一个自己最想让旧友记住的瞬间。其他人可以补一句，也可以纠正一个善意的夸张。把早期借物是否归还、老路是否修好、有人是否终于回家顺手兑现；已经完成的事不用重做。

旧友也说一件自己的新鲜事：渡船补了一块新板，山路现在能过窄车，或自己换了谋生地方。只采用与旧回结果相容的版本。他们不是一直站在原地等英雄回来。

饭后让玩家留下一件不必贵重的东西：一封信、一段笑话、下次会面的日子，或真的自愿赠给朋友的一件物品。赠物按真实归属办理。若这一桌有人永远回不来了，可以留一个空位，也可以直接谈起他，不强求大家用同一种方式难过。

这场让开头的小事得到回应。渡口记住的可能不是摘剑破阵，而是当年有人没有把那车口粮交出去。

### 四、门开着，你可以走

由想谈个人去处的玩家点名一个人：自己的师门长辈、邀请留任的人、曾一起退阵的同道，或始终在家等消息的人。没有已建立的师门，就不凭空指定一个师父替玩家作主。

对方先给一个具体邀请，不一次许下全世界。例如留下帮几个月忙、回山安住一个季节，或明年春天一起走一段路。

> “门给你留着。你若想走，也不必编一个我喜欢听的理由。”

让玩家说自己愿意接受、拒绝还是改条件。可以请老师再教一点东西、提出先回家、要求不再因一句门派恩怨出手，或承认自己还没想好。对方有自己的感情与立场，可以惋惜、争论或祝福；不要把拒绝邀请自动改成失去职业能力、废去法术或被全门追杀。

若前几幕的长耳、董全或韩家成员仍活着、已经与队伍建立联系，也可由其中一人说出自己的选择。他不会因为玩家选归山，就必须跟着归山；玩家选留周，也不使所有朋友自动接受官职。

落实一个小结果：给愿留下的人安排暂住之处，为离开者写一封介绍信，约定下次联系日期，或当面解除一项双方自愿结束的承诺。官职、名号或拜师若只用于尾声，就是故事去处；需要额外游戏能力时，另按继续战役时的现有规则讨论，不在此即席发放。

这场改变的是角色与一个群体往后的关系。未来可以再改，不必拿今天的一句话锁死余生。

### 五、封神台外的一句话

子牙回到西岐、请来符敕，岐山才有封神仪式。宣封跨过敌我两方，也给某些生前有过恶行者安排职责；它不是本桌的好人排名，更不按谁击杀最多发神位。

主持人不必通读原著名单。用几声遥远的唱名、一面迎风舒展的旗、山下等着的人，交代仪式正在进行。**本桌仍活着的人不因原著榜上有名就突然消失；已死的人不因名单上没有名字就被忘记。**

请每位想参与的玩家选一位确实已死的人。可以只写一封永远不会寄出的信，也可以共同描写一次告别；涉及已死的玩家角色时，先征得该角色玩家同意。这是本桌共同选择的收束画面，不给角色一项此后随时召魂问讯的新能力。

> 台外有人将一张空纸递来：“名字写不写都成。你想告诉他的那句话，留在这里就好。”

问玩家：“如果他只听得见一句，你会说什么？”若死者是玩家角色，让那位玩家决定是否回应、回应什么。可以道谢，可以责备，也可以约定日后再相见；不要求强行和解。

若玩家愿意为已死角色选择叙事神职，先说清楚想照看的事，再一起写一小段结尾，例如守望常有旅人失足的一段河岸。这个选择须得到该角色玩家同意；不自动复活，不赋予无限战力，也不因此剥夺别的角色的魔法物品。想继续以该角色参与常规冒险时，另按既有角色与复活规则落实，不能把一句神职描述当作新角色卡。

若玩家希望角色实际复活，先看该角色是否愿意，再按所用法术的时限、遗体、材料及其他限制办理。正常的救命机会应在前一场及时处理，不为等封神仪式而故意耗尽时限；仪式也不代替真实可得的施法者与材料。没有现成条件时，可以把寻求复活作为下一段冒险的愿望，不假装今天已经成功。

需要当场决定时，用这张简表，完整接口见[第六幕规则备忘](../research/ACT6_RULE_NOTES.md)：

| 现有法术 | 主持人先确认什么 |
| --- | --- |
| Revivify，三环 | 死亡不超过一分钟；动作、接触，消耗至少300 GP的一颗钻石；复生为1 HP，不复活老死者、不补身体缺损。 |
| Raise Dead，五环 | 死亡不超过十天、死亡时不是Undead；一小时施法、接触，消耗至少500 GP钻石；复生为1 HP，缺失维生必需部位会失败。复生后的D20检定受−4，每次长休减少1直至消失。 |
| Reincarnate，五环 | 死亡不超过十天的Humanoid或其身体一部分；一小时、接触，消耗至少1,000 GP稀有油。按原法术生成新身体与种族，保留记忆能力、更替种族特质；先让玩家知道并决定是否愿意回来。 |
| Resurrection，七环 | 常规施法者13级才获得七环；本桌保持12级，不默认拥有。若实际找到相应帮助，再依原法术办理，不自动赠送免费施法。 |

所有复生都服从Dead通则：灵魂知道施法者身份并可以拒绝，Revivify也不例外。一般仍持续的诅咒不会仅因复生全部消失，具体看原法术；死亡已经结束物品共鸣，复生后使用六魂幡仍须重新共鸣。Gentle Repose可依法保存遗体，并使覆盖时间不计入复生时限，不能重置早已过期的死亡日期。Speak with Dead只让尸体依生前所知回答，不带回灵魂，不能拿一句尸体的答话代替该角色玩家的当前意愿。以上依[SRD 5.2.1](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf)第135、157～159、164、180页。

不想写神职或告别的玩家可以让角色在山下喝茶、修理装备、陪朋友等候。仪式照常继续，不会因此失去任何已经取得的成长。

这场改变的是你们愿意怎样记住一个人，以及是否还有准备继续追寻的愿望。

### 六、下次在哪里见

把队伍真正带来的物件放到最后一张桌上，或只在纸上列给大家看。已经送人、遗失或依法毁坏的，不为谢幕重新出现。

> “以后谁还会用这东西？谁只是舍不得它？”

让每件仍由小队保有的物品有一个明确去处。不愿分家的队伍也可以只确认当前持有人，继续一起走。

| 本战役出现的物件 | 本场要说清楚的事 |
| --- | --- |
| 攀云绳，Rope of Climbing，一条 | 原持有人继续带着、借出，还是自愿赠给某位朋友。不会拆成四条同样的魔法绳。 |
| Weapon, +2，一件 | 沿用第四幕实际选择的武器种类和当前归属；不重新选择并补发一件。 |
| Sending Stones，原来完整一对 | 分别由谁持有哪一端，两个人是否愿意以后联系。它们仍是原来的一对，不是两套。 |
| 真绝仙剑，Weapon, +3（Longsword） | 按已发生的赠还、保留或转交决定；归山、受职与故事结束都不会让剑自动飞走。 |
| 六魂幡，Wand of Fear，若仍保有 | 写下持有人、实际充能和共鸣者。交物不等于新持有人立即完成共鸣，改写布上的名字也不改变法术。 |
| Cape of the Mountebank，一件 | 当前谁穿、是否已经使用及恢复安排仍照原物品条目；不因结尾自动刷新次数。 |

可以借给朋友，但要真的交过去；可以送回师门，但要出于持有人的决定；也可以继续带着，无需证明自己有足够高尚的理由。角色之间的物件分配由玩家谈妥，主持人不安排偷窃剧情替他们强行分好。

最后问小队：“下次还想一起出门吗？”想继续，就约一个具体地点、一件愿意做的事，或者只说等谁的口信。想在此停下，也可以约下一顿饭。不必用新的灭世威胁逼大家购买下一段冒险。

这场改变的是关系和物品的真实去向。它可以成为下一段故事的第一句话，也可以就是一个圆满句点。

## 每个人都有最后一个镜头

无论选了哪三个场面，最后都轮到每位玩家。让他选一个时间：第二天、第一场春雨，或几年之后；说角色在哪里、身边有谁、正在做什么。

活着的角色可以留在人间做事、归山、回家、受职、开店或继续同行。已死角色的玩家可以选择一个被人记住的细节、一句告别或自愿讨论过的神职尾声。角色还在等待救回，就承认等待；没有人为讲一个漂亮结局而被自动复活或强行赴死。

主持人只添一个呼应早期的细节。例如青蒲渡那只鹅又对木牌叫了一声，山祠铜铃被风轻轻碰响，陶七还惦记着那辆车，或传讯石里传来一句：“锅开了，你们什么时候到？”这句话应由确实愿意联系且持有相应石头的人说出，并按传讯石的正常使用限制传来。

然后结束。封神的大事有人记在榜上，你们做过的小事，也已经有人记住了。
