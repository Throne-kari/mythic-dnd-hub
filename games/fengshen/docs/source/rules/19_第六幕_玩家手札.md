# 第六幕·玩家手札

v0.7草案。配合[朝歌最后一夜](17_第十一回_朝歌最后一夜.md)与[封神之后](18_第十二回_封神之后.md)，由主持人按实际收到消息、看到场地和进入尾声的时间摘发。一次只发对应小节，不把尚未发生的结局提前宣布给玩家。

## 一、今夜这一路

发放：小队收到三妖准备夜袭的可靠消息时。署名可换成实际报信人，授权仍沿本回已建立的军务渠道。

> 朝歌外城已开，皇城午门尚未交接。
>
> 妲己、胡喜媚、王贵人正在整装，准备沿宫墙西偏道经过官桥前庭，袭击周军后营。前庭西街再走约五百尺便是营地；后营还在拆接济棚，须尽快通知。
>
> 请诸位设法使这次夜袭停下。可以拦、可以谈，也可以先让营中人撤到安全处，使她们无从突袭。不要为追一个已经离开此战的人，把眼前需要照顾的人全丢下。
>
> 此次可接受停战和自愿看管，在约定接收期间不因交出兵器便立即处死，天亮再议具体处置。不能许诺替所有人一笔勾销旧事。条件谈清楚，消息传回来，我们照实际约定办。
>
> 程简

完成本次目标，小队合计2,000 GP。谈退、制伏、击败或实际解除突袭机会，按同一目标结算；钱只领一次。最终两回保持12级。

## 二、随信送来的两瓶药

发放：交付实际物品时。两瓶由全队分配，不是每人两瓶。

> **英雄药水 × 2**
>
> 临行前交给诸位，喝不喝、谁来喝，自行商量。剩下的便留下。

| 物品 | 已确认的使用办法 |
| --- | --- |
| Potion of Heroism | Rare，无需共鸣。饮用或喂另一生物花附赠动作，药水消耗。饮用者得到持续一小时的10临时HP，并在这一小时获得无需专注的Bless效果：攻击检定、豁免加1d4 |
| 重复效果 | 不与另一个Bless叠成2d4；临时HP不叠加。药水未喝就保留，不因离城过期 |
| 普通军械 | 每人可选借一件现有普通武器与通常所需弹药，写下种类。熟练、伤害类型、射程等仍按原武器 |

**斥候给出的可靠提醒：**妲己对直接命中的术法、魔法控制和恐惧极难撼动，普通刀枪仍能伤到她；受Bless影响者用武器造成的穿刺伤害尤其有效。绝仙长剑仍造成挥砍，不因为说“刺”就变成穿刺。

这份抗魔不会让她的同伴一同免疫，也不会抹掉你给朋友的治疗、祝福、移动或掩护。她的爪伤会留下妨碍休息的诅咒，Remove Curse能解除。她能离开此界，但带同行者须对方愿意。

三妖都有外观幻象，喜媚与王贵人的真实身体很大。看穿外观是一条情报，不等于已经把对手消灭。其他具体能力由实际观察和规则查询取得，不必先熟读敌人卡才可决定行动。

## 五、天亮之后，你想见谁

发放：夜袭这一路已经按实际结果收束，大家准备进入尾声时。若仍在抢救或追逐，先继续眼前场面。

> 今日可以先不出发。
>
> 你愿意去见一个人，做一件小事，还是先把那封信拆开？

每位玩家选一个自己关心的画面：兑现承诺、在朝歌帮一顿饭、回渡口见旧友、跟师门说清去处、记住一位逝者，或和同伴约下次见面。大家不必选择同一个结局，也不必把所有旧事办完才可收尾。

- 我最想再见的人：＿＿＿＿。
- 我想告诉他／她的一句话：＿＿＿＿。
- 我还愿意履行的一件承诺：＿＿＿＿。
- 我想带走、借出或自愿赠送的物件：＿＿＿＿。
- 故事最后，我在哪里，身边有谁：＿＿＿＿。

活着的人可以回家、归山、留下任职或继续同行。想救回已死角色时，按真实可得的D&D法术、时限、材料和意愿处理；封神本身不自动复活或增加战斗能力。原有物品照实际归属保留，已经失去的也不因为尾声而复制一份。

全队若想留一页纪念，最后共同填写第十二回末尾的“这一桌实际发生的结局”。主持人届时单独摘发空白表即可，不用把整回主持正文交给玩家。
