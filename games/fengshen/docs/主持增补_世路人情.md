# 主持增补：世路人情

本增补沿真实 v0.2 十二回节点工作。原 `docs/source/rules` 是底稿，不重开一套通用战役。成熟性来自权力、成本和谁能说话：救援仍值得救，承诺仍能兑现，敌对者也会自利、害怕、渴望认可。不要把所有聪明办法改成坏结局来证明“世界黑暗”。

## 三条可执行链的主持方法

粮药链在第三回已有真实物资之后才出现。请指出18／24的差别，读出三项分配的实物成本。民诊医官余萤是成年独立医者：她希望诊所不被军需吞没，也想取得有影响力者的担保；她不会因没分到这批新药就让已救者恶化。军需也确实在救前线的人。保留实物是合法决定。第六回回礼药水真实入前两队员，第十一回民诊合作替换的是撤营工时，不能把不在场或已死亡者写回来抬担架。

韩家链是原安全协议外的自愿附约。韩荣在乎保住家门与议价地位，韩升拒绝集体认罪，韩变重视未具名居民的安全。公开补偿的60 GP直接从队伍扣款，原饷照原账付；限名责任保护姓名与本人行为边界，后续须核实书记没有换字。第九回的新人物是军务书记魏简与两名封签护卫：魏简想用扩大问责换升迁，两名护卫想带一份能交差的文件回去。背叛发生在新附件，不是推翻旧日护送结果。

先读封签再出示可选成本。调查DC15成功即核清；失败带来一小时补查，原件仍然到手，下一步直接撤封。交涉DC15失败耗半小时，不准重复刷同一说辞，但有查账、60 GP押金和原北入口。主动武力选项会真正把两名Scout变敌对并进入整院先攻，所有原守卫也按卡行动；不能用一句“打赢”跳过HP、动作或撤退。无需让护卫主动袭击一支选择绕行的小队。护卫倒下不等于同意改约，文书最终另审。

证言链在第十回原“听定光、处理幡”之后出现。定光是成年人，既不愿再被幡役使，也会想保住自身名声；承认自己曾依附权位，不等于被迫提供所有旧友姓名。公开40 GP抄印，或军议零GP保管、留下复核责任。沈砚有能力先推动处置，也由此控制谁先看见文本，权力须留下阅卷范围和复核义务。不同选择不回收六魂幡、不重扣本回报酬。定光失能／死亡时仅可作小队目击记录，不替他讲“愿意”。

第十二回的职书是权力与时间责任的交换。公开稽核官、军议录事、民诊理事分别有150／250／100 GP预支与具体义务，直到最终封卷才到账。可以混合：一人任职，另一人回家。封卷前改选可取消未领预支，不罚退出；封卷时职责写入每个人的结局和共同承诺。原普通职务仍可选择，不把新资格当整场唯一体面结局。

## 获利、背叛与退出的可执行接法

`intrigue.mjs`给下面三项交易接上现金、合作资格和结局，不要求主持用惩罚旁白补足。梁嵩、魏简及新增交易是本版游戏改编，不当作原著史实。让玩家在落笔前读到按钮说明；NPC可以催促，主持不能把代价藏成事后惊喜。

第一回梁嵩买的是责任解释。他承认原账存在，愿付80 GP请小队只追渡口差役、暂不查雇主。收钱不销毁玩家已取得的账据，也不让阿禾失去救援。第二／五回可调查买方委任；DC13失败多花半小时，副本仍给。第四回未撤专报就没有新增独立急递，但山脊、查信、合法传讯及原400 GP都保留；退80 GP、核对半小时（未查副本则一小时）恢复合作。十二回同样能更正；尚未更正时不能兼公开稽核。没有“付钱买清白”结论：更正的是小队自己的有偿报告，交易历史仍在后果中。

第六回梁嵩用180 GP买小队后续运输班次。这个选择能立刻补充现金，可能正好支付药品、欠款或押金；不是假奖励。代价是十一回不能同时请民诊组织新增撤营队，十二回不能兼民诊补给理事。余萤仍开诊，既有两瓶回礼仍照付，普通半小时撤营有效。退全款并实际花半小时交班才能恢复额外协作；没有强迫把钱还上的戏，资金不足时仍可保留委任、自行撤营。她拒绝的是双重调度，不是宣判一个人的一生。

第七／八回魏简付200 GP买只录新军功、不收新民伤异议的附报。他不会让小队公然毁旧安全约；他要把新增申诉挡在纸外，好用“无异议”封面换升迁。第九回调查DC15失败只多花半小时，也给删录证据。玩家可知情确认、保住现款；韩家因此不借独立副账，工兵账局不另付80 GP劳务。也可退200 GP、另付60 GP补印并花一小时更正，恢复新增合作。不是将旧日获救居民重新抓回，而是玩家决定是否继续为一项新排除行为背书。

十二回未更正者可接400 GP附报总办，封卷才发款。让职书读出“每季军功附报、拒收新增民伤异议”，不要把它改叫普通好官来冲淡交易。富足与地位确实来到，独立资格和申诉人的合作确实失去；同伴可回家或选别的职务。弃职取消未发预支，但不自动撤掉此前附报。最终每个人结局都会更新真实物件、后果和未尽责任，不以一个总阵营替代个人选择。

## 十二回可直接落桌的人情场面

以下镜头接在原行动之间，不替换目标，不要求玩家接受关系或付额外钱才能继续。仅已经当桌揭示的公共结果写入手记；不把未说的内心当玩家既知事实。

**一，渡口。** 梁嵩掂了掂钱袋：“粮可以给你们，名字也可以留。可谁是主使，何必今天就写死？”阮寿愿交代差事，不愿独担全部责任；陶七想赶在天黑前送旅人，不肯替任何人的免责专报作证。若小队拒绝，梁嵩收起钱袋，没有凭空调来新伏兵；若收下，账据买断按选项记入。救人能得到真诚感谢，收钱也能得到真金。

**二，山祠。** 石叔让孟平坐下再喝一盏茶：“修这条路，你以后要听谁叫？”孟平想接军方工程，也担心兄弟在赶工中被当成可替换的人。小队可把窄车、树渠和借物范围说清，也可不承诺新工程。查到梁嵩委任时，石叔只问小队准备怎样对自己的签字负责；他守祠、护渠的信念无需因商人逐利而变成骗局。

**三，麦亭。** 岑岳说留六包是为自己守兵吃饭，费安看见药箱后不再愿把扣药说成查兵器。余萤问的是十二包，程简问的是其余；两人都能指出需要救的具体人，谁也不能把同一包记两次。已救工匠自己开后窗离开，不必在两个机构之间选主人。药留给谁，用既有分配选项落账；不以随后的新死亡逼玩家接受主持偏好的分配。

**四，驿路。** 许照想留下抄本保护自己，沈砚想把求援变成自己能推动的工作。沈砚可以承认：“我愿帮忙，也愿将来有人记得是我办成的。”他有野心不使真实回复作废。私人交情可以暖，可以留白，送达资格不依赖亲密。限责专报未撤者仍能用原查信／山脊／法术路线办成事，急递新增帮助才依公账条件出现。

**五，石场。** 顾行舟把亲见的危险讲完，才承认自己还想在旧同僚面前留一点说话的余地。他不要求小队替他洗掉旧雇佣经历。问他是否帮助撤离、由谁来背书，可以得到具体答复；玩家不必揭他私事来换已经答应的报告。被扣者的营救照原石场和撤阵交接办理，政治牵连不吞掉实际生命。

**六，风阵。** 董全要的体面里有不愿服输，也有不想让从者替他再撑一阵；长嘶与回响要离开这场已经不值得的援助。原公开约战降幡即止，善于操作普通挂扣的玩家不必再通过一场道德审判。梁嵩在阵外谈以后车队的价钱：刚收兵时最缺现金，也最容易把未来班次卖出去。钱按运力委任入账，退出按实际交班办理。

**七，酒席。** 韩荣想保住家门作为谈判者的位置，韩升要饷与尊严，韩变不愿拿居民姓名替自己换免责；三人不必彼此完全坦白。魏简递的新附页比酒更甜：“不改你们的好名声，只少开一个受理口。”允许玩家把话题从人情拉回钱、范围与签名；公开补偿、限名、只守原约与有偿附报各按按钮成本，不强迫全家成为一派。

**八，开关。** 韩升松开钥匙前问：“你们走后，今天应过的话还算谁的？”小队可以把人员先走、公械点交、民居不驻武装写给实际接手者。魏简若有附报，继续办理自己的那份，不让它代替已谈妥的安全条件。有人愿留、有人愿走不是忠诚度竞赛；同一批人和伤势继续，合法门锁法术照用。

**九，北门。** 无形客要的是这一次工作的酬劳，不会为了主持制造恐怖自动跨位面追杀。魏简需要小队签名为自己换权位，封签护卫需要能回营交差的文件；他们的利益可以被查明、交涉或绕过。知情继续附报会失去实际独立背书；揭露则真的付退款和补印成本。取剑的普通挂扣不因文书纠纷变成神秘禁制，真实战术仍有价值。

**十，幡下。** 定光既害怕再次被役使，也想留下对自己有利的叙述。他可以删去未同意具名者，不能靠删去自己的责任把证言变成无瑕传记。小队可公开、保管或只写目击，幡的归属另算；一名受魅惑、支配、击昏或失能的人不能以点头替代核稿。让自由包括不作证、不给秘密，也包括承认曾经自利。

**十一，夜营。** 妲己担心失去支配局面的地位，胡喜媚担心再次被留下，王贵人想要独自离开的路；不把她们的欲望都写成诱惑身体，也不以一个人的退意代另两人同意。若小队的运力已卖断，余萤指出具体缺的是车与护卫班次。玩家可退约，或自己用原北路把人送走。空营确实使夜袭目标落空，不临时让敌人变成无所不知以惩罚撤离。

**十二，天亮。** 有人把职书压在钱袋上，有人问何时能还乡，有人只想在封神台外说一个死者的名字。魏简的职位能给舒适，不给独立；公账职位给有限权力，也要求有人看自己的账。让每个人分别回答，不要求同伴彼此赦免。可以从未竟责任接下一段故事，也可以在一顿普通饭后结束；这顿饭不用证明所有裂痕都已经修好。

## 成年关系与信息边界

NPC与角色均限成年人、自愿、非露骨。可以写一句目光、一封邀约、一段共同值夜后的沉默；想继续就询问“友情、暧昧或淡出”，拒绝就停，不扣任何机械收益。朋友关系、单身、已有伴侣、无恋爱兴趣都完整可行。不能以给药、情报、离关、复活或官职交换身体、秘密或亲密。角色被魅惑、恐惧、俘虏或失能时不得把服从演成同意。

引擎目前没有私人消息通道。共享 `campaign.facts`、journal、日志和可见角色状态都不能存私人内容。使用[离线手工页](主持私密分发_不进房间.md)，只发给参与者；不要把它附在AI玩家请求里。需要未实现的法术、私约、私人关系或定制人物状态时，由真人GM依原卡裁定，再只把公共结果写回。不会假称“系统已经安全隔离私密数据”。

## 主持裁定与验证限度

自由提议仍可用原主持工作台、gm事实、note与真实法术规则处理，但须写明原因、真正花资源并保存实际结果。不可强制死亡、受封、秘密披露、亲密或弃宝。计划外的合法聪明解法与同成果基础报酬照旧。

本版做新增链、扣款与物件、失败退路、权限、公开投影、结局封卷的定向程序／本机HTTP检查。测试夹具明确跳到相关回目并准备合成状态，部分检定人为设成必成／必败以查分支；这不是一桌真人十二回实玩，不能证明全战役时长、平衡或趣味。部署与模型调用没有在本轮执行。
