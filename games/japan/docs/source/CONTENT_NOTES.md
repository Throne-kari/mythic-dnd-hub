# 内容提示与略述边界（日本v2）

公开开桌提示保存在campaign.introSafety，十二章均标sensitive并提供descriptionSummary；选项textSummary、结果saySummary与原文采用同样事实、成本和规则结果。略述是本机展示偏好，不是服务器秘密。

本场涉及债务、劳动报酬、土地/登陆排除权、权力不对等、愧疚、背叛诱惑、亲人已逝与成年人自愿的旧伴侣关系。所有涉事人物成年。没有性暴力、露骨性细节、以受虐作奖赏或将现实信仰列为邪恶阵营。阿澄与渚的旧关系不设“接受亲密才能获得材料”的按钮：陈述、报酬、合同与证据可独立取得。

四预设旧事是可拒绝或改写的虚构背景，不要求人类玩家披露任何经历。begin通过privateFacts/privateSay逐角色投送；四个公开采用选项以actorIds和visibility:owner限制到持有人。真正私密采用owner投影，不能把descriptionSummary当秘密存储。采用旧事的后果在文本预告，其他公开证据、器材、金钱和战术路线始终存在。

可随时要求暂停、略述或跳过关系细节，无须给理由。若整桌希望删去旧伴侣关系，直接改成两位长期合伙人，保持相同证言和合同；不减少机械收益。若希望避开亡亲书信，可换成年人的旧往来声明，仍维持同意范围。主持需先协商改写，再保持事实和成本一致，不能用敏感内容当必须解的谜题。

没有隐藏道德点数。GP、本人药水、物件归属、事实、有限NPC援助和原卡战斗承担后果；没有仪式HP税、任意Poisoned或强制牺牲。现实宗教与神话资料用于母题和边界，船会合同制度是原创架空。具体神话来源与SRD许可见REUSE_AND_SOURCES.md。
