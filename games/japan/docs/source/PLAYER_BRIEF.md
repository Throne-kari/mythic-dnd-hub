# 《镜与归路：暗潮归灯》玩家简报

一场固定5级的四人合作冒险，目标4–5小时，实际讨论和战斗可能更长。你们来帮山谷恢复水道、接出被困工匠、带人归家并归还受托镜。很快会发现：每份救援安排都有人付钱，每份原账都有人希望被看见，也有人希望被收好。

这里没有要你猜的隐藏善恶分。先问清实际代价，再决定谁承担。你可以说服、调查、依规则施法、准备工具、战斗或离开；按钮是常见办法，主持应按真实能力处理合理新方案。

## 开桌内容提示

所有涉事人物均为成年人。故事涉及债务、工资、排除权、亲人已逝、背叛诱惑、愧疚、权力不对等与自愿的旧伴侣关系。没有性暴力、露骨性描写或把现实信仰当邪恶的设计。可以要求略述、略过关系细节或暂停，不需要解释个人经历；略述保留相同规则成本与后果。拒绝感情不会失去任务报酬或证据。

预设人物可能收到自己专属的虚构旧事。你可拒绝、改写或不公开；它不是你的隐私，也不是必须表白的通关题。你的职业能力不以接受背景为条件。

队伍初始只有两瓶标准治疗药水，分别由隼人与千鹤持有。剧情选项要用药时只耗行动者本人的持有物；不能替另一位玩家答应。受伤帮工也能用真实Cure Wounds或Healing Word治愈，照常花施法位并验证实际目标与HP恢复。共用GP用于已提前显示的实际成本。没有第二套秽、神力、荣誉或好感数值。

## 出发前就知道的事

- 泉道缺水来自倒木、截流与人的决定。泉中之声没有故意扣走饮水，铜镜也是普通受托物。
- 船队80GP预支附带本队的原件封存约，可退80解除；村议的独家渡约是另一份合同。
- 姓名原账在藏库；海上的船载配对运输存根。两份材料可以互相补证。
- 安全接人不一定保住工具，依法取镜不自动取得姓名账。每件物品各有持有人和同意范围。
- 200GP的施工款中有120GP属于六名成年工人。拿到钱袋后必须真实发薪；不能把未付工资说成自己的奖励。
- 人物有自己的目标，会接受交换、作证或拒绝。高骰不替第三人公开私事，也不消除你已经转交的物件。

风险和成本会在选择前讲清。没有预设谁必须献身，也不靠战后突然揭露“对手其实无辜”羞辱你。合理魔法照目标、距离、材料、持续与专注生效；可以真正帮助工作，不会为保留剧情临时失效。

## 在桌上怎么做

看清当前地点和场景限制，先说打算与准备。若要检定，主持说明失败后果；失败通常让事情继续，但可能损木料、缺少某份证据或多一道查件。战斗仍按原先攻、动作、伤害、HP、条件与死亡规则。敌方投降、普通停手和队伍败退是不同结果，败退不会领取胜利报酬。

行程多了十分钟不会自动恢复资源，也不是隐藏神罚倒计时。安全处需要按标准短休或长休处理。最后会按真实供水、持物、证人同意、工资与登陆权结算；做成的事情会保留，未结清的也照实保留。你们可以争取公开处理，也可以接受有所得有所失的私人安排。
