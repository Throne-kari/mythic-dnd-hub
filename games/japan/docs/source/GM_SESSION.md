# 《镜与归路：暗潮归灯》主持稿（v2）

本目录是独立第二版，固定四名5级预设、十二节点，目标一场4–5小时。它不是旧五回全文的程序化，也没有真人整场试玩结论。主标题沿用《镜与归路》，不改v1快照。实际行动、资金、物件持有和遭遇状态以服务端存档为准。

## 开桌与节奏

先读现有开桌内容提示。所有涉事人物均为成年人；涉及债务、劳动报酬、排除权、亲人已逝、权力不对等和自愿旧伴侣关系。无性暴力、露骨性描写、猎奇或将现实信仰写成恶源。任一人可略述、暂停或跳过关系细节，规则成本与结果保持相同。四张预设的秘密是可拒绝或改写的虚构旧事，不是人类玩家隐私。不要要求玩家以自白换通关。

把讨论留给三个实际问题：水和材料谁先得到；原件、工具与证词由谁决定；120GP工钱是否真交到工人手里。不是每章都要讨论所有可选项。默认先读描述，再让玩家提方案；按钮是常用办法。采用合法能力确实解决危险时按实际效果裁定，不为“黑暗感”临时封禁法术或强行保留损失。

前四节点约60–80分钟，救援与暮坂约90分钟，海岸与芦湾约70分钟，尾声20–30分钟；这些只是编排估计。讨论展开、战斗或休息可能延长。赶时间可略述普通行程和饭桌，但不要省略成本预告、同意与实际结算。时间字段不是隐形午夜惩罚钟；不声称走得快一定更善良。

## 人物不是任务终端

阿澄为救济签过不利临约，既想恢复村水，也怕成为唯一替罪者。她与渚曾自愿相爱，现今仍关心对方，但水、工资与登陆权有真实冲突。她的陈述、释放原账和报酬都不要求复合或接受亲密。

渚确实给船员发工资、提供船和应急水车，也利用条款掌握排他登陆权。她能接受具体合同证据、真实买回款或继续封存原件，不能买掉活人的独立声音。战败不自动使她思想改变；合同争议与物理通行分别记。

楮保护住店的成年债工，也可能焚毁别人的索赔凭据。榛是被困者，也是临闸设计的签字人。笠生提供免费路线，但验过双份账，也会为保差事通知船队。阿叶有自己的有限同意，信记载其父以维修款安置债工并签弃权书；这不是“死者其实邪恶”的反转判决。纱江愿做眼前工作，也会在欠薪后拒绝再借船。

给重复出现的人一句前次行为的回应，再进入新问题即可。黑色幽默是活人的节省气力：“死人只收灯，活人有时连明天的灯钱也先收。”温暖可以是一碗饭和一条固定梯的旧围巾，不需奖励点数。

## 三组持续因果

1. J02的bargeEscaped决定J09问运单还是找港工；exclusiveLease决定J11公众施工和J12撤约/买回；downstreamWorkshopFlooded增加J11实际40GP准备费。藏库姓名原账从未在船上，运单是配对补证。
2. J03破封与姓名暴露、J04旧名、J06报警，决定J08的实际人类增援及合法担保、交件、付费或梯绳分支。真实交出的原账不再可烧、再卖或作仍持有的筹码。已停手或死亡的押运领队不在后章复活。
3. J04器材/治疗援助决定J05保人货方式；toolsRecovered与engineeringEvidence决定J11是否补租，以及J12互补证据能否成立。J11工资款进入共用钱袋后，J12必须实际扣120才算发薪；带走则纱江明确追索并暂停以后借船。

公开大团圆不是唯一“正确”结局。也没有显著无成本全赢按钮：可以花钱降低风险、用现有法术真解决危险、在战斗里以真实资源换装备费，或接受限制保住眼前生活。聪明准备可以得到好收场，不因主题成熟而被强行扣去成果。

## 规则与资源

四角沿用Champion战士、Thief盗贼、Life牧师、Evoker法师5级原构筑；无忍术、神力、秽或好感数学。全队初始两瓶治疗药，分别给p1/p2。选项药水成本只扣行动者本人，不能借叙述扣别的玩家持有物。共用GP可付公开成本；一次性奖励与章完成门槛防止重复领钱。minutes不治疗，不恢复法术位或生命骰；安全场景可依原动作执行正常短休/长休。

胜利收束只读encounter_*_defeated或_surrendered；_cleared也可能是普通停战或队伍败退，不能当胜利。至少三名队员倒地可能停追，死亡、稳定和治疗仍依正常规则，不自动起身。withdraw表示撤出并保留实际伤势，不发该目标报酬。敌人自己的HP投降阈值是公开停战条件，不改原卡伤害、AC或行动。谈妥放行可另选已公开的具体处理；DM不得口头虚报已获物件。

## 尾声核对

公议要真实供水、归镜、往返、付工资、公共权利落实，再满足以下任一证据组合：
- 阿叶自愿公开，另有工程图、核验收据或港工之一；
- 阿澄自愿作证，加工程图与收据副本；
- 笠生验账说明，加核验收据与旧钩焊痕。

四角全不公开自己的背景也能公议。封存或脱敏同意配上已经落实的工资和船队安排可得私人妥协，不作羞辱。出售原账必须实际仍持有，150GP和转移同时发生；不能卖掉已烧或已交船队的物件。离场读取未付120GP、原物、合同与人物意愿，不自动神罚，不保证每人原谅。

## 验证边界

内容静态核对不等于完整真人游玩。技术QA由独立代理在隔离房间记录真实HTTP、路线、同步和保存证据；以最终QA报告与manifest SHA为准。时长、节奏与是否好玩仍须真人桌反馈。本文件说明设计与裁定边界，不把预想路线冒充已通过。
