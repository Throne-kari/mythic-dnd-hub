# 二十四终局矩阵

已与正式三章 campaign 对齐。每项先由前章行动建立水权、掌印初案、志愿范围、拘束或修复事实，再由终章有限政策组合成归宿；最后不是二十四按钮。全部二十四项已用正式初始资源、正常旅行/选择/战斗逐一抵达并断言恰好匹配一个。

主结局呈现债制与城市/人物的具体差异；实际水务与政体各有必现后记，避免混合状态被主文吞并。赔付、船权、八银现金债、匿名保护与不可逆伤害也按事实逐项保留。主文不能与后记互相打架。

## 互斥而非顺序遮罩

- 黑印 mode 按互斥政体分城库、庙院、商约、非前三者四组。
- 两位强制替身和四项本人志愿/注销方案使用六个不同 mode，不能在同一条末节点选择中同时产生。
- 撤约 mode 分十一组：淹街；未淹街但毁证；前两者皆无而盐化；三灾皆无时，共同政体按共同渠/出港/两岸/其余四组，另城库/庙院/商约/未成各一组。
- 闭门 mode 分三组：出港；未出港而城库；未出港且非城库。
- 九条末节点一次性结算，各 mode/政体/水务终章节点只能选择一次。因此互斥依赖真实可达状态，不依赖数组 find 的顺序。引擎对章战役也拒绝零匹配或多匹配。

## 不可逆后记与具体债制

首次黑印执行在终章第二节点，明确拘束乌鲁一夜并烙可转让号痕；最后撤约、苏恩服务或闭门皆有明确释放选择，但 first_collection_enforced 与烙印史不清除。独立回归验证所有这三条后续路线仍出现 first-black-order。

低街死者不能被修闸/撤约复活。真实救济三粮与未付分别触发 flood-paid/flood-unpaid，不假定所有政体已经受理赔偿。毁证后不恢复原件，盐化后不冒称丰收。贝鲁未归船不能被主文自动给船位，庙院/商约/城库掌印不能自动吞别签水权。

“注销索引”只对本人明确同意的纳鲁渡城籍号生效，代价为该号所带屋产继承与登记权；私名不变，未同意者不被代表。单纯出港没有注销，旧契仍按未注销号追索。因此 nameless-exodus 与 closed-fleet 不是改称呼的同一版本。
