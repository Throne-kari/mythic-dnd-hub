# 泥印未干 3.1 · 吉尔伽美什与七门之债

本作是原创的小型确定性 CRPG，扩篇为三章、九条章内主线、二十七个剧情节点、一百四十五个选择（保留原一百二十四个选择并新增二十二项）和二十四种互斥归宿。三条贯穿全篇的冲突分别是河渠救援与水权、泥板证据与城权、七门替身债；每章同时推进三条线。每线三节点，成功和失败都可交接。路线办结不是道德免责，章节通过也不代表所有目标成功。

## 来王如何贯穿三条线

吉尔伽美什仍然活着。他公开带着自己的死梦与一只给恩奇都的旧空碗来；恩奇都已经失去，死因没有套用未经本作核读的后世版本。王的慷慨与恐惧同时在场：他可以自掏王库付薪、亲自踏泥校水，也会在湿沙画出第二个位置又把它抹掉，想借一个河床空墓和一册“将来跟随王”的名字抵抗被遗忘。

本城并非他的属城。艾迪勒邀请的是测水队，外王得到什么权力，取决于本地逐项许可。第一章的王队许可登记不是死籍案受理，妮萨雅会在中章追问延期；限定受理仍需真实通行令。旧选择也回应王：本城自付工资、只授艾迪勒而非外王、公开父债或保护父名，都会留下王所面对的边界与诱惑，走原一百二十四项也无法把他绕成不存在。

第二章可用王队修公共闸，也可拿六粮签河床空墓合同，再决定是否真的开围堰。许可可先审计，因此暂停在前便不能新签墓工；先开堰再审计，土袋与石口还在。王提出的强役有确切对象和交易：六户各一成年，本次二十日墓工、十年每年一日祭供，不能退出、不传子女，不含陪葬；本城换取王队协查征收与有名户优先祭供的政治承诺。王若借未来幽魂名位发今日格式令，实际扣人的仍是本地书记、押役和王队，女王未任命这个活人。

终章可反对他：凭既成公开受理、完整物证和同意证言传问王，城库政体也能撤外王许可，不必先成立共同议席。撤权释放未来王役，已服的天数与投资仍按收据；拆实际围堰另付三粮，哪怕王已失信或许可已撤也可进行。封成的空墓保持空置与难行料道，不能一纸撤约抹掉。玩家亦可支持而限定他：以可撤回公共协议合作，分开恩奇都、父亲与外来工的祭名，校清未来身份，最后在无王堰/封墓/强役/未归牌时留下有限岸碑。王接受名字可能失传，追加工程仍需新同意。

利用是另一种具体行为。玩家把工程牌超用为护人命令，确实挡走追索证人的人；王失去信任，追索实牌和公开更正。归牌后保护不倒退，滥用史也保留。黑印结盟则把王的祭名执念变为有名优先的差序：必须实际赢得黑钥、执行乌鲁一夜拘束与永久烙号，仍有效的人间许可再与王的僭权联结。王队协查确有力量，却不给他永生，也不能让任何受索者替回恩奇都。

四同伴仍分别行动：王付薪不能买清卡拉特假签；王不能替妮萨雅决定原件与匿名者；公共工程队不能绕开贝鲁未获赔的船权；王的失友不挤走苏恩父亲与外来工的悼词。测水人若参与门下志愿轮值，也只能自己写可拒日期，王不能替手下自愿。

## 施工日与行动序号

游戏 clock 是行动序号，不是小时数。第一章急救、第二章多轮测绘/修渠/运料、第三章的涨水应对与石室封顶可以跨多个施工日；叙事在节点中跳接施工过程，不以一次按键几分钟建石墓。若四人仍在高台，那里是汛期避水仓，有密封麦、饮水和熏鱼，接应者按日看灯号送绳递信；他们仍须一次真实救援才算到岸。地图围堰/料道三格是每格两步的难行地，政治上的河段经营条款不等于角色绝对不能通行。

## 三章怎样改变这座城

第一章“夜水与借来的城印”先做眼前的事：付薪或真实欠条、救人、暂行配水、保存材料、限制或交出临时权力。妮萨雅承认曾为保两户配粮盖过空白行；贝鲁承认曾让城库货先上船；苏恩听见父亲当年用外来工替身条归来的真相。成年传令员乌鲁帮助送路条，也有想回去看望的母亲。

第二章“谁签下别人的明年”把有诱惑的交换变成可执行制度：工头要保续约和自己的罚金，城库要延长“一夜授权”，庙仓与伊杜用真实冬粮换取不同水权。证人开始遭报复，父债不再只是凭据，乌鲁的封套会被转让格式令实际扣住。泄洪、灭证、扣人和夺黑钥发生在中期；第三章还要面对受害者，而不是在按钮后直接出字幕。

第三章“第七门前没有空白人名”让前章人物主动回来：工班接受认责还是拒令；失屋者追问泄洪命令；船主要求归船和修船费；被找的证人需要真实保护；乌鲁和伊利会亲口拒绝被代签。玩家分别落实水务、决定掌印制度、处理最后债制。岸上两条线必须先得到成功或失败交接，肉身才可最后越过第七门或选择关门。

## 人与同伴

卡拉特欠薪是真的，假验收也是真的。他当年既想保工班下一季承包，也想保住自己罚金和屋子。中章本人承认才有认责的水权方案；已认责、工资已付且闸稳时，终章可动员工班自愿补闸，另可让他本人出庭。压案会给眼前粮与免罚，却引来工人拒令。伊利若获救后再被交为替身，他拒绝继续替队伍点工。

妮萨雅曾在空行盖印，后来亲自承认并分存。保护证人实际挡住一次报复，免费逐屋复核仍是有效证据路径。被强迫揭名后，她拒写追捕名单。她可以辞去城库职位，与已经具名同意的抄手限期轮值核名，不能替安全屋里的居民再签一次。

贝鲁的船仍有主人。他过去接受城库优先运货，现在要救人也要补自己的错。征船后留队是为了追船并送完家信，不等于继续免费给船；归船与四银修船费落实，才恢复新增自愿船务。有限渡次、两岸渡约、自愿出港与集中水务工程各有不同边界。

苏恩仍活着，父亲曾用外来工替自己归岸，后来年老自然死去；两人的经历不能混成同一笔债。苏恩可以公开父亲责任，同时继续悼念；也会因包庇留下未解遗憾。他主动提出的一季守门是本人决定，有结束日、不传给家属。其他同伴没有被队长一键签下。

## 七门与往返的空间因果

前两章以及第三章前两个门下节点，是七碗庙的活绳托身见证。身体留庙，塔玛、乌鲁和参与者自己的记忆维系返回；疼痛会沿绳返身，能带回的是记录与誓印。亡者无法沿活人的回路返回。这个原创机制允许三线交织，也不把不归之地变成任意肉身传送菜单。

各门各有付出与感官：第一二门收头衔并念城籍号，第三四门收香气与悼词、要求听见错名者，五六门校反印与父签，第七门要求实际决定谁能拒绝索取。最后裁债只有岸上交接齐备才开放，解绳后以真实归还、服务、强留、索债权或本人注销条款决定归来。

本城旧契只按特定城籍号索人。离港或换称呼无效；本人在前章确认授权后，可以放弃自己该号对应的本城屋产继承与登记权。终章“注销索引出港”仅作用于明确同意的户主，私名、记忆与留城者的号都保留。因此它与“未注销便出港、旧债仍追号”的结局有实质差异。

## 资源与代价

初始公粮十二、银二十四、净水一、恐惧零，都是游戏单位，不是历史物价换算。净水按瓮计量，是可消耗存量，不是水位或整个灌溉系统。岸上耗水用于验水、共同启闸封泥等有限用途；公开轮表或果园抵押关系才释放既存仓粮，不能靠一瓮水瞬间长出粮。实际供水制度另以工程与水权事实记录。

起手净水由七碗庙借供。末门将一瓮还入塔玛守的原碗，是归还维系托身的借水、洗去旧誓印；越权证据与修复反印同时成立才撤销代签。水不购买合法性，更不复活已死者。

八银抵押贷款把现金债与非法索人分开：谁拿钱，谁承担现金责任；取消索人条不免现金债，只有实付八银才清款，侵权历史永远保留。征用的船和家属抚恤也分别保留收据，完工与新得粮食不代替旧债。

每节点至少有一项无资源前置、无支付的选项；每章每线都有有限失败出口。免费高堤分两趟可救全四人，事前征得本人同意留重料及普通工资副页；原泥板已有保护，不因玩家不付船费而被强行浸毁。主动停止者仍有中章接人的实际选项。

## 黑暗后续与可修复的错误

泄洪会换出真实仓粮，也确实毁屋致人死亡；终章可实付救济和交命令，但不能复活。毁证写为砸散未烧泥板、浸洗刻痕、烧芦苇封套，不把泥板当柴。空白拨款能解除一部分眼前断粮，同时留下伪证与失去资格的两户。它们都有对象、得益和后续追索。

夺钥震裂反印，终章或中章末可以接回反印、重新听完申诉，再走合法撤约，不永久按一次战斗给“坏人锁”。黑印首次执行明确拘束乌鲁一夜并烙可转让号痕。后来解债、自愿服务或关闭制度都能明确释放暂扣者，却不能撤回那一夜与永久烙印；全部债制结局都有对应必现后记。

角色关系改变实际技能代价与帮助边界；船权、工班动员、分存与志愿范围由具体事实另外约束。数值不是替人同意的工具。

## 状态、结局与复核

每章路线 id 唯一，如 ch2-canal；第三节点写入 chapter:ch2:canal:settled，并且只做本路线的成功或失败结算。三线 settled 通过章门，不要求三线成功。最后门下节点有两条无反向依赖的岸上交接硬边，其他跨线要求只提供额外方案。

二十四归宿由债制 mode、政体、水务与不可逆灾变组合成互斥覆盖：四种黑印政治秩序、两位具体强制替身、四种本人志愿或注销退出、十一种撤约后不同城市、三种未解旧契。不存在靠结局数组顺序覆盖伤害的办法；任何实际终态只准匹配一项。政治结局不能偷偷吞并另签的水权，条件后记逐项保留真实水务、掌印机构、现金债、伤亡与同伴行动。

可复现完整九线成功的路线，按每章河渠→泥板→门下顺序，选择如下：

| 章 | 河渠 | 泥板 | 门下 |
| --- | --- | --- | --- |
| 一 | pay → ferry → share | copy → compare → limited | own → relinquish → truth |
| 二 | hands → confess → council | audit → hearing → commons | remember → witness → assume |
| 三 | workers → ferry → common | testify → public → commons | hear → repair → release |

这条路径无战斗、不强制揭名、不用替身，最终九线成功、零失败。所有二十四结局均有从正式初始资源出发的合法行动测试；另有独立零资源九线失败用例、章门拒绝、交织顺序与强制征债历史保留检查。3.1新增王的支持/限权/反对/利用/强役补救等十二项真实专项见 [GILGAMESH-NARRATIVE-RESULTS.md](../evidence/GILGAMESH-NARRATIVE-RESULTS.md)；原二十四结局的行动脚本在本新根重新回归，精确节点与跨章边见 [状态图](NARRATIVE-STATE-GRAPH.md)，具体归宿见 [结局矩阵](ENDING-MATRIX.md)。
