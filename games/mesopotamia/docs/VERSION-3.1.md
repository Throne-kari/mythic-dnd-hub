# 从候选v3到3.1

上一候选版《泥印未干 III · 七门之债》没有吉尔伽美什。此结论来自对实际交付文本的检索，见 `evidence/GILGAMESH-BASELINE-CHECK.json`；不把后来新增的人物回说成原版已有。

3.1在新目录中增量展开他的死亡恐惧、王库支援、河床工程、名役与当地授权之间的冲突。三章九线及24主终局继续存在；新增选择和旧选择的后果共同决定王的许可、实体工程、关系及归宿。具体实现数量、实际可达路径与文学审查以最终证据为准，设计稿本身不是通过证明。

王作为独立NPC有自己的目标与可改变的行动，不是玩家主角，也不占四名可控角色之一。关系与同伴关系分开保存；重大权利由具体承诺、契约和撤销事件确定。人物档案、HTTP状态与文件协议使用相同条件展开规则。

本版与v3使用不同campaign.id、端口和浏览器席位命名空间，各自创建运行数据。v3源码、ZIP和存档继续保留；本版不导入旧存档，以免把已经经过的无王剧情错误解释为已作王权决定。引擎可处理缺少NPC关系字段的状态，不等于承诺跨战役剧情迁移。

`evidence/baseline-v3/`归档上一版的验收；顶层新证据必须重新覆盖3.1实际文件。新肖像是游戏插画，UI参考图不是实机截图。没有实际浏览器、多设备或付费API通过声明。
