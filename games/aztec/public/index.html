规则与玩家指南

无需主持的冒险

默认“队伍共游”。你和朋友都是玩家，操作固定四人队伍、推进剧情、旅行和休整。游戏自动执行结果与敌方行动。认领标明席位身份，共游时不独占角色。

先商量再选择；当前局面的第一条合法请求立即生效。多人同时提交发生冲突时会刷新，请重新决定。

三章与三条主线

湖田、烟镜、贵骨三线跨越三章，并相互改变证据、物资、承诺和同伴归宿。点击路线卡查看进度，点击旅行线索前往任务地点。终章须先交接湖田与王权，才开放亡途的最后决定。

选项显示代价与可见后果。黑暗路线需要准备和真实执行；耗尽物资或战斗失败仍可前进。已发生的选择保存在行旅记录与旅程回顾。

地图与战斗

点头像选队员，再点地格移动。探索每次最多5步；战斗每回合2行动力、5移动力。墙与水阻路，桥可通行，高台每格耗2步，蚀影地格造成伤害。

攻击、防御和救治各耗1行动力。伤害为攻击力 + d6 − 护甲，最低1；攻击须在射程与视线内。防御本轮加2护甲，救治相邻队员耗1玉米、恢复5生命。敌方自动行动；可以撤退，倒下后可以扎营继续。

同行者与资源

耀特尔“黑曜破阵”削甲并尝试拉近敌人；伊策尔“镜纹封刃”远程削甲；内莉“苇舟疾行”增加移动；索科“净水救护”远程治疗。特技每战一次，信任达到+3时增强，降至−3则耗2行动力。

玉米供休整与救治，可可用于交易，净水与蚀影影响故事。扎营恢复全队，最多耗2玉米，缺粮增加蚀影。村社支持达到+3时扎营基础耗粮降为1。

Agent 玩家

打开“房间与邀请”，选择空闲角色，点“创建 Agent 玩家”。把返回的文件夹路径交给本机 agent，并让它阅读游戏目录的 docs/AGENT_PROTOCOL.md。它读取局面与合法行动，写入请求，游戏执行并回传结果；无需额外 DM。

接入使用你已有的 agent，不需要为游戏配置付费模型。HTTP 接入与文件夹接入共用席位、权限和修订规则。

存档与地图工坊

合法行动自动保存，服务器重启恢复房间。创建者同时具有命名存档、地图管理和 Agent 席位管理能力。邀请不携带席位凭据，浏览器按标签页记住身份。

地图工坊可绘制、撤销、设出生点、保存并载入，也可开启不发剧情奖励的独立遭遇。默认仅本机访问，局域网启动方式见 README。需要传统分工时可选真人主持。
