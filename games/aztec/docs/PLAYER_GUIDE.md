# 第五日之城：玩家指南

《第五日之城》是1–4人共享四人队伍的中文叙事战术冒险。游戏执行敌方回合、选择代价、章节和结局，不需要主持。

## 开局

双击游戏目录的 **启动游戏.cmd**，打开 [本机游戏](http://127.0.0.1:8856)，让启动窗口保持运行。选择「队伍共游 · 无需主持」，填写名字、选角色并开始。房间与邀请可以让朋友加入同一局。

四人始终组成队伍。默认共游中所有玩家都能操作队员，认领角色用来表示自己的席位。讨论重要决定后由一人提交，第一条合法选择立即发生，不会额外等全体投票。

让已有agent作为玩家时，在「房间与邀请」创建Agent玩家，把返回目录路径交给它，按 [AGENT_PROTOCOL](AGENT_PROTOCOL.md) 接入。它和真人共享当前房间，不需要再设AI主持。

## 你们要处理什么

新建的湖城伊斯塔兰遇到太阳停顿，三条命脉同时出问题：

| 主线 | 表面危机 | 你们真正决定的事 |
| --- | --- | --- |
| 湖田与供日 | 粮舟被扣、盐水漫田、留种粮受征 | 谁来供养、负担有多久、谁能拒绝、谁有路可走 |
| 烟镜与王权 | 住户失名、证词覆写、紧急印无到期 | 怎样取回过去，谁能握印，谁能查问握印的人 |
| 贵骨与亡途 | 骨名错置、归途欠粮、活身被纳入契约 | 本名归谁，重逢多久，谁的身体能被拿来付代价 |

每章三条线可以来回交织；本章三线完成交接后才进下一章。第三章先决定岸上田务与城权，再走最后的亡途。

## 认识四位同行者

- **耀特尔，日盾卫**：近战耐打，特技拉近敌人并削甲。他开过粮门救人，也押过拒供者，愿面对有姓名的追问。
- **伊策尔，画卷师**：较远射程，特技削弱敌甲。她能识旧纹，要保住本人决定画什么的权利。
- **内莉，湖田渡者**：远射与穿行，特技增加本回合移动。她愿救人，船田和未来班次仍需本人同意。
- **索科，亡途医者**：支援与救治，特技消耗一份玉米远程恢复队友。他希望再见弟弟，也尊重弟弟不想永久回返的愿望。

信任达到3，特技增强；关系降到−3或更低，特技需要2行动点。剧情中的背叛、赔补与归还按具体事件记录，不能只看一条好感数值判断所有事情是否解决。

## 看地图和选任务

点头像选队员，点可行地格移动。使用主线卡与旅行线索前往相应地图，不需要把四个人都走到兴趣点才允许阅读当前场景。五处地点是湖港、湖田、画院、太阳台与骨渡。

普通地面一格一步，困难地形一格两步，危险地形踏入会受伤。修闸、征粮、改写和运粮会在地图上留下便桥、深沟、烟痕与粮堆。

地图工坊可以另画地形与发起固定演练；演练不推进主剧情，不发主线奖励。

## 四种资源

| 资源 | 用途 |
| --- | --- |
| 玉米 | 队伍口粮、普通救治、部分施工、路粮与有限供养 |
| 可可 | 工料、采购、许可、赔补与文书劳动 |
| 净水 | 有限存量，按壶用于救护、封泥、试验与镜术 |
| 蚀影 | 失名、胁迫、亡途与失败留下的侵蚀记录 |

这些是队伍可支配份额。城里整季收成、田权与日台工程另有实际记录，花一份队粮不等于喂饱全城。

每个选项会显示即时代价与明显后果，资源不足的选项不会让你误扣出负数。善意也可能需要工料；强取往往马上有利，但会让真正受损的人在后面回来追问。

## 战斗

每名队员每轮有2行动点与5基础移动力。攻击、防御、救治、特技消耗行动点；移动看剩余步数，距离与墙壁会影响攻击或技能。

常用做法是先用削甲者破开防线，再让远射者与日盾卫集中攻击；索科尽量保持能看见队友的支援位置。防御增加护甲，别把全队留在危险地格。

敌方自动行动。剧情战斗可绕开，也可撤退承担结果继续。胜利奖励在敌人全被击败后才发；开战不等于已经救到人或拿到物。全员倒下后可休整恢复，粮不够也能靠施舍站起来，但蚀影会增加。

## 选择与结局

本作没有一个单独决定一切的善恶条。你们做成的工程、给过的授权、真正执行的伤害、谁的名字保住、谁的财物归还，都会继续生效。

到最后，能采用的方案取决于此前准备。强大方案不保证值得使用；神明能给真实力量，最后仍由你们选择。主结局有24种，个人与旧账后记会进一步区分同样制度下的不同经历。

每条主线都能免费承认失败并交接，资源耗尽不强迫重开。最后仍能承担夜色与迁居的后果，不需要刷出所有高级方案。

成人黑暗路线包含强迫供役、记忆改写、永久拘束同伴与活城供亡者等后果。它们会得到真实利益，也会把命令执行到受影响的人身上；游戏不会在尾声自动让这些人原谅玩家。

## 存档与继续

合法行动会自动保存。房间创建者可在界面保存命名槽位或导出；重启服务后接续本作房间。数据目录与其他神系游戏独立，不需要移动旧存档。

要查看完整数值可读 [RULES](RULES.md)。想保留剧情悬念时，先不要打开 [STORY](STORY.md)、[ENDING-MATRIX](ENDING-MATRIX.md) 与主持手札；它们是完整剧透材料。
