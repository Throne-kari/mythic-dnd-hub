# 第五日之城：游戏规则

本作是固定四人队伍的中文叙事战术游戏。预设剧情、敌方行动、检定、资源、章节和终局由服务器处理，默认不需要主持人。规则采用本项目的原创 d6 战术体系；人物、场景与阿兹特克神话改编内容为本作创作。

## 剧情与资源

玉米用于治疗与休整，可可用于交易，净水和蚀影参与剧情条件。底层字段依次是 `grain / silver / water / dread`。每项选择列出费用与后果；只有当前地图、当前章节、前置事实和资源都满足时可以执行。选择只能结算一次，自动记录 `node:<节点ID>`。

每章有三条交织主线，全部收束才开放下一章。成功与失败都能收束主线，已经发生的死亡、背叛、授权和物资损失会留在后续内容中。最终选择受前章行动约束，不能在尾声随意换取一个尚未建立条件的政体。所有章节收束后封存唯一匹配的主结局，并附全部适用的同伴与世界后记。

`requires` 的条件全部同时成立：`flags` 必须已有，`notFlags` 必须没有，`resources` 表示最低数量，`completedRoutes` 表示至少完成多少条路线。NPC 关系下限和上限分别用 `npcRelationships` 与 `npcRelationshipsMax`。关系分数不代替具体承诺与实施旗标。

选择先扣 `cost`，再结算 `effects`。战斗选择的普通效果在开战前发生；`encounter.reward` 只在胜利后发放。败退记录 `encounter:<遭遇ID>:lost`，不会补发胜利奖励。失败路径继续接受已发生的代价。

## 地图与工坊

点选队员后在地图移动。`.` 地面与 `=` 桥每格消耗1移动力，`^` 困难地形消耗2，`*` 危险地形经过时损失1生命；`#` 墙与 `~` 水不可进入。墙阻挡视线，棋子阻挡通行。探索时每次最多走5移动力，周围3格逐步揭开；旅行会在新地图出生区域安排四人合法站位。

剧情决定可以改变固定地图的桥、泥障、危险和兴趣点。变化从已保存的事实重新展开，撤销许可不会自动删除已经建成的实体。米克特兰（`underworld`）中，亡影阵营 `shades` 低至 -4 时危险格伤害提高至2。

房间管理员可进入地图工坊，新建独立地图、设置地形和出生点、保存并重新载入。工坊不覆盖固定地图。自建图可开启「堤岸巡守」或「黑镜亡影」遭遇，使用相同战斗规则；工坊遭遇不奖励剧情资源，也不完成主线。撤退与全员倒下仍有通常损失。

## 战斗与成长关系

四位队员依次行动，然后敌人自动行动。每轮每人有2行动点、5移动力；攻击、防守、治疗各消耗1行动点。移动不消耗行动点。行动点用尽自动轮到下一人，也可结束回合。

攻击距离按横纵格数相加，必须有视线。伤害为 `max(1, 攻击 + d6 - 敌方护甲 - 防守加值)`。防守提供2护甲，持续至自己的下回合，不能叠加。普通治疗消耗1玉米，为相邻队友恢复最多5生命并救起倒地者。倒地者不能行动。

| 角色ID | 独特技能 | 效果 |
| --- | --- | --- |
| `yaotl` | 黑曜破阵 | 3格内可见敌人护甲 -2，并尝试向自己牵引1格 |
| `itzel` | 镜纹封刃 | 4格内可见敌人护甲 -3，持续本场战斗 |
| `nelli` | 苇舟疾行 | 本回合额外5移动力，无需目标 |
| `xoco` | 净水救护 | 消耗1玉米，3格内可见队友恢复最多8生命，可救起 |

独特技能每场战斗每人一次，通常消耗1行动点。同伴关系达到3时，前两人的削甲额外1、疾行额外2步、救护额外2生命；关系低至 -3 时技能改耗2行动点。普通行动仍可照常使用。

撤退使蚀影 +1，倒地队友以1生命离场。全队倒下使蚀影 +2、损失最多3可可，需要休整。休整全队恢复，通常消耗2玉米；居民阵营 `commons` 达到3后只耗1。玉米不足仍能休整，每缺1份使蚀影 +1，因此不会因零资源永久卡住。

## 存档与结算

每次合法行动由服务器完整校验，成功后才一次性更新资源、旗标、日志与修订号。非法行动不扣费。随机数种子保存在进度中，读档后骰序连续。`createState`、`applyAction`、`legalChoices` 和 `publicState` 为纯规则接口。

房间、席位与命名存档放在本作 `data/aztec-v3/`。自动档随合法行动原子保存，重启恢复本作房间；管理员可另存命名槽位。读档提高修订号，不改变席位、房间模式或管理身份。本作以 `aztec-fifth-sun-v3` 标识战役，不自动迁移其他神系、旧版存档或凭据。
