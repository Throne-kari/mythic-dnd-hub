# 第五日之城：完整剧情与人物

本文件含全部主线与结局剧透。实际可执行内容以 `content/campaign.json` 为准；本文件用于阅读故事和追索选择，不需要主持逐项裁定。

伊斯塔兰是一座建城仅一代人的原创湖城。第五日的太阳三度停顿，执政者把供日、居民登记与亡者归途并成可以相互索取的契约。你们不是替神明完成既定正确答案的人，而是四名拥有旧罪、亲人、财产与拒绝权的同行者。三条线分别回答：谁负担活下去，谁能说出过去，谁有权结束或重新开始一次生命。

## 第二章：真正开始偿付

第二章跨数个有真实劳动与供给的试行日，行动次数不是小时。三种黑暗技术都先产生可见收益或损害，不在最后凭空解锁。

| 节点 | 场景 | 实际抉择和后果 |
| --- | --- | --- |
| ch2-canal-1 | 借粮的归还日 | 真还四粮、按明价买早收粮与窖水、领取保闸田户志愿维护物，或公开欠签继续延期 |
| ch2-canal-2 | 船钥从谁手里归还 | 赔补并重签、先还舟田不索原谅、再强运一轮，或在无背叛情况下签有限渡次 |
| ch2-canal-3 | 让太阳动一寸的工程 | 建有限共养网、让阶庭负担一季征粮、把三名拒供者押进一班日轮苦役，或停工交接 |
| ch2-archive-1 | 耀特尔的旧矛 | 让家属参与真问责、受终身豁免、胁迫再押三人，或先保留公开证言不裁结 |
| ch2-archive-2 | 把恐惧擦掉以后 | 按阿玛本人同意修回一段来处、改掉三名粮工的征粮证词、战胜守镜者毁一面公镜，或拒绝本轮改写 |
| ch2-archive-3 | 四张明日的空椅 | 写共同、阶庭或豹冠章程，或不统一。章程是准备，终章还需真正接仓钥和发令 |
| ch2-descent-1 | 欠给亡者的三份玉米 | 实送三粮并结已有试贷、按原价买回贵骨、免费还阿耶尔路牌核名，或承认欠项仍在 |
| ch2-descent-2 | 索科站上日柱之前 | 可停止的血样试验、强绑索科一轮后拆柱放人、战胜旧约反噬获安全原型，或停试 |
| ch2-descent-3 | 特莫提出的拒绝 | 特莫只愿一夜返访；乌娜和阿耶尔各作决定。保留有限返访、已成日芯或亡粮方案，或把未成事实交接 |

三项关键黑暗历史：

- **公共改写**：三名粮工真的忘掉征粮令的责任经过，队伍得到六玉米、四可可，露庭出现危险烟痕。只抹事件证词，不把他们的本名一并删除。
- **强绑试验**：索科完整身体被强接日柱一轮，停止声被鼓声盖住；队伍得到八玉米、四可可，太阳稳定几日。一轮结束后实际拆柱，索科带伤回队。只有这次真正试绑才给永久日芯原型。
- **亡粮通道**：三份本城原粮离开种粮库，双主回赠两壶生前封存净水，骨渡堆粮改变地面。双方完成有限交易；原型后来可以被扩大为强制活城契。

有限试验和付费工程同样有真实效果。战胜反噬可得到安全返访原型，最终也可不经过那场战斗，用更多工料重新建路。

最后启动以后，同伴被永久索取、全民覆写或活城种入亡界才真正发生。预刻日芯时，同伴仍能行动与反对；永久离柱权在实际终局启动时被夺走。

## 六种终局不是同一个胜利

有限共养只承诺一季，返访只给愿来的亡者一夜；两者都把下一次协商留给本人。停止续日让城进入真正夜色，并开始有限迁居与谋生，不凭旁白补出粮食或保证自然晨光。

永久日芯让选定同伴清醒且不可离柱；全民改写让城内网中居民记得自己一直愿意，并以未来真实记忆持续供日；活城种名让留城住户与屋舍生根亡界，姓名成熟供粮且无法单方退出。已迁离的人不被跨湖自动追回。

每个方案分别落在共席、阶庭、豹冠与分治四种已经实际形成的权力结构中，因此有24个独立主结局。具体差异见 [ENDING-MATRIX](ENDING-MATRIX.md)。42项条件后记继续记录同伴、旧账、骨的现物、船田、种粮、试绑与修复，不把主结局的明暗替换成事实。

## 战斗与失败前进

五场剧情战斗：扣舟队、收卷者、守镜画影、日柱反噬、最后种子车。战斗都是可选的真实回合遭遇；奖励只在胜利后发。败退留下遭遇失败记录，后继节点仍开放，可承担结果继续。

每条线第三节点都有免费交接；最终授印可以免费分治，最后终局可以免费停日。净水、粮和可可耗尽不会使剧情困在没有可选项的节点。失败不会被偷改成胜利，也不会成为必须重开存档的隐藏门槛。
