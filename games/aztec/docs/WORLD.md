# 第五日之城 · 世界与队伍

## 城为何悬在一线

第五日之城是一座本作原创的湖上城。城中以“五日”称现在这轮太阳照耀的时代；人们知道旧的世界曾经结束，却不知道眼前的饥荒、暗日与亡河逆流究竟预示什么。三种答案同时争夺城市：让水和种子重新养活人，让一个声音替所有人决定明天，或从死者之国借回创造生命的贵骨。

神会到场，也会行动。羽蛇神的风能让停滞的日轮移动；烟镜会将统治者不愿承认的愿望照到城墙上；亡界双主能够放行或扣留贵骨。人的决定同样真实：转给亡界的种粮不再留在活人的碗里，改掉的证词会使受害者失去追索的对象，被绑上太阳台的人不能因为城中又亮了一天就自动获得自由。

湖港、画院、王署、供养制度与所有本城人物均为原创。它们借用墨西加／纳瓦材料中的神话母题构成奇幻故事；游戏里的暴政、记忆改写与亡粮契，是本城走到的岔路，并不充当整个文化的画像。纳瓦语言与社区今天仍然存在。

## 五处可以走进去的地方

| 地点 | 日常生活 | 冲突与实际地图作用 |
| --- | --- | --- |
| 芦苇湖港 | 舟工称粮、亲属接船、商人修补芦苇席 | 西岸粮棚连着两道伸入湖中的栈桥。桥头适合守住通路；征船会留下搬运障碍，离城线会出现新的灯下浮栈。 |
| 奇南帕湖田 | 种田人用泥、根与木桩维护田台，顺渠运粮 | 双纵渠与横渠将地图分开，桥的位置决定绕行距离。共修田闸会加出两座中桥；征粮会压坏田埂，离乡后会留下空田。 |
| 烟镜画院 | 画师保存图卷，见证人让后代知道自己是谁 | 四组卷架围着露庭形成环廊。实改证词会让危险烟痕出现在庭中；共议会把中央通路清出来。 |
| 双阶太阳台 | 雨台收种子和供水，日台分火种、守望天光 | 两座分开的阶台要攀登，中央轴道可以绕行。试绑日柱会留下灼痕，分火与俘日会造成不同的可见地面。 |
| 亡途骨渡 | 亡者各有归处，灰犬阿乔在旧渡线留下爪印 | 折线石脊穿过黑水，旁路可以避开一段刀风。到亡界的粮会堵住入口；一夜返访的渡舟能接出一座短桥。 |

地图中的水是不可步行区域，墙会阻挡通路和视线；桥可正常行走，困难地形每格消耗更多移动力，危险地形在踏入时造成伤害。每张地图都有足够四人站稳的抵达区域。地点图标用于辨认场所与后果；剧情通过当前可用事件推进。

## 三条主线

### 湖田供养

这条线首先问：下一季还能由谁决定种什么、吃什么、把水给谁？

共同修闸可以救眼前的田，却不能单凭一次善举解决分配。种田人要知道共同劳动会不会变成新的无偿徭役；舟工要知道出城是否仍有自由；已经饿过的人不愿用一句“全城利益”换走最后的种子。

终章可以落实共同田台、王粮征收、带种离乡，也可能让供养秩序失去执行者。这里的善果要落在可使用的水、粮和退路上，恶果则可以非常有效：库存增加、运输整齐、命令迅速，同时住户失去拒绝交粮的办法。

### 烟镜王权

这条线问：谁有权让一种记忆成为全城的真实？

烟镜并非只会说谎。它善于指出共议的拖延、见证的偏私与英雄的自爱，然后提供一个能立刻见效的权柄。代价不在抽象的“腐化”，而在具体的人身上：三名粮工的名字仍在，关于征粮的证词却从公共记录中消失；掌权者可以把受害者的经历换成自己认可的说法。后来为愿意取回者修复证词，也不会抹去覆盖过的痕迹。

共议、神庙摄政、冠权与权力破碎各有延伸。神庙并不因为用神的名义统治就天然正确，居民共议也必须面对自己的决定。队伍可把烟镜当作对手、盟友或共同体无法垄断的见证者。

### 贵骨亡途

这条线问：延续生命需要取回死者的什么，又该由谁回答？

贵骨援引羽蛇神下入亡界、取得前代人骨以创造人类的母题。本作让这个创造问题重新出现：活人能否向亡界借回新的生机，又是否愿意把自己的姓名与屋舍交给亡界供养？亡者是否只要被爱就必须回来？死者的亲人、亡界双主与需要粮食的城民都不会给出同一个答案。

归还、互惠与有限度的延续有其代价；囚禁、改写与亡粮契也会带来切实收益。亡粮契把活城留居者和屋舍种入亡界，成熟的姓名成为供养，住户无法退出。黑暗不来自一句“你们变坏了”，而来自玩家亲手建成的制度照常运转，人们一面受益，一面失去离开的路。

## 神圣者如何出场

| 名称 | 本作的动机与行动 | 对话时抓住什么 |
| --- | --- | --- |
| 羽蛇神克萨尔科亚特尔（Quetzalcoatl） | 希望生命继续，也希望创造者承担创造的代价。他以风、螺声和贵骨参与决定，不会替队伍把城变好。 | “你愿付出什么”应包含他自己；若他要求别人受苦，玩家可以追问他过去的选择。 |
| 烟镜神特斯卡特利波卡（Tezcatlipoca） | 揭露欲望与权力的实际面貌，考验统治者。他可以真诚赞赏果断，也可以让掌权者成为自己最满意的俘虏。 | 他提供的诱惑必须解决一个真实困难，并说得出谁会失去什么。 |
| 亡界双主：米克特兰特库特利、米克特卡西瓦特尔（Mictlantecuhtli、Mictecacihuatl） | 共同守住亡者与贵骨的去向。两位有能力放行，有权追索，也会听见交换条件。 | 不将“死了”自动解释为“有罪”；他们处理的是归属、往来与界限。 |
| 雨与日火两座台 | 雨台借鉴特拉洛克，日火台借鉴维齐洛波奇特利相关的双神庙空间。 | 湖田、供养、火与战争之间的联系提供背景；本作的具体日柱仪式是原创。 |

这里的神都拥有自己的判断。玩家亲近某一位，并不等于接受所有要求；与神争辩，也不等于对整个信仰宣战。重要的是说出条件，并让条件在城市里产生后果。

## 四个不能互换的人

四位队员的具体职业、能力和数值以游戏角色卡为准。下面是可直接使用的扮演入口，不额外赋予技能或隐藏任务。

- **耀特尔（Yaotl）**：你曾违令开粮门，也曾押过拒贡者，知道执行一项命令如何把责任分散得无人承担。面对王署时，问清自己是在保护谁的身体，也让自己的旧令能被追问。
- **伊策尔（Itzel）**：你辨得出覆盖下的旧笔，也曾删去一段记忆救下养母阿玛。你可以保守别人的秘密，却坚持事件留有反证；你的手不是任何人的公用权杖。
- **内莉（Nelli）**：渡舟是你的，母亲留下的湖田也是你的。你愿意救人、运粮，却要自己决定渡次与班期；一次善意不能自动变成别人永久征用你的理由。
- **索科（Xoco）**：你替活人止血，也替死者保存本名，想让弟弟特莫安心走完骨路。若有人说你是全城的希望，先听清这句话之后有没有允许你拒绝或离开的路。

队伍意见可以不同。合作的意思是共同承担落地的选择，而不是强求四人使用同一句道德判断。让人物在一次决定后说出自己愿意继续同行的理由，会比在每个选项前争论阵营更有用。

>
> 粮棚里有人在称重。太阳台有人在量绳长。画院里，一个画师正把一张已经画好的脸涂白。
>
> 渡船人问你们先往哪里去。他没有问你们信哪位神。
