# 合作与启动

安装 Node.js 22 或更新版本，运行 `node server.mjs`，打开 **http://127.0.0.1:8856**。无需安装 npm 包。也可在本目录运行 `node server.mjs`。保留启动窗口，结束时按 Ctrl+C。

默认创建「队伍共游」房间，1–4位玩家即可开局，无需主持或 DM。创建者也是普通队员，同时拥有地图、命名存档与智能体的管理能力。选角色代表席位身份；共游时任何队员都能操作固定四人队伍，队员断线后其他人可以继续操作并推进战斗。

剧情、旅行、休整、撤退和终局由任一队员提交。先商量再点击；最新修订上的第一条合法请求立即生效，不等待投票或队长。两人同时提交时，后到的过期请求会收到409并刷新，由该玩家重新选择。系统不会把旧意图自动重发。

## 邀请与恢复

在房间面板复制邀请地址，朋友打开后认领空闲角色。邀请不含管理令牌。四个身份由真人席位和文件玩家共同使用，已认领角色不会被新席位抢占；共游的全队操作不依赖认领者在线。

浏览器标签页保存本席位，重开游戏可恢复原席位。服务器重启会恢复本作房间与文件玩家。自动保存和命名槽位分别保存进度；读档不会恢复旧权限、切换房间模式，或清空防重复提交的请求账本。

| 席位 | 队伍与剧情 | 管理 |
| --- | --- | --- |
| 共游普通玩家 / 玩家智能体 | 操作全队，推进剧情、旅行和休整 | 不可保存/载入工坊图、命名读档或创建智能体 |
| 共游创建者 | 同上 | 工坊、命名存档、导出、创建智能体 |
| 可选主持桌玩家 | 只操作自己认领的角色 | 无 |
| 可选主持 | 全队与剧情 | 全部房间管理 |

传统主持桌仅在新建房间时选择；默认开局不需要这个席位。神明和关键 NPC 由故事规则呈现，不成为可认领的四人队伍成员。

## 局域网

默认只监听本机。要让同一局域网的朋友访问，在本游戏目录的 PowerShell 运行：

```powershell
$env:HOST = '0.0.0.0'
$env:PORT = '8856'
node server.mjs
```

房主仍可打开 `http://127.0.0.1:8856`。朋友把邀请地址中的 `127.0.0.1` 换成房主的局域网 IPv4 地址，保留端口与其余路径。使用朋友实际访问的地址打开房间后再复制邀请，链接会采用当前地址。本包没有替用户开启防火墙、隧道或公网托管；局域网是否可达取决于电脑现有网络设置。实际跨设备连线需由朋友接入验收。

`PORT` 可更改端口，`HOST` 可选择绑定地址。私有数据默认位于 `data/aztec-v3/`；只有显式设置 `AZTEC_DATA_DIR` 才改用其他位置，不读取其他游戏的数据环境变量。

## 玩家智能体

房主在智能体面板给空闲角色创建「玩家」文件席位，把返回的文件夹交给智能体。它读取 `snapshot.json`，决定当前合法行动，写入 `inbox.json`，由同一服务器校验并执行。快照公开当前轮次、可执行剧情和具体合法动作。玩家智能体在默认共游房与真人队员一样可操作全队，无需先建立 DM。

具体命令、回执、重连与可选模型适配见 [AGENT_PROTOCOL.md](AGENT_PROTOCOL.md)。核心游戏和文件协议不需要模型密钥，游戏不会自行启动模型或智能体进程。
