# 玩家本：你们是账房合伙人

本次是1190—1191阿卡围营的原创账房故事。城的受降与历史处决保留为既有历史背景；你们能真正改变的是当事人的去处、文书和实物的去处、谁付款和未来由谁履行承诺。开桌可要求略述战争或关系细节；不因拒绝秘密或亲近扣任务资格。

四位角色固定3级，按现有D&D 2024/SRD 5.2.1卡行动。按钮是常见方案，真实法术、工具、治疗、救援和另提办法仍有效。说话不因为剧情紧张就自动消耗回合；场景跨月也不自动恢复资源。独立人物只能同意自己有权同意的东西。

你们的起始共同物件如下。粮袋是实际同类存粮；不是新货币，也不是阿卡史实物价。

| 物件 | 实际归属与用途 |
|---|---|
| 六袋账房豆粮 | 队伍库存 `food`；交换、捐赠、旧债、个人释放各自真实扣袋 |
| 栈账正本 | 队伍；可封存交独立抄手，届时队伍只有副本与收据 |
| 铁马烙印 | 队伍遗产；若为个人释放留置，原物留萨利姆，队伍不能再带走它 |
| D-1旧债条 | 队伍实际持有；向船家欠两袋；付清或替代约时原条交回 |
| 守夜履约合同 | 已完成劳动的证据，不再要求重复做一夜才能作证 |
| 哈利姆的铜水罐 | 始终归哈利姆；每日一份只是这件原创物的限制，不封你们合法造水能力 |

每个时段会遇到这些公开成本：

六袋减去A02最多两袋、D-1两袋、个人释放两袋，正好可全部兼得；额外一席用独立援粮，不从这六袋重复扣。真实付不出的成本会被拒绝，不会生成负库存。你们也可以保粮给自己、留下未结债，后果是明确合同，不是善恶分。

每人可选一条公开背景：亲手做过守夜工作、认识一位抄手、曾保管一件托管物、曾沿岸路送人。也可换成自己愿意的理由。没有必须公开的背叛秘密或强制恋爱。与成年NPC的友情、亲近、拒绝或淡出都保留同样的任务路径。

允许一段公开摘录，不等于允许参加会面；允许会面，不等于允许下一程迁居。每次新答复须来自实际同场、清醒且未受魅惑的本人。暂不能答复者仍可得到必要救助和照护，保留原伤势与未定去处；不需要公开人名才能完成本切片。具体按钮和保管旁路见[同意与在场修订](AGENCY_AND_PRESENCE_FIX.md)。

离开每个节点前，问三件事：这是谁的原物；这是谁真正同意的事；谁还有一项未履行的窄约。持有名字不代表持有人身，救过一次不等于得到终身代言权。
