# 当前数字内容合同

此文档对应公共核心清单 `20261020T155611Z`，不代替引擎实际校验。`data/campaign.json` 保存本包真实章节、节点、NPC、物件、遭遇、规则卡和场景；`chapters` 的 `scene` 对应 `scenes`，每个可选方案有稳定ID、条件、成本、结果与跳转。三弧包从HUB选择实际章节，四节点一弧独立结束；不得把三弧连算成一场已验证的4–5小时。

条件支持真实小时 `timeAtLeast/timeAtMost/timeBefore`、钱物/事实/地点及 `npcAlive/npcCanRespond/npcCanConsent`。存活不等于能答复；新同意必须本人实际同场、HP大于0、未失能、未受魅惑或支配。救助、既有债权、既有物权不自动变成新的签署同意。具体每条数据仍需作者明确引用对应条件。

钱为实际GP/个人钱袋或本包明确数量字段；费用和消耗通过 `cost/consumeItems` 扣除。`privateFacts/ownerId/visibility` 由服务端按实际席位过滤，不能把私人物件ID猜中当作所有权。`narrativeTransfer` 只为可信作者效果交付NPC当前实际持物，不能给原始命令、其他玩家或费用检查扩权。物件转移同步实际库存，切换遭遇保留原NPC伤势及死亡，不另造同名健康替身。`conditional` 再按实际条件写后果；`goToChapter` 选择真实章节。不同故事的专用字段以各包 `CONTENT_MAPPING.md` 及父级主持本/后果矩阵为准。

规则行动保持SRD法术位、材料、目标、距离、持续时间和意愿要求。原数据没有快捷按钮的合法行动由主持按原规则裁定；GM裁定命令不等于引擎自动实施完整物理或经济系统。游泳额外移动、桥面与飞行通行按实际能力；高差、急流、屏息等复杂情形仍需主持。

地图为5尺格10–500尺场地，房间/墙/门/地形/水面是实际几何。`mapDrafts` 保存草稿，`mapEdits` 保存发布修订，原始campaign图保留。发布检查房间revision、草稿revision、棋子占地及战斗状态；玩家JSON/SVG过滤主持标记/私密几何/来源笔记。地图导入不等于剧情或NPC任意迁移，发布后的同桌行动使用已发布几何。

生产写入通过RoomStore事务复制后提交，失败不落盘，命令ID去重、旧revision冲突拒绝；房间存档、三个手动槽、撤销与地图修订一起恢复。直接调用底层apply的开发脚本不能替代生产事务测试。完整程序路线、边界夹具、HTTP席位和真人游戏分别记录。
