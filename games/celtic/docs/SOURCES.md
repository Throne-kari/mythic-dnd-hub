UCC保存的是不同年代的文学文本及现代编校，不是一部统一“凯尔特圣经”。本作以爱尔兰的神话、英雄与航海叙事为主，威尔士材料在词条与银庭谈话中明确标出，不把地域传统拼成一套自古统一的神谱。

原创的杜恩·卡奥兰、穆伊琳、德雷赫、卡苏、伊蕾丝及三同伴，不冒称原典人物。穆伊琳作为土地化身有自己的声音，仍无权替住在土地上的每个人答应征收。丘民、潮民、王庭与记名师都存在内部差异，不把压迫写成某一族群的天性。

本作没有复制上述译本的长段文字。结局中的役尸丰年、永冬配给、续龄贵族、整代流亡、记忆宴资和消名统治，是根据本战役既有行动展开的原创后果，不作为古代真实法律或宗教仪式介绍。
