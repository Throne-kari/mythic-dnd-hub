# 人物与各自想要的东西

人物不是换取一种结局的钥匙。同伴的信任数值记录公开立场，不能兑换劳动、服从或替本人签约。固定四英雄是玩家席位，三名叙事同伴另有营地交谈与随行动变化的态度。

## 四名英雄

| 席位 | 人物 | 过去与现在的目标 | 故事中的个人冲突 |
| --- | --- | --- | --- |
| p1 | 芬恩，34岁，护路战士 | 曾替旧王征走最后一袋种粮；想让自己的盾真正护住能生活的人 | 盾可以救人，也可以替夺粮、役尸与唯一王令堵住反抗者的门。他必须承担自己护住的秩序 |
| p2 | 奈芙，29岁，荆林游侠 | 自己的田曾在抄来的地契上消失；愿相信人的脚印与可走的路 | 开路与封路都需要她的本领；永冬、代际流亡和消名城会使她的地图成为边界另一侧还存在人的证明 |
| p3 | 艾妲，38岁，守火祭司 | 行旅医者，供奉布里吉德；照顾活人，也希望死者能停止劳作 | 治好一个被束缚的人可能只是把他送回下一班苦工。她既要判断何时救命，也要判断何时帮助解除命令 |
| p4 | 布兰诺克，31岁，欧甘术士 | 刻字人与识读者；相信记录应留下更正的位置 | 名字、誓文与故事都能成为证据，也能成为绞索；他最后留下的是人的原话，还是王庭唯一能被听见的词 |

四英雄的能力沿用合作底座的固定职业机制，不因后记文字自行改变。后记按已经实施的世界事实追加：会护路的人可能成为自由村落的教习，也可能成为更精确的镇压者；不会由“队伍赢了”自动替个人洗去责任。

## 三名叙事同伴

### 席芙拉（Siofra）

她随失踪七十年的船返回，身体仍是三十六岁。妹妹已经去世，妹妹的女儿老去，下一代的身高又与她相仿。她想见自己真正还在世的亲人，学会在今天生活；她不要求每个人继续扮演七十年前等待她的人。

她会认潮、量船、组织本人愿意做的一季引航。抽走门卫或沿岸人的余生以后，她仍提供已经知道的事实，拒绝再为盗年掌舵。永冬与永宴对她不是同一种诱惑：前者把生存压进配给，后者把想家的一部分自己拿走。有限渡航、缓慢老去、与后辈共居和封门之后留在人间，也分别需要她承受不同的失去。

### 费尔加（Fergal）

四十二岁的王庭守卫，曾被“不许拒客”与“不许暮后开门”两道旧誓缠住。摄政利用它们的冲突，迫使他交出求庇护的友人。他要说清命令由谁发出，不让“我守了誓”成为参与伤害的最后理由。

他可以以自己的名义守一季，也可以失去王家席位后斩断旧誓。活人姓名被改绑到队伍手里时，他退出新命令的执行；相冲誓禁成为武器时，他不会替它挑下一个对象。有界王权与新誓若要得到他协助，必须真的容得下拒绝，而不是只在文本里印一个退出日期。

### 梅尔（Mael）

四十六岁的记名师，曾把六名反对征收的人写入死亡册，其中四人仍活着。他带来的底稿有院长的命令，也有自己的副署。他想让原稿被公开，让还活着的人拿回名字，并接受别人追问自己的那一笔。

保留副署会让他承受真实责任；刮掉副署并不会使他更清白。队伍卖出避难者的名字后，他停止提供新名单；把旧册换成自己掌握的密册，他也不再署名。还名、共证新誓、拆院和无名避所分别让他成为教人识稿的人、可被纠正的书记、失去自证档案的人，或只记床数的接待者。黑暗结局不能借他的悔意强迫他继续作恶。

## 神异与政治人物

| 人物／力量 | 独立目标 | 愿意交换与不能代替的事 |
| --- | --- | --- |
| 穆伊琳（原创土地化身） | 让土地摆脱被擅自永久献出的收成，保有自己的生机 | 愿为具体土地范围作证；她不是所有住民的所有者，也不能用自己的同意替住户献身。强迫荆冠会把她与统治者都变为根的结构 |
| 伊蕾丝（原创潮使） | 维持自己所属银庭的通路、界限与可兑现交易 | 提供邀请、分季与关门的价；不保证凡人每种愿望都能兼得。丘庭内部也有主张吞年与主张有界往来的不同者 |
| 马纳南 | 以原典潮上意象进入银潮主线 | 本作实际可交涉者主要是潮使；马纳南不出面替玩家挑善恶，不是解决三线冲突的万能裁判 |
| 莫瑞甘 | 战事与预言母题中的不确定征兆 | 乌鸦会出现，不能因此推导“神赞同我的路线”。不以一次兆头消除玩家对实际命令的责任 |
| 摄政德雷赫（Dreoch，原创） | 让一个濒饥的王国继续存在，并保住能调动资源的统治结构 | 愿让出王位与部分权柄，让队伍签自己的一格；也会以粮、献约和命令转移代价。退位、被击败或交易退场不自动取消旧结构 |
| 院长卡苏（Kathal，原创） | 维持记名院对继承、活名与亡者的最终解释权 | 可以丢掉一本册而把结构交给新王。他不是只靠一场击杀就能拆除的全部问题，名字掌握方式才决定结构是否延续 |
| 村议者奥兰（原创） | 让人有种可播、有粮可领，分配能被逐户核问 | 要求粮的来处留下记号；尸耕粮即使能救人，也不能被改写成没有来源的天赐 |
| 守陵人罗丝（原创） | 让自己父亲及本地亡者能安葬与被记得 | 可以给出实际陵路与见证，不以能长粮为由替父亲答应永续劳役 |

威尔士的阿劳恩与阿努恩放在独立的传统辨别词条，不在爱尔兰银潮主线里冒作同一位神与同一个世界。布兰诺克也不是航海者布兰的后代；同名近似不制造未经来源支持的神祇谱系。
