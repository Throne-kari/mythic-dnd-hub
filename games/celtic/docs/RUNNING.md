# 启动与朋友共游

安装 Node.js 22 或更新版，双击根目录的 `启动凯尔特.cmd`。程序会启动独立本机服务并打开 `http://127.0.0.1:18846`，无需安装 npm 依赖、账号或密钥。保持启动窗口开启；关闭窗口或按 Ctrl+C 停止。

默认是合作冒险。第一次进入获得普通玩家席，初始控制四名英雄；另有独立管理席。选择英雄、旅行、调查和剧情决定均可由玩家执行，敌人按规则自动行动。多个玩家先讨论再点选，服务器执行当前局面的第一项合法请求；晚到的过期请求刷新后重新选择。

在“进入管理”后分配普通玩家角色，再返回玩家继续。管理席不推进故事。另一浏览器会话需要对应普通玩家的席位令牌；令牌的权限与角色归属受服务器检查。断线满 90 秒后，仍有角色的合作玩家可以显式接管离线队友的一名英雄。

默认只绑定本机地址；此版本没有开启防火墙、创建公网隧道或部署网站。朋友可以在同一台电脑共同决定行动，也可以在本机多个浏览器会话使用独立席位。

命令行启动：

```powershell
node server.mjs
node server.mjs --no-open
node server.mjs --port=18848
```

`可选主持模式.cmd` 使用独立端口 18847 和独立数据目录，保留真人主持的全队控制与裁定；它不是默认玩法。

默认数据写入 `data/cooperative-celtic-v1/`，主持模式写入 `data/hosted-celtic-v1/`。每次成功行动原子保存自动档，管理席可以手动保存和读档。重新启动后创建新席位，再用新管理席显式读取自动档；旧令牌不会恢复。启动、新建空桌和读取存档不改写原自动恢复点，下一次成功行动才更新自动档。

源码包不应包含 `data/`，其中有私人进度、席位相关信息与智能体快照。新作的战役 ID、存盘格式、数据目录及浏览器会话命名空间均与其他游戏独立。

地图工坊仅向管理席和可选主持开放，可以绘制、摆放出生点、设置探索点、存盘、重载和开启遭遇试演。固定剧情地图与自制图分开，自制图不会自动生成新剧情。
