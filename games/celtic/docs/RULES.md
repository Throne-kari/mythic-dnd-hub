# 桌上规则

四名固定成年英雄分别担任近战前卫、远射牵制、治疗护持和范围施法。属性、护甲、生命、速度、射程与有限能力写在角色卡中。规则采用本作公开缩编的 d20 体验，含移动、视线、地形、借机攻击、动作与附赠动作、治疗、临时生命、倒地与救援和战败后的继续。

探索时选角色并点地图移动，靠近探索点可以调查。当前场景的故事选项受资源、既有行动、章节与阵营关系限制；可用决定会直接改变世界旗标、解锁后续场景，并保留在日志里。

战斗时每名英雄按先攻使用移动、一个动作和一个附赠动作。普通攻击由 d20 加攻击值对护甲；伤害按角色与能力结算。四邻格用于移动距离，石墙挡视线，深水不可进入，荆林、湿泥、冷雾和花灰消耗双倍移动，异界裂隙触发危险。点击结束回合后系统推进其余先攻，敌人自动选择移动与攻击。

共同药水用于饮用或喂给相邻队友；治疗可救起倒地者。全队短休消耗两份补给，恢复半数最大生命与有限能力。退离遭遇和战败按该场战斗配置留下后果，剧情不会自动复位。

三条主线可交替推进。章节目标必须实际完成或带着失败后果收束，才能进入下一章。结局由承诺、实施和最终授权共同决定；不能在最后一页任意选择没有准备过的归宿。善意、夺权、役使与交易会改变不同人物和制度。

管理席能编辑地图、存取档案和分配席位，不能直接推进剧情；默认冒险无需真人主持。
