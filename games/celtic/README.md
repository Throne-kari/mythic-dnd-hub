# 荆冠与归潮 · 七夜之外

荆冠下的土地需要供养，异界归来的人错过了一生。四名英雄穿过归潮，寻找自己的名字。

1–4 人；无需主持；三章 · 52 场景 · 24 结局。版本 1.0。
## 启动

推荐从合集网站进入，作者可在本机管理台启动、停止游戏和管理存档。单独运行需要 Node.js 24 或更新版本，无第三方 npm 依赖。

```sh
node server.mjs
```

默认地址 http://127.0.0.1:18846 。终端按 Ctrl+C 停止。可通过 PORT 指定端口。合集内部使用 HOST=127.0.0.1，通过网关提供网站入口。

HUB_DATA_DIR 指定本游戏的独立运行目录，包含房间、存档、席位和智能体文件。在合集目录内直接运行游戏或命令行工具，也默认使用合集 runtime/celtic/；HUB_RUNTIME_DIR 可调整合集运行目录。独立移出合集后使用本游戏原有默认数据位置。运行目录不应提交到 Git。游戏内容、规则和素材随源码提供，原作者机器的存档、配置和凭据均不在此发行版中。
