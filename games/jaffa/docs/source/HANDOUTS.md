# 《雅法余烬：盐仓之夜》玩家材料

这些是可按场景逐张发出的材料。**不要开场整份发出。**H01 在岸边获知路线后给；H02、H03 在盐仓调查时给；H04 在排水道发现便条时给；H05 在天亮前商谈时给。H06 是可选的桌边公开速查，可开场发。正文中角色已经做成的事情优先于材料中的旧描述。

【史实背景】1192 年 9 月上旬，停战消息已经传抵雅法后的一个原创夜晚。雅法仍在拉丁一方控制下。【本作原创】本材料中的人物、盐仓、绳场、排水道、地形、私人文书和奇物均为创作，不是历史文献转录，不代表全城制度。铜盂与火灵属于 D&D 奇幻，不是对现实信仰的证明。

## H01：岸边湿地上的路线图

交付时机：S01，尤素夫或汉娜说明地点后。

尤素夫用木片画了四块地方，又在海的那一边重重划了一条线。

```text
                          北 / 往城里
                               ↑
                北巷 ─── 盐仓正门
                         ┌─────────────┐
                         │ 西棚   东棚 │
                         │    院落     │
                         │ 炉间   盐库 │
                         └────后门─────┘
                               │ 约30尺
                          地表检修口
                               │ 约30尺
     岸边石阶 ─── 旧排水道海口 ─┘
       │
       汉娜的小艇                 石滩
       │                     （离木屋约120尺）
    南 / 海水

    盐仓东侧的巷道可去长绳场；步行约五分钟。
    绳场西门朝盐仓，东门通岸边石路。
```

这是记方向的草图，不是精确测绘。院落与战斗位置由主持补充。上方检修口和海侧入口都是进入排水道的实际通路；汉娜的小艇有帮助，也有石阶和石台可走。

尤素夫已经说出的信息：

- 玛尔塔还在盐仓，她有门钥匙，门本身通常没锁。
- 布特鲁斯的脚被木架压伤，需要抬梁、垫木或担架。
- 阿黛拉抱着铜盂从后门往旧排水道跑了，还没回来。
- 奥东的人威胁过他们，有人把焦油往仓后搬。

## H02：炉砖上的冷座示意

交付时机：S02，查看炉间或听布特鲁斯解释后。

一块旧炉砖上画着这样的东西。四角磨得很圆，砖背面写着“先问它，再动手”。

```text
             炉家 / 铜盂或合适耐热石盆
                       _____
                      /     \
                     |  火  |
                      \_____/
                   平整耐热底石
                ┌─────────────┐
                │ 湿石冷座    │
                │ 石槽中盐水  │
                └─────────────┘

        干木、布和绳离炉家至少两尺。
        盐水在底座外围，不灌进住着火的盆里。
        留通风处，保留能让它自行离开的方向。
```

布特鲁斯的说明：

“冷座是让热有地方慢慢走，不是把里面那位浇灭。石头放稳，盆别漏，湿的地方别碰着干木。搬它之前说清要去哪里，用湿布隔热，不要突然蒙紧。旧铜盂若坏了，可以换耐热石盆；住哪儿，还得问它自己。”

所需材料：四块合适石砖、一个完好的浅盆或旧冷座、盐水、湿布。仓里有这些日用物料。愿意照图花约十分钟，不需要精通神秘学才能修好。急着修或处于实际危险中，由主持说明检定和后果。

## H03：没有交出去的拒售便笺

交付时机：S02，调查陶匠工具或询问奥东的购买主张后。

> 奥东：
>
> 你问过两次，我的回答没有变。铜盂不卖。你买下的那批绳、木板和破罐里，没有这只盂。

>

便条边有一块黑色黏痕，带焦油气味。它可与已经看见的搬运、人物证词和仓后火绳互相核对；无需破译密码。没有这张纸也可以依据自己看见、听见的事行动。

## H06：今夜你可以怎样做

交付时机：可开场公开；这是桌边速查，不是角色世界中的文书。

你可以调查、交涉、分工、潜行、救援、施法、制服对手、撤离或拒绝委托。战斗是可选手段；不需要杀死所有敌人才能获得完成奖励。目标可以同时实现，不预设必须牺牲一个人或烧掉仓库。

- 核心线索会随合理观察或询问直接给出；骰子决定风险、速度和额外收益。
- 普通火、未燃火绳和能搬动的障碍，合理方法往往直接有效。
- 已经熄灭的火、已经救出的人和已经拆掉的布置不会为剧情需要自动重置。
- 火灵可以沟通；其意愿和安全条件需要被听见。魔法按真实能力生效。
- 若你选择冒险，主持会先说明可见危险；一次普通失败不等于无预告死亡。
- 暂退治疗、分队和让可信的人接手不是放弃；明确退出也有完整收束。

你要记住的四个名字：**玛尔塔、尤素夫、布特鲁斯、阿黛拉。**救援后可以亲口点名确认，再决定谁去做下一件事。
