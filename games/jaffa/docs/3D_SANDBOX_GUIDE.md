# 立体沙盘与模型导出

本版沙盘使用实际三维顶点和面，按yaw/pitch正交投影到Canvas；不是将二维地图贴图倾斜。场地、墙门、车、箱堆、桶、绳柱、人物和危险标记按本场数据构建，不使用封神地图、人物或法宝。

## 查看与操作

- 拖动沙盘旋转并改变俯角；点击仍用于选择人物、物件或可达格。
- Shift拖动或双指操作平移；“平移”可切换单指拖动模式。
- 滚轮、双指捏合或＋/−按钮缩放；⌖归位。
- 左右箭头旋转；俯角按钮改变观看倾斜程度；“顶视”切换俯视。
- “低墙”切换展示剖切，便于看清室内。“格”切换5尺网格。
- “OBJ ↓”导出当前席位可见场景的完整世界高度模型。

这些是已接入代码的操作入口，真实鼠标/触屏和响应式画面验收仍受 `BROWSER_BLOCKER.md` 所述Chrome启动拒绝阻塞。非浏览器数学与接口测试不等于已通过该项。

## 尺寸与规则边界

源坐标以尺为单位，X向东、Y向南、Z向上。六景平面尺寸、墙门位置、三尺北台、凹处和已标定高度沿用正文与静态地图。未知水底高度不虚构为规则数据；人物与无精确高度的标志模型属于展示。

旋转、顶视、缩放和平移只改变相机。低墙只缩短屏幕上的墙，不拆除服务器中的墙，不新增通行、射线或掩体效果。碰撞、移动、射程、视线、火区和资源仍由原服务端规则判断；立体展示不代表已加入任意高度的三维战斗规则。

## OBJ交付

导出为Wavefront OBJ，**1个顶点单位=1尺**。OBJ轴为X东、Y向上、Z北；源坐标转换为 `(x, z, -y)`。相机yaw/pitch、缩放、低墙显示不会改变导出的世界几何，墙总按已标定完整高度导出。

对象名称和注释已作单行/标识符处理。导出只使用当前席位收到的可见状态，不包含房间/席位凭据、邀请、聊天、主持正文、规则卡或隐藏NPC。它是场景几何，不是存档或D&D规则证明。颜色作为注释保留，不依赖外部贴图或网络材质文件。

包内 `docs/models/雅法_S01_立体沙盘.obj` 是用实际Board导出函数、真实HTTP玩家投影生成的首景样例。可由支持OBJ的软件打开检查。另有离线解析该文件生成的几何预览，标题明确“非游戏画面”；它不冒充实际浏览器截图。

样例包含988顶点、645面，SHA-256为 `121588e5d88f15c13eb79735a93ee7c8b7b2db5b3bf81d79b6551292dcdf0a49`。离线预览见 [OBJ几何预览（非游戏截图）](models/雅法_S01_OBJ几何预览_非游戏截图.png)。可选开发工具 `tools/render_obj_preview.py` 使用本机已有Matplotlib重新绘图，游戏本身不依赖Python或该绘图库。
