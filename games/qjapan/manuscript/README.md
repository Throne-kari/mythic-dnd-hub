## 本版实际内容

- 弧一把资助、自己的著作权、侍从受托抄件和公开署名放在真实合同中。可以自利地接受商行稿费，但不能因此占有别人的证词；独立不等于必须贫穷或牺牲。
- 弧二让接应劳动、受托银扣、继承者的住处、先还羽衣与退款缺口产生具体后果。任何成年关系都可写成友情、合伙或淡出，资源与既有同意不随亲密程度改变。
- 弧三用普通60GP公库、器具、照护、隐私授权和三种有限服务合同处理公共制度。PC可不代管钱、不扮私人伤口，仍能调查和表决；没人被强迫承担终身劳动。

每弧至少三处在场选择，另有结局前结算。重要原遭遇保留调查、交涉、战术/绕行与撤退；失败带实际损失继续。好办法确实省钱、省人力或避战，已救者与已完成照护不为制造黑暗被追夺。没有好感、善恶、秽、寿数或声望数值条。
