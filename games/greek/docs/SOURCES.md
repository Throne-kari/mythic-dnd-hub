# 神话依据与原创边界

《无葬之城》是新建的原创 CRPG。忒斯玛（Thesma）、外港败战、角色、三线事件与制度均为虚构，不宣称对应已发现的历史城邦，也不冒称为旧希腊项目的升级版本。玩法是自定义 d20 规则，并非 D&D 2024 规则的完整或官方实现。

本表只记录实际核阅的原典译文与官方文化机构页面；没有用搜索摘要代替原文。核阅日期：2026-10-21。正文采用自行撰写的中文转述，没有搬用现代译文长段落。

## 四章版的新增原创机制与留痕

内容版本2保留原典依据，扩大原创后果，不增加未经核证的历史断言。役魂护岸、俄瑞斯、骨灰快苗、内泉影像、第一份祭谷在本城的执行方式、十年可退出守桥约，以及海岛接收条款均是本作创造。绝不称其为真实的希腊劳动法、德尔斐程序或厄琉西斯秘仪。

原典对“葬仪改变死者处境”的支撑具体在《伊利亚特》23卷69–92：未受葬仪的帕特罗克洛斯受阻于河外，完成火葬后不能再回来。游戏仅借此确立送亡的实在性；仍可显现的受役影子与释放仪式另属原创设定，并非翻译或复现这一段故事。该卷约138行以后的发绺誓愿也显示对河神的承诺与亡友之情可能冲突，本作不照搬为普遍仪式。

《致德墨忒耳》305–313并未把饥荒简化为人不肯耕种：即使犁过田、播下麦也可能不生。四章版据此保留筛种与劳作不能保证神恩的边界；祭谷破约的闭苗事件为虚构城地方祭约的实玩后果。470行后关于仪式不宜轻言的界线仍被尊重，没有编写所谓真实秘仪操作教程。阿波罗相关来源只支持神谕圣域背景，不证明泉影内容或现代心理学/致幻机制。
