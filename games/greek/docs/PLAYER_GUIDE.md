# 合作冒险玩家操作

从合集游戏入口打开《无葬之城》，自动创建合作冒险，不需要真人主持或模型 API。规则、敌人回合和战斗结算由系统执行。在“房间与席位”复制同行邀请链接；朋友加入后可认领多罗斯、塔蕾娅、梅莉娅或伊昂。

未认领的英雄可由同行者共同操作。其他队员在线认领的英雄不能抢控；其连接断开并确认离线45秒后可由同行接管，返回上线后恢复归属保护。可在房间面板查看当前可控英雄；后台标签页只要保持同步连接就仍算在线。默认界面不包含主持叙事与地图工坊；旧主持房间保留原功能兼容。

## 在城里行动

地图每格代表一个战术距离单位。先点下方英雄卡，再点可走格移动。墙、深水和石柱不能直接穿过；石路与地面消耗1，高台与碎石消耗2移动力。高台只改变移动消耗，没有额外高度加成。石柱附近提供掩体并遮挡远射。探索时移动不限每回合步数；战斗时受当前英雄speed限制，青绿可达格只是提示，服务端仍会重新验证。

左侧的三条命运可随时查看。任务文字给出所需地点；按场景道路旅行不耗一天，抵达后全队在入口集合。把一名可控英雄移到剧情点两格内才能作出选择。锁定选项可能缺少交叉旗标、资源、到场英雄，或正在战斗；错误提示不会偷偷扣资源。每个阶段都有不花资源但导致失败的出口，资源短缺也能继续故事，不必卡死。

每作出一次剧情决定或休整，日期加一；第49日未解决的主线失败并触发封港。四章完整路线共36次决定，到第37日，剩余时间可安排休整。每章三线各三个节点，先走出本章的一线等待其余两线汇流，不能越章抢先拿后章奖励；下一章公开补给只发一次。前章目标失败会留下损失并接续下一章的新目标。无需按固定顺序完成三线：例如先修水闸能降低墓园打捞代价，先公开神谕账册能迫使神庙开仓，后续公民资格、补偿、种源和证词还会改变制度与迁徙条件。

## 遭遇与代价

两场遭遇由明确的剧情选项引发；合作路径可以避开它们。当前英雄有一次行动及独立移动点，攻击需要射程和视线。守势临时提高护甲；治疗花1药材，可救起倒地同伴。梅莉娅信任达到2时多恢复2生命，严重失信则拒绝额外协助；伊昂的见证会影响技能检定。基础英雄控制权不会因剧情自动删除。

结束四位英雄的回合后敌人自动移动和攻击。合法交涉可消耗2谷物或3银币，令愿意谈判的敌人撤离；撤离写入地图状态，不能刷掉落。拒绝谈判的敌人不能用此按钮绕过。战斗结束才能继续剧情或旅行。全员倒下会被带回集市、恢复半血，付出两天、两粮与民乱；这可能使最后期限更紧迫。

全队休整消耗两粮并过一天，生命全满。资源、同伴与阵营分数在顶部或队伍信息中可查；最近事件保留摘要，完整卷轴可回看最多800条日期、实际骰、命中、伤害、成本和剧情后果。一次检定失败仍会向前推进，并结算完整失败结果，不靠重复点按钮重掷。

## 可选旧主持模式的地图工坊

主持打开地图工坊，以既有地图为起点另存自定义ID；剧情原图不能被覆盖。选择地形笔刷，在格网上绘制。怪物工具可放置和移动敌棋，出生点与剧情点必须保持可通行；所有点位和出口必须从入口可达。

依次进行“保存地图 → 重载地图 → 载入战局”。保存写入当前房间的customMaps；重载重新读取权威状态而非只保留浏览器草稿；载入战局让队伍和怪物实际使用此图。JSON导出可分享地图数据，导入仍需服务端检查。自定义图最多12张，尺寸6–40格，默认战役图为20×13。保存当前自定义图会按模板重置敌人和队伍入口，主持应在两场遭遇之间编辑。

## 存档与继续

合法动作自动保存；合作队员均可用界面的四个存档槽保存，只有房间发起者可读取，以免其他队员覆盖当前进度。API另支持安全的英数短槽名。读档恢复章节、剧情、队伍、资源、地图和回合，修订号仍递增，旧客户端动作因此失效。在保留运行目录的部署上，服务重启后原浏览器会话可续接。免费临时磁盘部署休眠、重启或重新发布可能丢失房间与存档，不能把浏览器令牌当作备份。旧主持模式仍可从同浏览器的主持备份恢复，须由服务器验证原令牌。保留完整runtime备份，不要直接修改运行中的JSON；源码升级时把原版和runtime分开留存。新四章版的contentVersion为2，不会把12节点技术原型存档误读成新版。

第四章三条主线全部完成或失败，且无战斗时可结算终局。24个内容终局各有权力安排、角色命运、世界情况和代价；期限失败另计。正常、黑暗、妥协、失败可以混合，前期损害不会被末尾一个善意按钮自动清除。完整剧情参考含路线与剧透，玩家可待终局后再阅读，不是开团必需步骤。
