# 四名三级预设角色规范

核对依据：共用引擎`preset-base.mjs`中的四张完整SRD人类卡（2026-10-20），姓名与人物由本作`campaign.json`覆盖。全部固定三级、熟练加值+2、速度30尺、初始3枚生命骰；每人另有个人治疗药水1瓶，与任务争议药匣中的四瓶是不同物品。

这份规范说明构筑与规则来源，运行时的HP、法术位、临时效果与物品以实际房间人物卡为准，不能用本表重置资源。普通装备由本场主持预配；铆钉皮甲与工具是装备，不是额外角色特性。

## 通用人类特性与构筑

- Resourceful：完成长休后获得Heroic Inspiration。当前开场各有一次，至多持有一次。
- Skillful：额外一个技能熟练。Versatile：本卡选Skilled，额外三个技能/工具熟练；加值已经计入下列熟练技能。
- 背景分别采用Soldier、Criminal、Acolyte、Sage；故事头衔不替换机械背景。
- 属性采用标准数组并按背景提升；没有种姓、神力、业力等数值。
- 语言：通用语；地方语言在开桌填定，按角色创建规则选择合法来源的语言，不以现实族群决定智力或道德。人名均为原创角色用名，不冒充原典英雄。
- 一般技能使用对应属性调整值；列出的熟练/专精按下表，不把“18技能都显示”误认为18项都熟练。

## p1 阿鲁娜：Fighter 3 / Champion

人物：灯镇护渠卫士，愿意把拉绳与扛货的人安全带回。可成为队伍中的稳定支点，也可以拒绝把保护变成替别人作主。

| 项目 | 数值/选择 |
| --- | --- |
| 力/敏/体/智/感/魅 | 16 / 13 / 16 / 8 / 12 / 10 |
| 属性调整值 | +3 / +1 / +3 / −1 / +1 / +0 |
| HP / AC | 31 / 19（链甲16+盾2+Defense1） |
| 先攻 / 生命骰 | +1，优势 / 3d10 |
| 豁免熟练 | 力量+5、体质+5 |
| 技能熟练 | 运动+5、体操+3、洞悉+3、威吓+2、调查+1、察觉+3、游说+2、求生+3 |
| 背景 / 专长 | Soldier；Savage Attacker；人类Skilled |
| 工具 | 骰子 |
| 长剑 | 攻击+5，1d8+3挥砍，5尺，Sap |
| 标枪 | 攻击+5，1d6+3穿刺，投掷30/120尺，Slow |
| 手斧 | 攻击+5，1d6+3挥砍，投掷20/60尺，Light，Vex |

三级通常每次Attack仅一次攻击；额外攻击五级才有。卸盾须按Utilize规则。链甲带来的隐匿劣势保留。

资源与选项：

- Second Wind两次：附赠动作回复1d10+3HP；短休回一次，长休回全部。
- Action Surge一次：本回合多一个动作，不能用于Magic；短/长休恢复。
- Tactical Mind：失败能力检定时可按原文花Second Wind加入1d10；仍失败不花次数。
- Champion：武器/徒手19–20暴击，先攻与Athletics检定优势；暴击后可立即移动至多15尺且不引发借机攻击。
- Savage Attacker：每回合一次命中后，武器伤害骰掷两组择一，不复制固定加值或偷袭等非武器骰。

## p2 那林：Rogue 3 / Thief

人物：熟悉货仓、暗路和绳结的港口寻路人。秘密既能换钱，也能打开一条公开道路；他自己决定何时把秘密交出去。

| 项目 | 数值/选择 |
| --- | --- |
| 力/敏/体/智/感/魅 | 8 / 17 / 14 / 14 / 12 / 10 |
| 属性调整值 | −1 / +3 / +2 / +2 / +1 / +0 |
| HP / AC | 24 / 15（铆钉皮甲12+敏捷3） |
| 先攻 / 生命骰 | +5（含Alert熟练加值） / 3d8 |
| 豁免熟练 | 敏捷+5、智力+4 |
| 技能熟练 | 体操+5、欺瞒+2、洞悉+3、医药+3、察觉+3、游说+2、巧手+5、求生+3 |
| 技能专精 | 隐匿+7、调查+6 |
| 背景 / 专长 | Criminal；Alert；人类Skilled |
| 工具 | 盗贼工具 |
| 短剑 | 攻击+5，1d6+3穿刺，5尺，Finesse/Light/Vex |
| 匕首 | 攻击+5，1d4+3穿刺，投掷20/60尺，Finesse/Light/Nick |
| 短弓 | 攻击+5，1d6+3穿刺，80/320尺；本卡未选其精通 |

资源与选项：

- Sneak Attack每回合一次2d6：须Finesse或Ranged武器，并满足优势或目标5尺内有另一未失能敌人等完整条件；有劣势不能偷袭。
- Cunning Action：附赠动作Dash、Disengage或Hide。Steady Aim按原文放弃移动换取相关优势。
- Fast Hands：附赠动作执行相应巧手、Utilize或触发需Magic动作的魔法物品；不是让普通准备法术变成附赠动作。
- Second-Story Work给攀爬速度30尺，跳跃按其原文处理；不是不受地形约束的飞行。
- Alert：先攻加熟练加值，掷完可与同场一名自愿且未失能盟友交换先攻。
- 短剑与匕首Nick可按Light规则在同一Attack中完成额外匕首攻击；无相应风格时额外匕首不加敏捷伤害，不再获得第三次轻武器攻击。
- 三级尚无Uncanny Dodge、Evasion或Reliable Talent。

## p3 米拉：Cleric 3 / Life Domain

人物：把人能否平安回家看得比争名更重的行路医者。D&D施法是游戏能力，不意味着现实宗教的唯一仪轨或权威。

| 项目 | 数值/选择 |
| --- | --- |
| 力/敏/体/智/感/魅 | 13 / 10 / 14 / 12 / 17 / 9 |
| 属性调整值 | +1 / +0 / +2 / +1 / +3 / −1 |
| HP / AC | 24 / 18（链甲16+盾2） |
| 先攻 / 生命骰 | +0 / 3d8 |
| 豁免熟练 | 感知+5、魅力+1 |
| 技能熟练 | 运动+3、洞悉+5、调查+3、医药+5、察觉+5、游说+1、宗教+3、求生+5 |
| 背景 / 专长 | Acolyte；Magic Initiate(Cleric)；人类Skilled |
| 工具 / 圣职 | 书写工具 / Protector（军用武器与重甲训练） |
| 钉头锤 | 攻击+3，1d6+1钝击，5尺 |
| 法术攻击 / DC | +5 / 13 |
| 法术位 | 一环4、二环2 |
| 引导神力 | 共享2次，短休回1，长休回全 |

准备与戏法：

- 戏法5：Guidance、Light、Sacred Flame、Spare the Dying、Thaumaturgy。
- 常规准备6：Command、Create or Destroy Water、Detect Magic、Healing Word、Shield of Faith、Silence。
- 领域固定4：Bless、Cure Wounds、Aid、Lesser Restoration，不占六个常规名额。
- Magic Initiate额外固定Sanctuary，每长休免费一次，也可耗法术位；不重复占常规准备位。
- Detect Magic与Silence可按实际准备和仪式标签进行仪式施法。

引导神力选项：

- Divine Spark：Magic动作，30尺内可见的另一生物，1d8+3治疗或依原文作伤害与体质豁免，不能选自己。
- Turn Undead：按原文选择30尺内不死生物，失败后Frightened与Incapacitated，受伤等会提前结束；本场不要求使用它。
- Preserve Life：Magic动作，30尺内Bloodied生物（可含自己）分配共15HP，各目标最多恢复至最大HP一半。
- Disciple of Life：用法术位施放治疗法术时，在施法当回合额外恢复2+法术位环级。药水、Channel Divinity、免费MI与仅增加最大/当前HP的Aid不因这个特性追加治疗。

重甲来自2024 Protector，不来自旧版生命领域一级特性。Lesser Restoration为新版附赠动作；治疗法术使用当前版本的骰数，不套2014数值。

## p4 迦维娅：Wizard 3 / Evoker

人物：喜欢对照契书和水路结构的学者。她问“这句话到底答应了什么”，也愿意让法术为实际选择打开道路。

| 项目 | 数值/选择 |
| --- | --- |
| 力/敏/体/智/感/魅 | 8 / 14 / 13 / 17 / 13 / 10 |
| 属性调整值 | −1 / +2 / +1 / +3 / +1 / +0 |
| HP / AC | 17 / 12（无甲）；实际施放Mage Armor后15 |
| 先攻 / 生命骰 | +2 / 3d6 |
| 豁免熟练 | 智力+5、感知+3 |
| 技能熟练 | 奥秘+5、历史+5、洞悉+3、医药+3、察觉+3、游说+2、巧手+4 |
| 技能专精 | 调查+7（Scholar） |
| 背景 / 专长 | Sage；Magic Initiate(Wizard)；人类Skilled |
| 工具 | 书写工具 |
| 匕首 | 攻击+4，1d4+2穿刺，投掷20/60尺 |
| 法术攻击 / DC | +5 / 13 |
| 法术位 | 一环4、二环2 |
| 奥术回想 | 每长休一次；短休后回总环级不超过2 |

准备、法术书与戏法：

- 戏法5：Acid Splash、Light、Mage Hand、Ray of Frost、Minor Illusion。
- 常规准备6：Mage Armor、Magic Missile、Shield、Sleep、Misty Step、Web。
- Magic Initiate固定Feather Fall，每长休免费一次，也可耗位；免费次数与普通法术位分开。
- 法术书12：Alarm、Comprehend Languages、Detect Magic、Mage Armor、Magic Missile、Shield、Sleep、Unseen Servant、Misty Step、Web、Scorching Ray、Shatter。
- Ritual Adept可从书中仪式施放Alarm、Comprehend Languages、Detect Magic、Unseen Servant，不需要准备但须读书并按仪式增加时间。
- Scorching Ray与Shatter是Evocation Savant加入书中的两个法术；当前未准备，不能看见书名就直接按普通施法施放。
- Potent Cantrip：伤害戏法攻击失手或目标豁免成功仍半伤，且无其他附带效果；Ray of Frost失手的半伤不附减速。
- 三级没有Sculpt Spells、Memorize Spell、高环法术或自动保护队友免受Acid Splash影响。

## 装备与材料核对

四人都有普通衣物、背包、口粮1日、水袋、火绒盒、蜡烛10支、麻绳50尺及5GP个人装备记录。职业武器、护甲、盾与工具按人物卡。药物与特殊任务物件的取得、使用、转交按唯一ID保存；标准药水不能被“甘露”别名增效。

V/S/M、耗价材料、专注与施法目标始终照官方条目。界面未提供的细节由主持依原文裁定并同步资源，不声称本作实现全部SRD。完整出处见[规则检索](03_SRD规则检索.md)，许可见[SRD归属](04_SRD归属与许可.md)。
