### 春议是实物投入

- **守港**：自有长船押给湾户，队伍留下一个冬天任期。可用押船加八枚赎港，非此使命现金赎港为十六枚；退任则失押船。该船不能再作住船或拆作梁。
- **护证**：自有长船改成证人住船，队伍承担护航，船舱不再装自己的贸易货。流动稿可直接上船；庇护也有真实床铺。土地工程须另付料。
- **留乡**：不可逆拆自有船，船梁只可在庇护或土地工程用一次。已经用于灯屋，就不能再免费修同一座工棚；想迁海须真实修好燕尾与保住浮箱。

因此三条完全相同的前史在春议后也会产生不同的资产、职责与下一章费用，不能只改终章镜头。另两条主线仍须各自立案、执行，按结果完整回收。

## 最小接口

`initialState` 只给实际共同资源：24 金钱、8 行粮柴料、4 治疗药水。四名角色的正式战斗与属性卡由 `engine.mjs` 管理；内容 `party` 只有同名背景简表，没有第二份数值卡。

场景为 `scenes[id] = { id, arc, title, location, mapId, text:[], requires, choices:[] }`。地图从 `harbor / thing / mound / hel / forest / forge` 六张取。选择为 `{ id,label,description,requires,effects,next,check?,combat?,ending? }`。枢纽导航均为 `repeatable:true`；结算节点以 `ID_done` 禁止再入和重复领款。

条件只有运行核心能执行的 `all / any / not / flag / resourceAtLeast / relationAtLeast / questState / sceneUnlocked`。关系提供可靠协作的可见前提，不被扣除。标准属性仅 `str/dex/con/int/wis/cha`。所有负资源在选择前有足额条件；检查的尝试成本若有则放在选择的 `effects` 中，之后才执行 `check.success / failure`。本稿的三个检查均无额外金钱成本。

`effects` 的资源、关系和阵营数字为增减，`flags / quests` 为赋值，`unlockScenes` 为真实开放。任务只用 `locked / active / done / failed`。选择通常返回 `hub`，下一阶段由新解锁的枢纽按钮进入；不必绕行整张地图才获准读下一页。

每个 `battles[id]` 有 `enemies / victory / defeat / escape / outcomeText / next`。战胜、战败和逃离各自赋予相符事实并开放下一阶段；不靠结局标签倒造资源、伤亡或转移权利。战败伤势与救回 1 生命的短篇规则由运行核心处理。

## 必经失败、可选战斗与黑暗路线

- A2 查纸失败只失去识别货箱来处的把握，仍可证明补页；B2 比纸失败仍保留物理证据；C3 抢修失败改开侧闸，仍可免费安置六人。
- A3 `fight`：胜得环，败或逃得可核旧约摹样，A4 继续。败退失去此次取环机会，不虚扣不存在的柴。
- B3 `silence_echo`：胜至 B4H；败或逃至 B4L。未到雾厅就没有亡者证词。
- C2 `wolves`：胜木到闸；败失这一车木、冬闭；逃离也冬闭。C3 仍有零资源开侧闸。
- A5 `leave` 明确使粮仓线失败；B5 `blame` 明确使证词线失败并使无辜猎伴离村；C5 `lie` 明确使碑线失败并保留公共谎言。三线失败仍可到终局，不生成无端游戏结束。
- 黑暗选择包括勒索、强迫假画押、夺仓强派工、售卖亡者假话、导盐水毁渔具、永久安全假碑。收益与代价各自成立；不会靠神罚回收利润，也不会把同伴拒绝变成自动服从。

## 可直接复跑的路径

每条动作的前一步是从 `hub` 选择 `visit_场景ID`；序幕先用 `land`。终局先 `final_council`，再作 `council` 选择。检查与战斗的独立验收由 QA 报告负责，本页列数据的合法预期，不冒充已执行证据。

| 路线 | 选择序列 | 预期结果 |
|---|---|---|
| 三线协作 | A1 `shore` → A2 `extract` → A3 `witness` → A4 `rotation` → A5 `commons`；B1 `refuse` → B2 `consent` → B3 `walk` → B4H `public` → B5 `correct`；C1 `compare` → C2 `crew` → C3 `repair` → C4 `grain_shelter` → C5 `witnesses`；终局 `commons` | `common_spring`，含两个实际 A→C 和一个 B→C 协作 |

## 回收与显示

`campaign.epilogues` 有 15 条具体事实回收，每条附 `requires`，必须经运行核心过滤后显示，不能原样展示未发生的未来剧透。三名同伴的 `reactions` 已按低到高优先级排列，核心取最后匹配项为 `currentStance`。过去已经发生的污染、诬告、泄名或勒索不会因后来的更正被删除。

史料采用和明确未采用的争议见 [sources.md](sources.md)。本作没有付费 API、密钥或模型依赖；本代理只负责 `content/campaign.mjs` 与本目录两份叙事说明，最终 UI、规则缩编与独立验收由各自所有者完成。

## 扩写前的七结局检查点（历史保留，非最终数量）

本节保留三章扩写前的原始七个收束。该检查点有 22 场景、98 选择、3 战斗、7 结局；普通玩家 p1 从 `createState(41)` 经 33 条真实选择到达 `common_spring`，金钱 24、行粮 10、药水 4。实际产生 `crew_used / communal_grain_used / public_witnesses / measured_supports`。此前两处非法战斗出生点已修到地图可走格。此为作者烟测，不代替独立验收或真人时长证明。

- **换班之春**：仓钥轮过三只不同的手，账上每一筐粮都有去向。弗里盖尔修完约好的两次栏，第三次缺人时，人们重新来问他。卡里的名字没有被用来要求另一人吃苦。碑边写着这一季的水位与限期；它没有许诺永安，下一季仍有人愿意来量。
- **租来的春天**：黑帆照约发了粮，湾里过了冬。解冻以后，新来的小船才知道三年的卸货权意味着每一筐鱼都要多走一道秤。你们救回的事没有失效，签出的权也没有消失。来春若想改约，须有人拿出新的船、粮和愿意担的风险。
- **盐冠**：仓门只认你们的钥，碑上永安的两个字被反复拿来堵住询问。粮依然发出，却由命令决定谁先领、谁先上工。弗里盖尔带着自己的工具走了。索尔维格留下未刮的旧稿，霍格娜不再给新路。你们得到了一个可供统治的冬天，也使有人开始寻找离湾的船。
- **见光的债**：勒索的钱不再藏在“替大家好”的话里。你们把来处说清，账房也把可指认的数目留给受影响的人。承认没有自动变成偿还。至少这次碑上保留了更正，原稿没有烧掉。愿意继续核对的人能看见你们在哪一步改了口，仍可要求把具体的债一笔一笔清掉。
- **向西带灯**：六名成年人各自选了新的床铺和接收人。有人想家，有人庆幸终于离开，谁也没被一句“他们去了西边”从故事里抹掉。关于卡里的有限报告随船同行。它没有替旧屋挡住潮水，却让新岸边的人知道：这个冬天，并非所有离开都叫作被神选中。
- **空行解冻**：第六行没有字，父亲的火塘边也没有供人传抄的最后呼喊。木片仍记着每个已经到达的去处，留白没有撤销这些实际结果。春来时，未修的榫仍要修，闭着的路仍须再议。人们可以继续争论碑义，不必替一份从未答应的神谕流血。
- **这一季的冷和平**：把已经做成的事留在已经做成的地方：救起的粮没有再沉下去，自由离开的人没有被旧约重新押回。没开成的仓、没撤掉的假话和没修好的闸也一并留下。盐峡湾没有因一次旅途便和解。来春若有人再来，必须从这些真实后果出发，而非从一张把所有人都写成英雄的白纸开始。
