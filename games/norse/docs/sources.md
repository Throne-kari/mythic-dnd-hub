## v3 新写内容

三章扩写的反字雾桥、只能重说已写／已说句子的灯具、炉下借名钉与潮钟，都是明示为本作原创的可玩怪异规则，不来自埃达篇章。弗里盖尔的妹妹芮芙、雾姊旧慰语与成年徒弟索尔、护船队长托拉、斯万希尔德、哈康、玛伦、伊杜娜、冬学堂与三章24种具体秩序／土地后果，也均为新写人物与社会关系；没有据这些情节增加历史事实。三章仍保留卡里自然落石的既定死因。

盐峡湾、石南谷、三窗谷、灰顶丘、旧臂环、弗里盖尔、赫瑞德、卡里、霍格娜、索尔维格、赫立尔夫、西格丽德、托吉尔、弗里德芙和受保护少年阿尔夫海因承接 v2 的原创设定。v3 不导入玩家旧存档，不默认某一种旧结局已经发生。

内里、猎伴伊尔莎的本版具名、三派组织、新收据与伪纪念纸、粮船搁损、三年港约、潮闸锻棚、借名之影、各项交易价格和全部可执行分支均为 **D·本作原创**。卡里仍死于自然松落的岩石；新冲突是活人在事后借名收债，没有用新阴谋推翻旧死因。

旧诗、散文、萨迦、碑铭与现代接受不能互相补成一个统一教义。本作未采用或新断言 Grágás 誓法、真实立石程序、Rök／Kvinneby／Sö 179 争议读法、溺者归属、Niflhel 层级、诸神黄昏时间表。游戏中的“常固／此季”与第六行并非任何真实碑文译文。巨族是故事称谓，不能反推为 D&D 怪物种族的历史等号。
